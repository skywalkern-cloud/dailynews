AI初创企业的下半场：钱往哪里去？

作者｜王晗玉 编辑｜张帆 2026年的风险投资市场，正在上演一场前所未有的“AI大分流”。据Crunchbase数据，今年上半年全球初创企业融资额约5100亿美元，已超过去年全年；仅第一季度，约80%的风险投资便流向了AI公司。OpenAI单轮融资1220亿美元、估值冲上8520亿美元，Anthropic则以9650亿美元估值反超，成为全球最有价值的AI初创企业。 狂热之下，分化同样剧烈：头部模型公司融资能力依旧惊人，大量垂直应用却是有用户、难见利润。 市场不再比模型参数，开始比应用落地，“AI下半场”的拐点叙事，正在取代此前的算力军备竞赛——对于仍在牌桌上的初创企业而言，生存规则已经变了。 当全球资本涌向高增长机会，下一站究竟在哪里？11月2日至3日，香港金融科技周×StartmeupHK 2026即将举行，市场目光将再度聚焦这座连接内地创新与全球资本的城市。在科技周启幕前，36氪与华映资本创始管理合伙人季薇、香港投资推广署署理初创企业总裁吕缙勇进行了深入交流，试图回答一个问题：AI初创企业的下半场，什么才是真正的判断标准？ 拼过模型参数，再拼“数据飞轮” “阅项目”无数的季薇先给出一套大致的分析框架：AI投资可分为基础层、模型层与应用层三层。基础层涵盖GPU、高速光互联、先进封装、存储体系乃至供电热管理，以及推理调度、异构算力适配、数据治理与安全等系统级环节。 外界对“算力投入过度”的质疑，在她看来更多是节奏问题，而非方向问题——基础设施投入与收入形成之间，天然存在周期错配。正如2000年前后，海底光缆与交换机先于互联网公司的盈利而繁荣，彼时谷歌甚至还没有收入。 真正决定一个细分赛道能走多远的，是她数次提及的“数据飞轮”：数据以什么成本获取、以什么形态进入模型，能否在短时间内形成正反馈、反哺模型能力。 这也是为什么编程是目前收入规模最大的AI应用——代码对错一目了然，正反馈极强；而视频生成虽需求真实，却因反馈难以标准化，模型提升的难度高得多。正如OpenAI停掉Sora，Anthropic从未碰过视频，背后正是对这一点的判断。 市场的验证来得很快。Cursor年化收入在一年内从突破10亿美元涨��约26亿美元，GitHub Copilot付费用户已超470万。在季薇看来，任何一个AI应用赛道的天花板，最终都取决于市场规模与用户注意力总量，而非单点技术炫技。 吕缙勇则从需求侧补充了另一层标准：能否解决真实、高频、高价值的痛点，客户是否清晰、有付费意愿，技术壁垒能否持续转化为成本优势——经历过互联网泡沫洗礼的人都知道，泡沫破裂后活下来的公司，无一例外先站稳了商业模式。 具身智能：最热闹的赛道，最“早期”的阶段 在季薇眼中，具身智能依然是AI应用里最活跃的领域，也是最“早期”的领域。模型发布与评测的频次仍在持续，说明最聪明的大脑还在涌入，只是尚未等到属于它的“chatGPT时刻”——她给出的保守时间预期是5-10年，但非常相信这个时刻会到来。 一个被反复澄清的观点是：具身智能不等于人形机器人。它可以是海底的仿生形态、低空的自主飞行器，也可以是太空中的柔性机器人，去做人类到不了的地方的工作。 华映资本在这些方向均有布局，包括低空自主飞行机器人，以及中国首家在太空完成验证的柔性机器人；其投资的具身智能世界模型公司——自变量机器人——也是目前在香港活跃的世界模型团队之一。 吕缙勇同样认为，具身智能是“模型+硬件+数据+场景反馈”的系统工程，各环节尚未真正咬合：打螺丝仍需人类工程师在旁边兜底，物流搬运的稳定性也远未达标，眼下能落地的更多是巡逻、巡检这类相对受限的场景。 市场的预测也在印证这种“早期”共识。摩根士丹利预计，中国人形机器人市场规模今年约20亿美元，2030年或达150亿美元；不同机构对广义具身智能的测算口径差异明显，从数千亿到万亿不等。 对香港而言，AI与智能制造、AI for Science、绿色能源管理，以及金融、医疗、物流等高价值企业级应用，正是未来3-5年最有潜力的方向。 吕缙勇特别提到，香港的研究型大学沉淀了大量科研IP，AI介入实验室的意义在于把“爱迪生式的试错”大幅缩短——从干实验到湿实验，减少人为失误、提高命中率，这可能催生一批高价值的突破性成果。而大湾区的制造生态正在与香港的科研资源加速融合，也让具身智能的供应链有了更现实的落地土壤。 现金流成为创始人的必修课 当36氪问及那些手头现金快撑不下去的中小AI初创公司该何去何从，吕缙勇的建议很直接：尽早做一次冷静的现金流分析，聚焦能带来正向现金流的业务，砍掉非核心开支；资金见底时，应坦诚与战略投资者沟通，而非等危机爆掉后才求助。政府补助也应尽早纳入规划，而非临到融资时才想起申请。 季薇也提到，现金流管理是创始人的必修课，“口袋里只剩1-6个月的钱，还在问该怎么花，多半要反省自己的规划能力”。 在她看来，业务的里程碑必须与融资的里程碑咬合推进——从政府科研经费、早期机构的成果转化支持，到市场化机构，再到能带来订单与资金的产业资本，每一步都要提前规划，而不是埋头干一年再抬头找钱。 她也认为，并购不应被视为危机管理，而是发展过程中的主动选择，真正的“1+1&gt;2”才值得做。 结合过往投资案例，季薇专门提到一个真实的转型样本：一家原本做培育钻石自动化切割打磨的公司，凭借核心工艺积累转向芯片堆叠所需的散热材料，在半导体领域找到了第二曲线。在她看来，AI在各行各业的应用都还在早期，拥有核心技术壁垒的公司，换个赛道再试一次，并不算晚。 如何答好“出海”这道题 谈及即将到来的香港金融科技周×StartmeupHK 2026，季薇透露，她将在科技周上与另外两位嘉宾带来一场对话，主题是《全球资本新动向：解码下一个黄金投资赛道》，“其实跟今天聊的还挺类似的”。吕缙勇笑着接了一句：“今天已经剧透了。” 而站在香港市场，话题也自然落到了内地企业出海这道必答题上。 季薇专门提到华映资本参与投资的协作机器人企业法奥机器人，这家公司在2025年位居中国协作机器人总销量第一、海外出货量第一。在季薇看来，它的发展很契合一句话——“Think Global, Act Local”（全球化思考，本地化运营）。 季薇认为，传统出海路径往往是先设海外主体、参展、签代理，再找客户需求；但真正有效的路径或许恰是从客户出发，想清楚对方需要什么、预算多少、谁做采购决策、替代方案有哪些、数据如何处理、售后由谁负责等问题。 因此，数据合规、知识产权、出口管制与安全审查等一系列规划要前置到产品设计阶段，而不是铺完市场再补课。她也不建议一上来就全球铺开，而是先在一个标杆市场跑通，再向相邻市场复制。 吕缙勇对此的补充是，跑业务除了要快，更要精准接地气。企业出海要尽量避免把内地“跑省份”的复制打法直接搬到海外——每个城市的文化、法规甚至历史背景都不同，尊重当地规则、组建本地销售与交付团队，接地气地跑业务往往比技术本身更重要。 在这套出海叙事里，香港的独特角色也正被重新理解。研发、供应链与应用场景可以放在一小时生活圈内的大湾区，国际融资、区域总部、合规架构与人才引进则落在香港。依托普通法体系与国际仲裁经验，海外客户更愿意与香港主体签约；香港也正帮助企业把内地的创新能力，转化为国际客户可以长期信任的商业关系。 过去一年多，华映资本把香港视为“再创业”的基地：申请牌照、筹备港币基金，未来投向将面向全球优秀创业者与前瞻性技术突破，并深度参与香港本地高校的科研转化。同时据季薇观察，越来越多的风险投资同行也正在加强在香港的布局。 来到AI下半场，香港这个连接内地创新与全球资本的双向门户，也不再只是大企业的上市终点站，而正成为更多AI初创企业的出海桥头堡。一如吕缙勇送给出海企业的建议：出海之前，先来海边看看。 新入口和旧城墙之下，“中国版Muse”有多远？

文 | 李炤锋 编辑 | 张雨忻 1040万次，这是Meta的AI个人助理Muse上线不足两个月的累计下载量，由此，国内快速掀起了一轮Personal Agent产品热潮——谁能做出一个“中国版Muse”，成为了全行业都在关注的话题。 一批创业团队正在加速入场。去年离开字节的原豆包PC端产品负责人齐俊元，今年再次创业，推出主打持续记忆和主动服务的Today AI。以通用任务执行走红的Manus，则于近期推出个人助手Cue，为Agent配备邮箱、电脑等工具。以AI硬件r1起家的Rabbit，如今将重心延伸到新一代OS3：用户既可以通过网页，也可以通过r1使用这套助手，团队还在开发为之配套的新一代AI 硬件...... 这些团队正在尝试不同的产品路径：一种是在手机或电脑上提供独立的Personal Agent软件，另一种则是和硬件深度融合，以硬件为入口。 在软件测，有的产品强调持续了解用户、主动提供帮助，有的为AI配备独立的电脑和账号，让它执行任务，还有的尝试连接用户已有的电脑，并通过软件和硬件等多个入口接收指令。这些做法并不互斥，但各家选择的起点不同。 但在国内，创业公司的Personal Agent首先要面对的，是来自大厂的免费产品。豆包、千问已经聚集了大量用户，字节和阿里还在不断向其中加入办事能力。大厂可以把新功能送到已有用户面前，独立的Personal Agent亟须回答的是：它提供的便利，究竟能让多少用户持续使用，甚至愿意放弃大厂的免费产品而为自己付费？ 另一方面，争取到用户，也不等于能替用户办成事。国内的购物、出行、支付等服务集中在各个平台，Personal Agent要跨App执行任务，都需要获得服务方的许可。第二代豆包手机助手在近期推出SAEP协议后，微信、淘宝、支付宝、美团等App出现在拒绝AI代操作的名单中。现阶段，助手远远做不到在 App 间畅通无阻。 近期，智能涌现与多个Personal Agent创业团队聊了聊，我们发现，尽管Muse那样的通用助手是行业的愿景，但对创业团队而言，眼下的产品逻辑必须有所取舍。 个人生活助手理旦先从记事、安排日程做起，再逐渐接管更多生活场景；同样开发个人Agent的WishSeen，准备先集中打磨一个生活功能；主打主动服务的个人助手UniCone，则优先面向创作者、个人IP等人群。它们有的从功能入手，有的从客群入手，但路径有共同之处：先争取一部分用户持续使用、愿意付费，再考虑扩大产品的服务范围。 WishSeen联创曹方咏峥表示：“个人Agent是个好的叙事，但如果不能让用户持续使用，并且持续愿意为它付费，那肯定是不行的。” 当“AI接管普通人生活”的热潮涌向国内，用户习惯与服务生态的差异也随之显现。“中国版Muse”能否沿着同样的路径起飞？甚至包括Muse在内的，究竟能不能成为一门生意？投资人、创业公司和大厂，都已置身这场尚未揭晓答案的赌局中。 你的生活，需要交给Agent吗？ Personal Agent要进入普通人的生活，先得证明这个需求真实存在。 今年以来，各类Agent产品迎来了爆发式增长，从Coding到Work，再到如今面向生活场景的个人助理。随着应用场景越来越细分，Agent厂商必须给用户一个使用其产品的理由。 LinkAI创始人查雨捷的团队位于深圳，从聊天机器人项目chatgpt-on-wechat起步，逐步将其发展为能调用工具、操作电脑的开源助理CowAgent。团队同时提供企业平台LinkAI，帮助客户搭建智能体、知识库和工作流。 “其实Personal Agent不是一个特别新的品类或者技术，它更多是一种使用场景。”查雨捷对智能涌现说。他的顾虑是，普通用户已有豆包、千问，专业用户也有办公Agent。“再开发一个同类产品，怎么让个人用户买单，其实是一个问题。” 美国风投机构Menlo Ventures在今年发布的消费者AI报告中发现，美国AI用户中，同时使用通用助手和专门处理某类任务的AI工具的比例，从去年的60%升至72%。机构认为，即使已经使用ChatGPT，用户仍可能为其他的具体需求，再选择一款更好用的工具。 这份报告提示了一种可能：Personal Agent和通用AI工具也许并不冲突，前提是要在日常场景里能够提供真实的便利。 理旦是一款帮人打理生活的个人助手。用户说出要做的事，产品把待办从聊天记录中提出来，放到主界面。创始人阿汤把这种设计称为“以事情为中心”：目前先帮用户记事、安排日程，未来希望进一步替用户完成订酒店、订机票等任务。 理旦的社媒主页写着“在成都，5个人做中国版Muse”。但阿汤坦言，他们已经在计划出海：“我们后面的重点是做海外，但想先通过国内市场把产品磨出来。” Personal Agent如果要持续服务用户，就得知道什么时候该帮忙。 来自深圳的UniCone团队正在开发主动式个人助手，尝试从用户授权的屏幕内容、聊天记录等信息里整理待办、拆解任务。“它得是主动性的，和之前帮你完成某件事情不太一样。”UniCone CEO说，这需要不断感知用户的情况，在后台运算，判断提供帮助的时机。 这种判断并不容易，尤其是用户的个人信息会不断变化。科技媒体TechRadar编辑兰斯·乌拉诺夫曾分享他在试用Muse时，就曾遇到这样一个场景：Muse发现旧资料里的葡萄牙旅行计划，与近期邮件中的意大利行程不一致，随后，Muse向乌拉诺夫确认并更正了目的地信息。 Muse的主动服务能力，得益于其在邮箱中实时掌握了大量用户信息，但这一路径显然和国内用户生态有着巨大差异——在国内，大量上下都存在于微信、支付宝、大众点评等多个超级App中，Personal Agent如果拿不到这些信息，能提供合格的主动式服务吗？ Today AI产品经理Suki是比较乐观的，她认为，微信之外仍有可用的信息来源。“微信不能垄断一个人工作和生活的全部信息，至少很多工作信息都不是沉淀在微信上的。”Suki表示，Today AI不少用户已授权助手访问飞书、健康、日历等数据，这些应用也能为助手提供理解用户的线索。 但并不是所有 Personal Agent 都想一开始就包办用户的生活，尤其是暂时没有拿到大钱的创业公司。 正在开发手机个人助手的WishSeen，准备保留记忆和主动性，但只集中打磨一个生活功能。联创曹方咏峥解释，追求大而全，团队既难承担成本，也难做出差异。“我宁愿把某一个功能做到用户足够愿意每天使用，甚至付费。” 对创业团队而言，暂时收起万能助手的设想，先把一个具体的生活功能做扎实，似乎更容易在大厂的资源夹击下，找到一个向上的突破口。 新入口和旧城墙 目前，这一批Agent创业团队基本都已经小范围验证了产品逻辑的可行性，但这只是打造产品的第一步——从0到1，创业公司可以在数百名种子用户中验证想法；可再往前走，就要面临和大厂的资源竞争。 今年1月，阿里在发布会上演示了用千问订奶茶，背后是淘宝、支付宝等服务的接入。千问C端事业群总裁吴嘉当时表示，希望未来“大部分生活办事场景只用千问App就够了”。到了9月，阿里又推出面向手机厂商的Qwen Intelligence；10月，千问Go开放体验申请，尝试理赔、价保和预约。 9月底以来，字节跳动旗下的豆包也在陆续接入出行、生活缴费能力。大厂可以在原有产品中加入生活服务能力，也有足够的资源打通部分外部生态。 但对于独立Agent团队而言，获客则要从零起步。 “大厂确实资金雄厚，能够免费，也能够给自己砸钱打广告，这方面我们是比不了的。”阿汤说。他把理旦的突破口放在交互上：“如果产品一模一样，肯定比不过大厂。” “提醒、待办这些东西，不应该沉在会话流里，应该被提出来，放到主页面。”阿汤说，“真正有价值的东西提出来之后，聊天记录就不那么重要了。” AI短剧的特殊之处在于，它把文化内容与人工智能产业连接起来。传统短剧制作仍受到演员、场地、拍摄周期和后期制作成本等条件限制；AI则能够参与剧本开发、角色与场景生成、画面制作以及多语言适配，从而显著降低进入海外市场的门槛。换言之，AI短剧不仅在“卖故事”，也在输出模型能力、工具链、平台运营和工业化内容生产经验。 **为什么选择AI短剧而非全真人制作** 方汉将AI短剧视为微短剧国际化的重要技术路径。相比真人拍摄，AI短剧的优势首先体现在成本可控。微短剧需要快速试错、密集上线并持续测试用户反馈，如果每个项目都依赖真人演员、现实场景和传统摄制组，单部作品的成本与周期都会成为商业化障碍。AI生成能够减少对演员、摄影棚及复杂拍摄环节的依赖，使团队以更低成本制作大量内容。 其次，AI更适合规模化生产本土化版本。中国微短剧拥有成熟的连续剧集、短视频节奏和情绪钩子，而海外市场存在语言、审美、叙事传统和付费习惯上的差异。真人短剧的本土化往往需要重新拍摄，AI则可以更快地生成不同角色、场景和语言版本，甚至针对不同国家制作差异化剧情。 第三，AI有助于突破真人演员的供给和档期限制。对于需要大量角色、奇幻场景、历史背景或特殊视觉效果的故事，AI可以快速完成现实拍摄中成本高昂的部分。不过，AI短剧并不是简单地用数字人取代演员，而是以技术重构整个生产流程，使内容生产从重资产拍摄转向更灵活的数字资产和工业化协同。 **为什么优先开拓海外市场** 中国国内微短剧市场已经发展成熟，并形成了较强的用户基础和竞争环境。国内市场并非短剧的唯一增长空间，海外则存在更广阔的潜在需求。短剧以情节密集、情绪强烈、节奏明快和单集篇幅较短为特点，容易适配移动互联网和碎片化消费，也适合通过付费解锁、应用内购和广告等方式实现商业化。 中国厂商在微短剧领域积累了成熟的运营经验，包括用户获取、内容投流、付费转化、续集制作和快速迭代。海外市场用户结构更加多样，不同地区对爱情、复仇、家庭关系、身份逆袭等叙事元素存在差异化需求。中国企业能够将成熟的短剧运营方法带到海外，同时利用AI技术降低翻译和本地化成本。 因此，出海不仅是市场扩张，也是中国互联网内容能力、平台能力和技术能力的一次集中输出。与单纯把国内作品翻译后搬运不同，真正的海外业务需要理解当地文化，并用当地受众喜闻乐见的方式重新表达。 **文化差异：婆媳关系未必通用，狼人可能比吸血鬼更好卖** 短剧出海不能忽视文化语境。中国故事中常见的婆媳矛盾、阶层差异、家庭伦理和复仇逻辑，并不一定都能被其他市场准确理解。如果直接照搬国内情节，海外用户可能因为缺少共同经验而难以产生情感共鸣。 方汉以“婆媳关系老外看不懂”为例，说明文化壁垒会直接影响内容的传播效果。相比之下，“狼人比吸血鬼更好卖”，则反映出海外市场中存在自身熟悉的幻想文化和类型传统。中国微短剧虽然擅长制造强冲突，但真正有效的出海产品，需要找到跨文化传播中的共同情绪，同时结合目标市场的文化符号进行再创作。 这意味着本地化不是简单的语言翻译，而是对人物关系、价值判断、叙事悬念和视觉符号的整体调整。AI可以提高本地化速度，但无法代替创作者对文化差异的理解。能否把中国成熟的情绪生产方式与海外受众熟悉的文化元素结合起来，是AI短剧能否从“快速复制”走向“真正出海”的关键。 **AI短剧的生产效率如何计算** AI短剧的核心商业价值，在于把内容生产从传统重制作模式改造成高效率、低边际成本的数字化模式。传统短剧需要经历选剧、编剧、演员、拍摄、后期和发行等环节，任何一个环节都可能延误上线。AI介入后，剧本拆解、角色设定、形象生成、场景搭建、配音、字幕和画面生成等环节可以被连接起来，多个版本还能够并行制作。 从企业角度看，效率不能只看生成一张画面或完成一段视频需要多长时间，更应考察完整项目从创意到上线的周期、每个环节的人工投入、单部作品的制作成本、内容更新频率，以及作品上线后的用户留存和付费转化。只有当AI真正减少重复劳动、缩短制作周期并提高内容测试速度时，它才能构成商业模式，而不只是技术演示。 同时，AI并不等于完全无人化。高质量短剧依然需要编剧、导演判断、审美把控、剧情审核和运营反馈。技术决定生产速度和成本，人类团队则决定作品是否好看、是否可信以及能否击中用户情绪。 **爆款的灵魂仍然需要人类编剧** 方汉强调，爆款短剧的“灵魂”仍然需要人类编剧。AI能够生成情节、对白和场景，也可能快速提供多个创意方案，但短剧最关键的内容能力仍是判断什么能激发观众兴趣、什么冲突能够持续推动追更、哪个人物关系能够形成情绪依赖。 微短剧竞争高度依赖创意密度。一个项目可能拥有相同的题材、相似的角色和相近的AI画面，但如果缺少对人性的洞察，就难以建立付费用户愿意持续观看的情感关系。人类编剧的价值，不是与AI比速度，而是提出更好的问题、设计更可信的人物弧光、识别容易被机器稀释的平庸套路，并在技术生成之外赋予作品情绪和意义。 因此，AI短剧更可能形成一种协作模式：人类负责核心创意和审美决策，AI负责扩写、视觉实现、版本适配与重复性工作。真正的竞争力不只是掌握生成模型，而是建立能够持续生产好故事的创意机制。 **更大的命题：全球文化平权** AI短剧出海最终指向的不只是某一家企业的商业增长，而是全球文化传播方式的变化。过去，小语种市场往往因为翻译成本、配音成本和内容供给不足，难以形成独立的影视产业。AI生成、字幕、配音和本地化工具，可以降低小众语言市场的进入门槛，让更多国家拥有自己的短剧品牌和内容产业。 当技术平台能够跨越语言和地域限制时，文化传播有机会从少数强势文化单向输出，转向更多地方文化被看见、被消费和共同参与。中国微短剧企业可以把成熟的商业模式和生产能力带到海外，同时也吸收不同国家的故事、审美与表达方式。这样一来，“全球文化平权”并不意味着所有文化完全趋同，而是让原本缺乏传播能力的文化同样拥有抵达全球用户的可能。 **总结与核心启示** AI短剧出海是中国文化产品、数字平台和人工智能技术协同走向世界的一次新实验。AI降低了微短剧的生产成本，提高了本地化和规模化发行速度；海外市场则为中国内容企业提供了更大的增长空间。但技术并不是唯一答案，婆媳关系难以被海外用户理解、狼人比吸血鬼更好卖的例子说明，文化差异仍然需要创作者认真处理。 这期对话的核心启示是：AI短剧的竞争力来自技术效率与人类创意的结合。AI可以更快地生产画面、对白和本地化版本，人类编剧则必须负责情感共鸣、人物塑造和跨文化理解。未来胜出的企业，不一定只是拥有最强模型的平台，而是能够同时建立创意体系、生产流程、全球分发和本地运营能力的公司。最终，AI短剧既可能成为中国文化出海的新增长点，也可能推动更多地方文化以更低成本进入全球市场，迈向更加平等、多元的文化传播格局。

# 永久资本、集中投资与在市场下跌中保持主动：比尔·阿克曼的投资方法论 **市场下跌时的优势来自“不能赎回”** 市场一旦下跌，投资者往往会产生撤资冲动。这种行为会迫使基金出售资产、增加市场压力，也会让原本拥有长期眼光的管理人被迫在低位做出决策。比尔·阿克曼认为，永久资本改变了这套逻辑：如果投资人的资金无法被轻易取走，基金管理人就不必为了应对赎回而卖出证券，反而能够在恐慌和混乱中寻找被错杀的企业。 阿克曼将这一优势视为自己投资方法的重要基础。集中投资意味着一旦找到少数真正优秀、能够长期创造现金流的公司，组合资金就有可能持续投入到这些企业之中。相较于不断追逐短期机会，这种策略更强调耐心、持有能力以及对商业价值的深刻理解。永久资本提供的不仅是时间，还减少了市场情绪对投资决策的干扰，使投资者能够独立判断，不必被短期资金流向牵着走。 **为什么只投资少数公司** 阿克曼以集中投资而闻名。他并不追求把资金分散到大量缺乏了解的企业上，而是倾向于选择少数高确信度标的，并围绕这些公司进行深入研究。集中投资的潜在回报建立在三个前提之上：企业具有长期可持续的竞争优势，管理层能够有效配置资本，以及未来的自由现金流足以支持较高的估值。 这种策略对研究能力和风险控制提出了更高要求。只投少数公司意味着单个判断失误可能对整体组合造成更显著影响，因此，不能把集中投资简单理解为长期持股，更不能把它等同于忽略估值。阿克曼真正强调的是，将企业分析、基本面研究、估值纪律和长期资本结合起来。只有当企业价值持续增长，并且价格没有明显透支未来预期时，集中持有才可能成为优势。 **用长期现金流判断企业价值** 节目讨论了如何判断一家企业是否值得长期持有。阿克曼的分析重点并非短期股价波动，而是企业未来能够产生多少现金，以及这些现金流最终归属于谁。长期现金流是检验商业模式、竞争优势和资本配置能力的关键尺度，也是将企业内在价值与市场价格联系起来的基础。 现金流的重要性在于，它比利润更难通过会计方法或市场叙事进行包装。投资者不仅要观察收入和利润，还要判断利润能否转化为现金、增长需要投入多少资本，以及企业是否能够把现金持续投入高回报项目。对长期投资者而言，当前估值必须与企业在未来多年产生的现金流相匹配；如果价格上涨主要依赖估值扩张，而不是现金流增长，那么投资的安全边际就会下降。 **长期资本并不等于忽略风险** 永久资本可以让投资者在市场下跌时更加积极，但它并不自动保证投资正确。阿克曼所强调的是，在拥有充足资金和较长时间的前提下，认真研究、持续跟踪企业，并愿意接受来自反方的质疑。真正困难的问题不是找到自己认同的观点，而是确认自己的投资假设是否经得起反驳。 因此，估值仍是集中投资不可缺少的约束。长期持有不能成为忽视价格的理由，更不能成为拒绝重新审视商业模式的借口。即使面对表现优异的公司，也需要持续判断其竞争优势是否削弱、行业格局是否改变、增长是否放缓，以及原有资本配置逻辑是否仍然成立。长期资金给予投资者修正错误的时间，但前提是他们愿意承认错误并及时调整。 **认真听取反方意见** 节目特别提到，投资者需要认真听取反方意见。阿克曼将“被挑战”视为投资过程中不可缺少的一部分。对任何投资结论提出质疑，有助于识别叙事中的漏洞，也能防止投资人因为持仓已经获利或对公司产生感情而形成确认偏误。 有效的反方意见并不是为了证明观点相反而争论，而是要提出能够检验投资逻辑的具体问题，例如：企业的竞争优势是否真实，管理层是否会损害少数股东利益，当前价格是否已经包含过于乐观的假设，关键假设如果失败会造成多大损失。阿克曼的做法之所以能够形成鲜明风格，一个重要原因就是他愿意让有能力、有信息的人挑战自己的判断，同时仍由自己承担最终决策责任。 **AI正在重塑市场与投资** 对话还涉及人工智能对市场和投资的影响。AI 的发展可能改变企业的生产方式、竞争格局和成本结构，也可能催生新的高增长公司，同时削弱部分传统商业模式。对投资者而言，AI 既是产业机会，也是一种估值风险：如果市场已经把巨大的增长预期计入价格，那么技术进步即便真实发生，投资回报也可能低于预期。 面对这一趋势，长期投资者既不能因为题材热门就追逐概念，也不能因为已有成熟业务就忽视技术变化。更合理的方法是分析 AI 究竟如何影响企业的收入、利润率、资本需求和竞争优势，并判断公司是能够分享技术红利，还是会被新进入者、供应商或客户重新分配价值。AI 最终仍应被纳入现金流和资本回报的框架，而不是被当作脱离基本面的独立故事。 **家庭变故、脑康复与脑机接口** 节目还谈到阿克曼在家庭变故之后，对脑康复和脑机接口产生关注。这部分内容让讨论从资本配置延伸到医疗、技术与人类恢复能力等更个人化的议题。脑机接口代表了神经系统与数字设备之间更直接的连接方式，可能在康复、辅助沟通和功能恢复方面带来新的可能；但要真正进入广泛应用，还需要解决安全性、可靠性、可负担性、伦理规范以及监管问题。 从投资角度看，这类技术仍需要接受与普通医疗或科技企业相同的检验：临床价值是否明确，产品能否规模化，监管路径是否清晰，商业化能否形成可持续现金流。对阿克曼而言，这段经历可能进一步强化了他对长期研发、复杂问题解决和高质量组织的关注，因为这类项目通常需要长期投入和耐心，无法依靠短期市场情绪迅速兑现。 **总结与核心启示** 本期对话的核心是：永久资本、集中投资和开放质疑共同构成了一套强调长期价值的投资方法。市场下跌并不可怕，真正危险的是资金期限与投资策略错配。当投资者没有被迫赎回的压力时，才更有机会在恐慌中研究机会、买入优质企业，并以未来现金流而不是短期情绪衡量回报。 比尔·阿克曼带来的最重要启示有三点：第一，集中投资的前提不是自信，而是深度研究、估值纪律和风险管理；第二，长期持有并不意味着永远不变，而应持续检验企业竞争力和投资假设；第三，投资者应主动听取反方意见，让结论经得起挑战。无论讨论传统企业、AI 还是脑机接口，真正值得长期关注的问题始终相同：企业能否创造真实、可持续并归属于股东的现金流，以及当前价格是否留下了足够的安全边际。

## 中国摇滚四十年：在历史现场与神话叙事之间寻找真实 **摇滚诞生的历史坐标** 1986年5月9日，崔健在北京工人体育场举行的“让世界充满爱——献给国际和平年”演唱会上演唱《一无所有》，这一天由此被广泛记为中国摇滚的诞生日。四十年后的回望，不仅是为了纪念一首歌、一位音乐人或一场演出，也是为了重新追问：摇滚乐为何会在当时的中国出现，它又如何从一种边缘的音乐实践逐渐成为理解社会情绪与时代变化的重要窗口。本期播客由《三联生活周刊》主笔张星云主持，邀请乐评家、学者李皖，以《我们的摇滚四十年》封面报道为基础，梳理中国摇滚起步阶段的历史，并讨论“摇滚已死”论背后的现实。 **从工体到红磡：一段被反复讲述的历史** 从1986年的北京工人体育场，到1994年的香港红磡体育馆，中国摇滚史上的几个标志性场景不断被后人讲述。《一无所有》唱出对个体处境的质疑，“中国摇滚乐”走向海外的大规模演出则一度成为文化开放与传媒汇聚的象征。然而，越是广为流传的叙事，越容易在重复中形成固定印象：人们逐渐记住的是“诞生日”“红磡”“英雄人物”和代表作品，却可能忽略这些事件发生的具体条件，以及音乐人与所处时代之间更复杂、更暧昧的关系。李皖的讲述，正是要重新回到历史现场，区分真实经历与后来的概念化塑造。 **1986年前后的青年文化土壤** 节目首先回到1986年前后，讨论当时爱音乐的年轻人究竟在听什么。中国摇滚并非凭空出现，它诞生于特定的社会转型、青年文化需求、城市生活方式和外部音乐传播的交汇之中。那个时期，改革逐步展开，社会价值观念开始松动，年轻群体对个性表达、情感宣泄和精神自由的需求日益增强。摇滚乐所包含的反叛姿态、怀疑精神和强烈节奏，为这些需求提供了新的语言。 与此同时，中国摇滚的形成也经历了“东西碰撞”。西方摇滚乐传入中国，与本土的民谣、说唱、戏曲、民歌和时代情绪结合，才逐渐形成具有中国经验的中国摇滚。它既不是对海外音乐的简单模仿，也不是传统音乐的直接延续，而是一种在特殊历史条件下生成的新表达。摇滚进入中国，既受到媒介、磁带、演出市场和城市文化环境的影响，也经历了本土化过程。 **时代巨变中的第一代摇滚人** 第一代摇滚人的重要性，不仅在于他们留下了若干经典作品，更在于他们以音乐忠实记录自己所感受到的时代巨变。在八十年代的社会转型中，摇滚成为表达失序、焦虑、理想、愤怒和希望的一种方式。音乐人观察城市与人的变化，把个人体验放进更大的时代背景中，因此他们的作品天然具有强烈的现实感和历史质感。 李皖对这一阶段的关注，提示我们不要只用作品排行榜或怀旧情绪来理解早期摇滚。那些看似粗糙、躁动甚至充满争议的演出，实际连接着社会结构的变化和一代青年的精神处境。崔健的《一无所有》之所以具有标志性，正因为它超越了单纯的口号，以个人的困惑和追问呈现了一个时代的共同情绪。 **《一无所有》与摇滚的历史象征** 1986年的工体演出后来被塑造成中国摇滚的“原点”，但历史起点与神话起点并不是同一回事。纪念日式的叙述强化了故事的整体性和戏剧性，使某一场演出成为整个运动的象征，也容易遮蔽此前长期积累的音乐探索，以及此后不同阶段的发展。 节目并未把中国摇滚描述成由少数天才突然创造出来的传奇，而是把它放回八十年代的青年文化环境中考察：为什么是那个年代？哪些人受到影响？他们面对怎样的城市与社会现实？又是什么力量让一场原本普通的演出在日后获得“诞生神话”的地位？这些问题，有助于还原摇滚发生的条件，也能避免把复杂历史压缩为一个过于整齐的故事。 **“94红磡”如何被符号化** 这并不意味着后来的“神话”毫无价值，而是提醒人们：纪念传统可以帮助一代人确认自身经历，但历史研究不能止于重复结论。中国摇滚四十年既值得被纪念，也值得被重新打开。只有区分事件现场、参与者回忆与公众叙事，才能看清音乐风格、人物选择、媒介传播和制度环境之间复杂的作用关系。 **“摇滚已死”究竟意味着什么** 在商业化、主流化和媒介碎片化的今天，“摇滚已死”成为一个反复出现的判断。它可能指传统乐队形态和经典作品不复再现，也可能指反叛精神被消费主义吸收，或指真正具有现场力量的摇滚乐队越来越少。但摇滚是否仍然存在，不能只以商业成绩、曝光率或是否能进入大众排行榜来衡量。 四十年的时间，足以让一种音乐从边缘声音变成公共记忆，也足以让真实历史被层层讲述覆盖。重新讨论1986年的工体、1994年的红磡以及第一代摇滚人的作品，并不是为了拆除已经形成的象征，而是为了理解象征为何产生、在什么条件下产生。 这期节目以中国摇滚四十周年为线索，从1986年的《一无所有》与工人体育场出发，追溯中国摇滚形成时的时代环境，解析第一代音乐人如何记录社会巨变，并重新审视“94红磡”等历史事件如何被记忆、宣传和符号化。其核心启示是：历史纪念不能替代历史现场，“摇滚已死”也不能简单理解为一种音乐类型的消失。 ## 短剧巨头对决：红果、绿泡泡与AI浪潮下的红海生意 **红果跑出规模，绿泡泡加速追赶** 字节跳动的红果短剧与腾讯的绿泡泡短剧，正在短剧赛道形成正面交锋。红果短剧的日活跃用户已经突破一亿，并跑通了广告变现闭环，因此在本轮竞争中占据明显的规模优势。腾讯旗下的绿泡泡则依托微信生态，以小程序作为轻量化入口，快速触达用户并追赶红果。两家互联网巨头的加入，意味着短剧已经从内容创业和流量生意，进一步演变为平台级入口、用户时长和商业化体系的竞争。腾讯与字节的再次交锋，也将短剧市场的格局推向新的阶段。 **从流量规模到生态竞争** 这场对决并不只是两款短剧产品之间的较量，而是字节与腾讯在内容分发、流量入口和商业变现能力上的一次正面碰撞。红果的优势在于规模已经形成，用户基础和广告模式相对成熟；绿泡泡的追赶路径则更强调微信生态的支持，通过小程序降低用户进入门槛，使用户能够便捷地接触短剧内容。 从行业视角看，微信生态为绿泡泡提供了区别于传统独立App的轻入口优势。依托用户熟悉的社交和支付环境，小程序可以缩短从看到内容、产生兴趣到进入付费或广告环节的路径。红果则需要依靠现有的内容供给、用户规模和广告变现体系巩固优势。两种路线各有特点：一方是先发规模带来的成熟闭环，另一方是生态协同带来的增长弹性。最终谁能在短剧赛道占优，不仅取决于产品体验，也取决于平台能否持续提供优质内容、稳定承接流量并提高商业转化效率。 **AI降低制作门槛，却没有解决盈利难题** AI技术成为短剧行业扩产的重要推动力。剧本辅助、素材生成、画面制作和后期处理等环节的效率得到提升，制作成本与生产周期随之下降，使大量短剧项目能够以更低的门槛批量上线。平台也因此更容易丰富内容供给，在短时间内扩充剧集数量和题材覆盖范围。 然而，供给增加并不等于商业成功。AI解决的是“如何更快、更便宜地生产内容”的问题，却没有同时解决“如何获得用户注意力”和“如何让项目回本”的问题。短剧行业由此出现一个明显矛盾：内容产能快速膨胀，真正能够成为爆款的作品却依旧稀缺。平台上线更多项目，可能提高整体流量和收入，却也可能因为大量低质量或同质化内容分流用户注意力，进一步抬高获客与竞争成本。 这意味着，AI更像是一把放大器，而不是保证盈利的机器。它能够放大优秀团队的效率，也可能放大低质量内容的数量。真正稀缺的依然是好故事、强情绪钩子、适合目标用户的表达，以及能够贯穿投流、留存和付费转化的运营能力。制作门槛越低，供给越泛滥，爆款反而越难被识别。 **爆款稀缺成为行业核心矛盾** 尽管短剧市场拥有庞大用户需求和可观流量，但“上线一部剧”与“成功一部剧”之间仍存在巨大鸿沟。大多数项目难以回本，已经成为行业繁荣表象背后的真实状况。短剧商业模式往往依赖持续投流、用户留存和付费转化，任何一个环节表现不足，都可能导致项目收入无法覆盖制作、投放与运营成本。 因此，短剧并不是一门天然稳赚不赔的生意。过去的红利阶段，部分项目依靠题材红利、流量红利和快速复制获得了较高收益，但当字节、腾讯等大型平台入场，平台会进一步争夺优质内容、优质制作团队和用户消费时长。内容供给方面对的不再只是同行，而是掌握更强流量分发能力、更完整数据体系和更成熟商业化工具的综合平台。 在这种情况下，短剧项目的收益波动性进一步上升。仅靠低成本批量生产越来越难以构成稳定优势，团队必须同时具备内容判断、投流测试、数据分析和长线运营能力。AI虽然能够缩短制作时间，却也让竞争者更快复制相同创意，使题材创新和内容差异化变得更加重要。行业正在从“有没有产能”转向“能不能持续命中爆款”。 **出海并非躺赢** 短剧市场的高热度也推动大量平台和制作方寻找海外增长机会。中国短剧拥有成熟的工业化生产、投放和付费运营经验，出海因而具有天然的内容与模式优势。但海外市场并不等于轻松的流量洼地，更不代表只要翻译剧集、复制国内模式就能获得成功。 不同国家和地区在用户偏好、文化语境、支付方式、监管环境及广告生态方面存在差异。国内跑通的用户心理、付费习惯和投流策略，无法被简单原样复制。海外平台还面临本地化制作、渠道合作、获客成本和合规运营等复杂问题。尤其在AI大幅提高内容供给效率后，海外同样可能出现产能过剩和内容同质化，竞争未必因市场扩大而减弱。 因此，出海是一项需要深度本地化和精细化运营的生意，而非“躺赢”捷径。真正具备全球竞争力的团队，需要理解目标市场为何付费、什么样的叙事能够引发共鸣，并建立与当地平台、渠道和用户相匹配的变现机制。单纯把国内短剧搬运出去，最多可能获得短期流量，很难自动形成稳定回报。 **总结：短剧大战背后的商业真相** 红果与绿泡泡的正面交锋，标志着短剧行业进入巨头平台强化用户入口、争夺内容生态和商业化效率的新阶段。红果凭借日活破亿和成熟的广告闭环领先，腾讯则通过微信小程序生态推动绿泡泡快速追赶。与此同时，AI将行业推向批量生产时代，却也带来产能泛滥、同质化加剧和爆款更加稀缺的问题。 这期内容最重要的判断是：短剧需求真实存在，商业模式也已经被验证，但任何具体项目都不能据此被视为稳赚不赔。平台规模更大，不代表每部作品都容易成功；制作成本下降，不代表获客和竞争成本也会下降；国内模式成熟，也不代表出海能够轻松变现。 **核心启示：技术只能降低生产门槛，精品内容与运营能力才决定回报** 短剧行业下一阶段的核心，不再只是提升产量，而是提高内容命中率。AI应当被用于提高创作效率和测试能力，而不是让团队陷入无限批量生产。平台需要建立更有效的分发与商业化机制，制作方则需要把预算和资源集中到高潜项目，并通过数据反馈持续优化。短剧仍是一门高流量、高弹性的内容生意，但最终决定盈利的，始终是用户是否愿意持续观看、付费以及主动传播。

WHOOP长期采集用户的24/7健康数据，节目提到平台已经积累约500亿小时的信息，其中包括心率、心率变异性、睡眠、训练负荷、身体恢复与压力等指标。与传统智能手表主要围绕步数、通知或单次运动记录提供功能不同，WHOOP强调全天候背景数据：系统不仅告诉用户“睡了多久”，还试图理解前一晚的睡眠质量如何影响当天的训练安排，以及连续高压工作、训练和恢复不足是否正在形成累积性风险。 不过，持续采集也伴随着隐私、安全和数据治理问题。健康数据高度敏感，一旦泄露，影响远不止于支付信息。节目在这一部分不仅呈现了WHOOP数据规模带来的竞争优势，也指向公司必须回答的关键问题：数据是否被充分告知其用途、用户能否真正掌握和删除自己的信息、AI分析是否具备足够透明度，以及企业级健康产品能否在个性化与隐私保护之间取得平衡。 **AI教练、日记洞察与GLP-1追踪：让数据转化为行动** 在产品能力方面，节目重点介绍WHOOP的AI教练、日记功能和GLP-1药物相关追踪。随着生成式AI进入消费健康领域，WHOOP并不满足于展示图表，而是希望利用长期生理数据和个人日志，对用户的训练、恢复、睡眠与生活方式提出更具体的建议。用户输入“昨晚睡不好”“今天要参加比赛”或“近期使用减重药物”等信息后，平台可以结合背景数据帮助其理解原因并调整行为。 “日记洞察”的意义，是把主观体验与客观指标连接起来。心率、睡眠和恢复分数只能说明身体出现了某种变化，却未必能解释变化的原因。用户日志为AI提供情境，使平台从描述过去转向支持决策。例如，系统可能发现恢复下降与饮酒、压力或训练安排有关，也可能判断连续高负荷虽然暂时提高了训练指标，却正在挤压恢复空间。这种“人机协作”的健康管理模式，比单纯提供更多数据更有实际价值。 GLP-1相关追踪则反映出WHOOP正在适应减重药物普及带来的新问题。使用司美格鲁肽或替尔泊肽等药物后，用户的体重、饮食、睡眠、训练表现和恢复状态都可能发生明显变化。传统可穿戴设备往往只把体重下降视为成功结果，但WHOOP有机会进一步观察药物如何影响睡眠、能量水平与运动表现，并提醒用户在减重过程中维持肌肉和体能。药物追踪不能替代医疗建议，却能帮助用户与医生沟通时提供更完整的时间序列信息。 **FDA监管与竞争者：WHOOP如何避免滑向“医疗设备”边界** 节目还讨论WHOOP与美国食品药品监督管理局，也就是FDA之间的关系，以及它与Apple Watch、Garmin、Oura Ring等竞争性可穿戴设备的差异。WHOOP需要明确区分“健康管理建议”和“医疗诊断”之间的边界：普通消费产品可以帮助用户理解趋势、改善睡眠和训练，但如果平台宣称能够诊断疾病、预测临床结果或替代医生，就可能进入FDA监管更严格的产品类别。 这种监管边界会影响算法设计、临床验证、产品文案和用户预期。WHOOP的优势并不一定是功能数量最多，而是专注恢复、训练压力和全天健康数据，并通过订阅服务形成持续反馈。竞争者则拥有更大的硬件生态、更多表盘功能或更强的品牌与渠道。WHOOP必须证明自己的专业性，同时避免把健康评分包装成医疗结论，并确保AI建议在证据不足时保持谨慎。 **从LeBron James成为代言人到品牌增长** 节目末尾的快问快答环节提到，NBA球星LeBron James成为WHOOP品牌大使。这一合作不仅体现WHOOP在运动员和高性能人群中的影响力，也标志着公司正从专业恢复设备进一步走向更广泛的主流健康市场。运动员能够为品牌提供可信的使用场景和榜样效应，而WHOOP的数据资产则帮助其证明长期训练管理与科学恢复的价值。 不过，从精英运动员向大众消费者扩张，并不能只依靠明星效应。500美元左右的硬件门槛、持续订阅成本以及复杂数据的学习成本，仍然可能限制用户增长。WHOOP需要通过更清晰的回报展示、更多样的价格方案和真正有帮助的AI服务，让消费者理解：购买设备并非终点，持续使用平台才是获得长期价值的关键。 **总结与核心启示：硬件只是入口，健康关系才是生意** 整期节目呈现了WHOOP从硬件公司走向数据与订阅驱动型健康平台的完整逻辑。约500美元的设备承担获客和传感器入口功能，约500亿小时的24/7健康数据形成难以复制的资产，AI教练、日记洞察和GLP-1追踪则负责把数据转化为个性化行动，最终通过持续订阅建立长期收入和用户关系。 WHOOP面对的真正挑战也不只是技术，而是信任与定位：它必须在FDA监管边界内提供专业建议，在Apple、Garmin、Oura等强敌之间建立清晰差异，并在隐私保护、AI可信度和用户留存上证明自己。节目最重要的启示是，在可穿戴设备行业，单纯卖出一台硬件并不能构成持久壁垒；只有将设备、长期数据、持续反馈和软件服务整合为闭环，才能真正改变用户行为并建立可持续的商业模式。

## 一二线城市为何正在抛弃进口豪车：进口车市场收缩与国产高端新能源突围并行 ### 进口汽车规模连续两个月近乎腰斩 曾经长期受到一二线城市消费者追捧的进口豪车，正在明显失去市场光环。节目引用的最新数据显示，进口汽车进口量已经连续两个月出现接近腰斩的收缩，进口车市场由过去的持续热门转入集体降温阶段。这种变化并非只发生在个别车型或少数品牌，而是覆盖了多个主流进口车类别，反映出进口车整体吸引力正在下降。 在此前的一二线城市中，进口豪车往往凭借品牌影响力、稀缺性、设计质感以及较强的社会认同感，成为高收入消费者的重要选择。尤其在住房条件、购车预算和汽车消费文化较为成熟的城市，拥有一辆BBA、日系高端进口车或超豪华品牌车型，曾是消费升级和身份表达的重要象征。然而，当市场环境与消费者观念发生变化后，这些品牌原有的光环逐渐减弱，进口车需求也随之承压。 ### BBA、日系进口车与超豪华品牌集体遇冷 从节目呈现的市场表现看，进口车降温并非局限于某一个价格区间或单一动力类型。BBA等传统豪华品牌、日系进口车以及超豪华品牌都出现遇冷迹象，意味着消费者对进口豪车的整体购买意愿正在降低。 这一变化说明，品牌知名度和进口身份本身已不足以支撑长期溢价。过去被消费者视为品质、身份与技术象征的进口车型，如今需要接受更充分的市场检验。消费者不再仅仅因为“这是进口车”就愿意支付较高溢价，而是会更加直接地比较价格配置、智能化水平、电动化能力、售后服务与用车成本。对于那些更新速度较慢、配置与价格匹配度不足、电动化进程落后的进口车型而言，需求收缩尤其明显。 ### 传统主力市场跌幅明显，需求向西部资源型城市转移 进口车消费曾经高度集中于北上广深、杭州、成都等一二线及传统汽车消费强市，但最新数据显示，这些城市普遍出现较为明显的进口车跌幅。它们过去拥有更密集的豪车消费人群、更成熟的汽车交易市场，也更容易接受较高的车辆价格，因此曾经是进口车最重要的需求腹地。 节目同时指出，在传统主力市场回落的同时，进口车的市场增量反而转向西部资源型城市。其中，克拉玛依成为节目特别提到的代表性案例：相关进口车数量净增165辆，增幅达到458%。这一数据呈现出与一二线城市截然不同的市场方向，表明进口车需求并未完全消失，而是在不同地区之间发生重新分布。 西部资源型城市往往具有较高的收入水平，资源型产业带来的财富效应使得部分消费者具备较强的豪车购买能力。当一线和强二线城市的进口车需求逐步降温、牌照成本和使用限制等因素继续影响购车决策时，部分高收入群体转而选择购车与出行限制相对较少的城市。与此同时，这些城市的进口车基数相对较低，因此新增车辆更容易形成很高的同比增幅。 ### 进口车降幅与燃油车大盘接近 节目提到，进口车目前的跌幅与燃油车大盘接近。这是一个值得关注的市场信号：进口车需求的快速收缩，并不完全可以用新能源汽车替代进口燃油车来解释。其背后很可能还受到燃油车整体市场走弱、消费更加理性、品牌竞争加剧以及消费者对车辆性价比要求提升等多重因素影响。 换言之，部分原本考虑进口豪华燃油车的消费者，并没有直接转向价格更高或定位相近的国产高端新能源车型，而是选择降低购车预算、延后购车决策，或者转向普通燃油车、新能源车等其他产品。进口车既受到新能源车型的直接替代，也受到整个燃油车市场收缩的拖累，因此整体表现明显承压。 ### 国产替代加速，国产高端新能源车型向上突围 与进口车持续收缩形成鲜明对比的，是国产高端新能源车型不断向上突围。节目将这两种趋势放在一起观察，指出国内汽车产业正在发生结构性变化：消费者对豪华、高端和智能化汽车的追求并未消失，只是实现这些需求的途径正在从进口燃油车转向国产新能源车型。 国产新能源车型能够通过智能座舱、辅助驾驶、电动化体验、配置丰富度以及更具竞争力的价格，满足过去部分进口豪华车所承担的需求。当购车预算有限，但消费者仍希望获得更好的科技配置和用车体验时，国产高端新能源车提供了更符合本土使用场景的选择。与此同时，国内车企持续向上布局，在品牌形象、技术能力和产品矩阵上不断加强，使消费者不再必须通过购买进口品牌来表达对高品质汽车的追求。 因此，进口车与国产高端新能源车之间并非简单的此消彼长。进口车市场的萎缩，恰恰映照出国产高端新能源产品正在获得更强的市场认可。过去“一二线城市偏爱进口豪车”的消费格局，也因此面临重构。 ### 从追求进口身份转向关注产品综合价值 进口豪车降温的深层原因，在于汽车消费逻辑正在从“身份消费”转向“价值消费”。在产品供给更加丰富、选择更加多元的市场中，消费者会更加理性地衡量车辆价格与配置、品牌服务、智能体验、补能便利性和长期使用成本。 这种转变动摇了进口车过去依赖品牌稀缺性和身份象征建立的溢价优势。即便消费者仍然重视品质、设计和驾驶体验，但如果国产高端新能源车型能够在这些维度上提供更优的综合价值，那么“进口”就不再是决定购买的关键理由。 一二线城市消费者购买能力较强、市场竞争更充分，也更早进入消费理性化阶段。进口车在这些城市率先失去光环，说明整个进口车市场必须重新思考产品定位和竞争方式，而不能只依赖传统品牌光环维持高价。 ### 市场不是单向消失，而是需求重新分配 进口车连续两个月近乎腰斩，与克拉玛依进口车净增165辆、增幅458%的现象同时存在，说明当前市场变化更准确的描述是“收缩与重分配”，而不是进口车需求完全消失。 一二线城市及传统主力市场受到的影响更加明显，而西部资源型城市等市场则可能成为新的增长点。不同地区收入结构、汽车消费习惯、政策环境和使用条件不同，导致进口车需求呈现显著分化。对于进口品牌和经销商而言，单纯依赖一二线城市的存量客群已难以支撑增长，需要重新认识下沉市场与区域消费特征。 不过，西部资源型城市出现高增幅，也可能与当地进口车基数较小、阶段性集中交付等因素有关，不能仅凭单一增量案例就判断进口车需求重心已经彻底转移。但这一变化至少表明，进口车市场仍存在结构性机会，只是旧有市场秩序正在被打破。 ### 总结与核心启示：进口车降温倒逼行业重新定价 本期节目的核心逻辑，是进口豪车正在失去一二线城市过去赋予它们的光环。连续两个月进口汽车量接近腰斩，BBA、日系进口车和超豪华品牌集体遇冷，北上广深、杭州、成都等传统主力市场跌幅明显，显示进口车市场面临整体性调整。其原因既包括国产高端新能源车型的替代，也包括燃油车大盘走弱、消费者更加理性和购车成本意识增强。 与此同时，克拉玛依净增165辆、增幅458%的案例，又说明进口车需求并未简单消失，而是在向西部资源型城市等区域重新分配。未来进口车市场能否企稳，不能只看品牌知名度，更要看能否在价格、智能配置、电动化体验、服务和产品更新速度上重新建立竞争优势。 这一轮变化带来的核心启示是：消费者对高品质汽车的追求仍然存在，但实现高品质消费的方式已经改变。进口品牌曾经依靠身份光环和稀缺性获得的溢价将面临挑战，国产高端新能源车型则迎来进一步向上突破的机会。最终决定市场选择的，不再是“是否进口”这一标签，而是产品能否在综合体验和价格价值之间提供更优的答案。

# Alphabet的AI增长与商业化困境：搜索加速、云业务爆发与资本投入压力并存 ## 财报电话会议概览 本期内容基于 Alphabet Investor Relations 发布的 **Alphabet 2026 年第三季度财报电话会议**，原内容更新时间为 2026 年 10 月 28 日。出席管理层包括 CEO **Sundar Pichai**、负责广告业务的 Philipp Schindler、负责 Google Cloud 的 Thomas Kurian，以及负责财务工作的 Anat Ashkenazi。会议围绕 Gemini 模型、搜索与广告、YouTube、Google Cloud，以及人工智能基础设施建设和资本配置展开。 本期最核心的矛盾是：AI 已经在推动产品使用量和搜索查询量快速增长，但这种增长尚未完全转化为同等规模的收入。尤其是 AI Mode 仍处于较低变现水平阶段。管理层因此面临一项关键任务：不仅要继续扩大 AI 能力覆盖，还要找到使用增长、用户体验、广告商业化和长期财务回报之间的平衡。 ## 搜索查询量创下近五年最快增速 Alphabet 管理层在电话会上表示，搜索查询量的同比增速已经达到近五年来最快水平。AI 功能正在改变用户与 Google 搜索互动的方式，过去以关键词输入和传统结果链接为主的搜索行为，正在逐步被更自然、更对话式和多模态的交互方式补充。 这一变化说明，AI 并非只是在传统搜索业务之外创造一个独立入口，而是可能从根本上扩大搜索的使用场景。AI Mode 可以帮助用户处理更复杂的问题，以更长上下文理解需求，并通过生成式答案整合信息。对用户而言，这意味着搜索从“查找网页”进一步转向“获取答案”和“完成任务”；对 Alphabet 而言，则可能带来更多查询频次、更长的用户停留时间，以及全新的广告展示机会。 不过，查询增长并不自动等于收入增长。管理层明确提到，**AI Mode 的变现水平目前仍然较低**。生成式回答减少传统搜索结果和链接展示，可能影响原有广告位；同时，AI 计算成本较高，每一次模型推理都需要大量算力支持。因此，AI 搜索带来的收入能否覆盖新增基础设施与推理成本，是商业化过程中必须解决的现实问题。 ## Gemini成为连接产品与平台的关键 本次讨论中，Gemini 被放在 Alphabet AI 战略的中心位置。它不仅支撑搜索中的 AI Mode，也渗透到 YouTube、Google Cloud 和企业解决方案。管理层传递出的基本思路是，利用 Gemini 推动产品体验升级，再通过庞大的用户基础和企业客户基础形成商业闭环。 搜索业务是 Alphabet 最重要的用户入口，广告业务则是其传统核心利润来源。将生成式 AI 引入搜索，可以在短期内增强产品竞争力、维持用户黏性，并提高查询总量。但这种改造不能只追求功能上的新颖，还必须兼顾广告主价值、答案质量、响应速度以及单位查询成本。 管理层还提到会逐步把 AI agent 和新的广告体验带给更多用户。这意味着 AI 商业化并非一次性全面切换，而更像分阶段推进的过程：先验证产品体验，再扩大用户覆盖，同时测试新的广告形式和收费方式。这样的渐进策略有助于降低大规模上线所带来的体验与收入风险。 ## 广告业务需要适应新的搜索入口 Philipp Schindler 参与了有关搜索与广告的讨论。随着 AI Mode 改变搜索结果的组织方式，广告系统也必须随之调整。传统搜索广告通常依赖关键词、查询意图和结果页面上的链接展示，而生成式搜索更强调直接回答、复杂上下文和连续对话，因此广告需要以更贴合 AI 交互方式的形式出现。 新的广告体验可能要求系统在理解完整对话意图的基础上，在适当位置提供相关商业信息。这意味着广告不再只是页面上的独立模块，而可能成为 AI 回答的一部分。对广告主而言，这种模式有机会提升意图匹配和转化效率；对用户而言，如果广告与问题高度相关，也可能比传统展示更具价值。 但 AI 搜索商业化仍处于早期阶段。其难点包括：广告与自然答案之间如何保持清晰区分；AI 回答是否会影响传统广告点击；高计算成本能否被新增广告收入覆盖；以及用户是否会因交互更自然而形成更高的长期留存。管理层强调逐步推广 AI agent 和广告体验，反映出平台需要在规模扩张与商业可持续性之间保持谨慎。 ## YouTube与多模态AI生态 Alphabet 的 AI 战略并不局限于搜索。YouTube 是 Alphabet 生态中的重要视频平台，也是 Gemini 能力落地和产生用户价值的重要场景。多模态模型可以理解视频内容、语音、图像与文字，从而支持内容发现、创作辅助、字幕与翻译，以及更自然的搜索和推荐。 将 AI 融入 YouTube，能够进一步增强平台的内容供给和消费效率。对创作者而言，AI 工具可以降低制作门槛、改善内容分发；对用户而言，更精准的推荐和跨语言理解有助于扩大可访问内容。视频本身拥有较长的观看时长，也为 AI 驱动的推荐、商业化和服务优化提供了较大空间。 从整体生态看，搜索负责承接用户意图，YouTube 负责内容消费和广告触达，Gemini 则提供统一的底层模型能力。三者相互配合，使 Alphabet 能够把 AI 从单点产品升级为跨平台基础设施。真正的考验仍是这些能力能否形成可持续收入，而不是仅仅增加功能和使用时长。 ## Google Cloud营收翻倍，AI基础设施成为主要驱动力 Thomas Kurian 介绍，Google Cloud 第三季度营收同比增长 **103%**，人工智能基础设施和解决方案是主要驱动力。这一增速显示企业对 AI 算力、模型服务和端到端解决方案的需求正在快速上升。 Alphabet 的竞争优势在于同时拥有 TPU、训练和推理能力、Gemini 模型、数据中心以及企业服务平台。企业客户不仅购买底层算力，也可能采购模型 API、机器学习平台、智能代理和行业解决方案。随着 AI 应用从试验阶段进入生产环境，客户的支出重点正从简单获取 GPU 算力，转向可以融入业务流程的完整平台。 Google Cloud 的高速增长也说明，Alphabet 正在从传统云服务商进一步转向 AI 基础设施与模型服务平台。对外部客户销售 TPU 系统，既扩大了收入来源，也提高了自有 AI 业务对基础设施资产的经济利用率。不过，硬件系统销售与普通云服务在收入确认方式上存在差异，这也是管理层重点解释的问题之一。 ## TPU系统销售与收入确认 管理层特别解释了 TPU 系统的销售如何确认收入。其核心意义在于，Alphabet 不仅在内部使用自研 TPU 支撑 Gemini 和 Google Cloud，也开始将其作为面向客户的产品出售。客户购买完整的 TPU 系统后，相关收入会按照硬件销售的方式进行确认。 这种业务模式有助于 Alphabet 分享 AI 加速器市场的增长红利，但与按量计费的云服务相比，硬件收入通常具有更明显的交付节点，收入表现可能因此更集中。与此同时，服务器、芯片、网络设备及相关库存需要提前采购和部署，会增加资本占用。Alphabet 必须判断客户需求是否具有持续性，避免在快速扩张周期中出现产能利用不足或库存压力。 ## 算力扩张推高资本开支和库存压力 AI 需求增长带来了显著的基础设施投入压力。Alphabet 需要建设数据中心、扩充服务器与网络容量、采购芯片并增加库存，以满足模型训练和推理、Cloud 客户需求以及内部产品使用。管理层在强调增长机会的同时，也明确指出资本开支和库存正在对自由现金流形成压力。 自由现金流承压并不意味着 AI 投资失去回报，而是说明这类投入通常先于收入发生。数据中心和 TPU 系统需要提前建设，客户合同与模型使用收入则可能随后逐步确认。如果需求保持强劲，当前的资本投入未来有望转化为更大的云收入和更低的单位推理成本；但如果技术迭代过快、客户需求变化或产能扩张过快，也可能造成资产折旧、库存积压和投资回报下降。 因此，管理层在 AI 投入上不仅关注“能增长多少”，也必须持续评估基础设施利用率、交付节奏、客户合同质量、库存周转和现金回收周期。AI 业务的财务评价不能只看收入增速，还要看资本密度与长期盈利能力。 ## 总结：Alphabet的AI战略进入规模化验证阶段 本期电话会释放出一条清晰主线：Alphabet 正利用 Gemini 全面重塑搜索、YouTube、Cloud 和广告业务。搜索查询量同比增速创下近五年最快水平，证明 AI 已有效扩大用户需求；Google Cloud 营收增长 103%，表明 AI 基础设施与企业解决方案正在形成强劲商业需求。 与此同时，AI Mode 变现偏低、算力成本上升、资本开支扩大以及库存压力上升，意味着增长质量仍需验证。Alphabet 的关键任务不是在“是否投入 AI”之间二选一，而是在速度、成本和回报之间建立可持续的平衡。 **核心启示**是：AI 带来的使用增长只是商业化的起点。搜索查询量增加，不等于广告收入等比例增长；云业务高速增长，也不代表自由现金流不会承压。真正决定 Alphabet 长期价值的，是其能否把 Gemini 的产品优势转化为高质量广告、可持续 Cloud 收入和可接受的单位算力成本，并通过 TPU、数据中心及逐步上线的 AI agent 与广告体验，把一次性技术投入变成长期、可扩展的商业回报。

## 芯片人才市场的冰火两重天：高薪急缺与高门槛入行并存 **一、芯片行业招聘市场出现明显分化** 芯片行业正在经历一种结构性的招聘矛盾：一边是AI芯片架构师、先进封装等紧缺人才被企业以高达百万元的年薪争抢，往往“一将难求”；另一边，微电子、集成电路专业的应届生却面临激烈的求职竞争，发现传统意义上的“入行门槛”越来越高。岗位需求仍在增加，行业平均薪酬也继续上涨，但这些宏观利好并没有均匀地传递给每一位求职者。人才短缺与求职困难同时存在，正是当前芯片人才市场最突出的特征。 **二、百万年薪难求AI芯片架构师** 节目首先聚焦年薪可达百万元的AI芯片架构师岗位。随着人工智能产业快速发展，芯片企业需要大量既懂芯片架构设计、又理解AI模型与算力需求的复合型人才。这类岗位不仅要求候选人具备扎实的微电子和计算机体系结构知识，还需要理解算法、算子、存储、带宽和能耗之间的复杂关系，普通的单一专业背景很难满足需求。 由于高端人才数量有限，而头部芯片公司、AI企业以及算力基础设施企业都在加速布局，顶尖架构师自然成为竞争最激烈的岗位。百万年薪不仅是对个人技术能力的定价，也反映了企业争夺关键技术骨干的迫切程度。 **三、数字后端工程师需求增速领先** 在各类芯片人才需求中，数字后端工程师的同比增幅位居第一。数字后端设计涉及芯片从逻辑设计到物理实现的转化，需要完成布局规划、时序收敛、功耗控制、信号完整性处理以及复杂工艺下的设计验证等工作。随着芯片制程复杂度提升、芯片设计规模扩大，企业对后端工程师的需求增长尤为明显。 这一现象说明，人才短缺并不只集中在“芯片架构师”这一类明星岗位。贯穿研发流程的关键工程岗位同样严重缺人。尤其是具备先进制程经验、能够处理高复杂度设计问题的人才，其议价能力和职业发展空间都在提高。 **四、岗位与薪酬增长背后的结构性错配** 从整体数据来看，芯片行业新发职位仍在增长，平均薪酬也继续上行，但求职端的体感却可能截然不同。职位增长并不意味着所有专业、所有学历层次和所有经验阶段的求职者都更容易找到工作；薪酬上涨也主要集中于高技能、高经验或高度紧缺人才。 行业的真实矛盾可以概括为“总量扩张”与“结构错配”同时发生。企业需要的是能够直接承担核心研发任务、适应新技术路线并解决复杂工程问题的人才，而大量应届生虽然完成了相关专业学习，却缺少能够证明其工程能力的实践经历。当企业更看重项目经验、量产经验和跨学科能力时，校园与产业之间的人才培养断层便会进一步显现。 **五、芯片专业并非毕业就能轻松入行** 节目指出，芯片行业“没那么容易入行”。微电子、集成电路等看似与芯片产业直接相关的专业，并不意味着毕业生一毕业就能获得理想岗位。芯片研发是一条流程长、协作链条复杂的产业链，不同岗位对知识结构与实践能力的要求差异很大。 相比通用岗位，芯片行业往往更加重视学历背景、核心课程基础、项目经历以及实习经历。求职者不仅需要掌握书本中的原理，还要熟悉EDA工具、行业流程和真实的工程约束。即使企业的招聘职位数量增加，岗位质量与人才要求也可能同步提高，这使得刚进入市场的应届生感受到更强的竞争压力。 **六、相关人才缺口最高可达30万** 节目提到，芯片相关人才缺口高达30万。这个数字反映出行业扩张与人才供给之间存在显著缺口，尤其在高端设计、先进制程、封装测试、芯片架构等关键环节。高薪急聘正是为了弥补这种数量和结构上的不足。 不过，人才缺口不能简单理解为“所有芯片专业毕业生都会被抢走”。企业真正需要的是符合具体岗位标准的人才，而市场中的供需错配较为严重：部分人才供不应求，另一部分求职者虽然拥有相关学历，却缺少与岗位匹配的专业技能和项目经验。因此，行业缺人并不等于个人只要相关专业就能轻松入行。 **七、企业竞争焦点从“抢人”转向“育人”** 面对持续的人才短缺，企业正在探索一条成本更高、周期更长的解决路径：从直接“抢人”转向“育人”。通过校企合作、联合培养、实习项目和内部培训体系，企业希望提前接触并识别潜在人才，再将其培养为能够适配自身技术与业务需求的专业人才。 “抢人”主要争夺已经成熟、能够立即上手的稀缺人才，但这种方式不仅推高薪酬，也难以从根本上扩大人才供给。相比之下，“育人”强调长期能力建设和人才梯队培养，有助于降低企业对外部高端人才的过度依赖。不过，这一转变也要求企业投入更多教学资源，并缩短从校园培养到产业岗位之间的距离。 **八、教育体系与产业需求需要进一步衔接** 芯片人才矛盾的背后，也暴露出人才培养周期与产业技术迭代速度之间的不匹配。芯片研发涉及电子信息、计算机、自动化、数学、材料和工艺等多个学科，但高校培养体系往往仍以课程和论文为主，学生接触先进制程、真实项目及量产流程的机会有限。 企业需要更多既理解底层硬件，又具备数字设计与验证能力的人才；高校则需要根据产业变化调整课程内容和实践教学。学生如果能够在学习阶段接触EDA工具、完成完整芯片项目或参与企业实习，将更有机会跨越从“掌握知识”到“能够胜任岗位”的门槛。 **总结与核心启示** 芯片人才市场正处于“需求旺盛、收入上涨，但分化加剧”的阶段。AI芯片架构师、先进封装人才以及数字后端工程师等关键岗位的薪酬和需求快速增长，反映出芯片产业对高端、复合型及工程实践型人才的强烈依赖；与此同时，相关人才缺口高达30万，也说明整个行业仍面临持续的人才供给压力。 这期内容的核心启示是：行业平均数据不能完全代表个人的就业体验，职位增长也不等于入行难度下降。芯片行业并不缺少受过专业教育的人，真正稀缺的是能够满足企业研发标准、具备项目经验并适应技术演进的人才。对企业而言，仅靠高薪挖人无法解决长期问题，人才培养和校企协同才是扩大供给的关键；对高校和学生而言，掌握完整流程、提升工程能力并积累真实项目经验，才是跨越求职门槛、进入芯片产业并获得职业发展的有效路径。

## 人口下降并非单纯“少生”问题：黄文政谈中国人口趋势、责任分担与养育保障 **核心判断：人口问题重要，而且可以解决** 黄文政在长篇对谈中反复强调两个基本判断：第一，中国当前的人口变化是一个极其重要的问题；第二，人口问题并非无解，关键在于能否准确识别问题的性质，并用合适的制度回应。人口下降不应被简单理解为年轻人“不愿意生孩子”，也不应被处理成对个人的道德催促。真正需要改变的，是养育成本与家庭责任之间的错位关系。 **2025年出生人口降至792万，创百年新低** 节目以2025年中国出生人口792万作为切入点。根据现有统计，这一数字不仅是近年来出生人口持续下降的集中体现，而且构成了1895年以来一百多年间的最低点。黄文政以1953年全国人口普查数据为基础，对1895年以来的长期人口变化进行回溯和重构，试图把人口趋势放回更长的历史周期中观察。 从百年尺度看，2025年的出生人口大约只有清末民初时期的一半。这样的对比说明，人口变化并不只是近几年出现的短期波动，而是具有长期性、结构性和历史累积效应。把今天的出生人口放到百年坐标中，能够更清楚地看到其下降的严重程度，也能避免只用某一年或某几个年度的数据得出过于偶然的结论。 **人口减少不等于生活会自动变得更轻松** 作为长期研究人口趋势的学者，黄文政不厌其烦地列举人口数据，是为了让听众理解一个经常被忽略的事实：人口减少并不意味着资源竞争必然减弱，也不意味着每个人的生活会因此更加轻松。 人口规模及其年龄结构的变化，会通过就业、养老、医疗、照护、消费、区域发展和公共服务等渠道传导到社会运行之中。尤其是在老龄化程度上升的背景下，如果劳动年龄人口减少，而养老、医疗和长期照护的制度安排没有同步调整，社会承担的养老成本可能进一步集中到数量更少的年轻劳动者身上。因此，人口的减少既可能带来某些资源压力的缓解，也可能制造新的财政、家庭和代际负担，不能仅凭“人口少了”就推断生活必然改善。 **黄文政的长期人口研究路径** 黄文政是育娲人口智库执行长兼首席研究员，同时担任中国与全球化中心特邀高级研究员、深圳综合研究院特聘工程专家。他长期关注人口问题，曾联合创办“人口与未来”网站，并与梁建章合作撰写多部著作及两百余篇文章，研究人口趋势与自然资源、环境、经济发展、科技进步、社会结构和文化活力之间的复杂关系。 这种跨学科视野构成其分析框架的基础：人口并非孤立变量。人口变化会重塑经济结构、养老体系、社会活力与资源环境之间的平衡；反过来，住房、就业、收入、教育、医疗和育儿成本，也会影响家庭的生育选择。节目由果壳主笔游识猷担任主播，围绕人口数据、人口政策及不同国家的生育激励实践展开讨论，时间轴在05:25处进入新加坡生育金内容。 **不应把责任全部压给年轻人** 黄文政明确表示，自己并不是来“催生”的。在他看来，生育意愿下降有其现实基础：年轻人在住房、就业、收入和养育成本等方面已经承受较大压力，如果政策仍停留在鼓励生育的口号层面，只是要求个人多生孩子，就等于把本应由社会共同承担的养育责任重新推回家庭。 尤其值得注意的是，现实中的养育具有明显的外部性。孩子出生后的成长、健康和教育不仅给家庭带来支出与时间成本，也会形成未来社会的劳动力、公共服务贡献和人力资本。因此，生育决策不能被完全视为家庭的私人选择。一个孩子所获得的养育投入，既来自父母，也受益于更广泛的社会。人口政策的重点不应是责备个体，而是重新认识社会在养育支持中的责任。 **建立类似养老金的“养育金”制度** 黄文政提出的核心制度设想，是建立一套能够像养老金一样带来体面收入的养育金。养老金回应的是老年阶段的收入保障，养育金则试图回应儿童阶段的养育责任，使养育者不必完全依靠个人储蓄、压缩生活品质或牺牲职业发展来承担全部成本。 这一思路的关键，在于让养育支持从一次性补贴、短期优惠或附加福利，转变为稳定、具有长期性并能切实改善家庭现金流的社会保障机制。所谓“体面收入”，意味着养育支持不能只是象征性的补贴，而应当具有足够的持续性和可预期性，帮助家庭覆盖育儿的基本开支，降低因生育而导致的收入损失和风险。 **资金来源：出口退税与长期国债** 在资金安排方面，黄文政提出，养育金可以来自出口退税与长期国债。这一方案反映出他对人口与长期财政能力之间关系的关注：出口退税能够释放一部分经济活动的财政空间，长期国债则可以把未来的财政资源用于当前具有长期收益的社会投入。 从制度逻辑看，养育投入具有明显的长期回报。今天为儿童养育提供保障，最终受益的是未来的劳动者、纳税人和纳税人；今天减少家庭因生育和养老双重压力而承受的负担，也有助于缓解未来的代际矛盾。因此，使用长期资金工具支持养育，并不只是扩大福利支出，也是在为经济社会的长期稳定和人力资源的持续再生进行投资。 **配套“全民起点收入”以托住家庭底线** 除了养育金，黄文政还强调要配套一套“全民起点收入”。这一概念强调为社会成员设置普遍的收入底线，使每个人都拥有相对稳定的基础生活保障，而不必仅靠市场竞争中的个人能力或偶然获得的机会维持生存。 “起点收入”与养育金发挥的作用不同：养育金主要针对养育责任提供补偿和支持；全民起点收入则从更普遍的收入分配层面托住社会底线。前者解除家庭在养育孩子时的后顾之忧，后者减少个体在就业、失业、疾病、照护等情境中的基本生活风险。二者结合，才能形成从收入保障到家庭支持的完整政策链条。 **从“催生”转向“分担责任”** 整期内容的政策立场可以概括为一句话：不要催已经承受巨大压力的年轻人，而要通过制度安排分担家庭责任。人口政策的目标不应只是追求某个出生人口数字，而应改善养育环境、提高家庭安全感，并让社会的收益与成本承担更加公平。 这一思路也表明，提高生育率不能只依靠宣传、道德动员或短期奖励。真正有效的制度需要具备稳定性、普遍性和持续性，使家庭在面对住房、就业、教育、医疗及养老压力时拥有更多选择。人口问题之所以“一定解决得了”，并不是因为个人意愿可以被轻易改变，而是因为社会仍有能力重新配置资源、优化制度，并承担起本应共同承担的养育责任。 **总结与核心启示** 这期播客以2025年出生人口792万这一百年低点为起点，通过回推1895年以来的人口轨迹，呈现中国人口长期下降的严峻程度。黄文政的核心观点是：人口减少不会自动带来更轻松的生活，人口问题重要，但可以通过制度加以应对。 其政策主张超越了简单鼓励生育的层面，重点在于承认养育活动的社会外部性，建立类似养老金、能够带来体面收入的养育金，并以出口退税和长期国债提供资金支持，同时配套全民起点收入，夯实家庭和个人的基本保障。播客最核心的启示是：解决人口问题不能只要求家庭“生”，更要由社会承担合理的养育成本、托住居民收入底线，并通过长期、稳定的制度安排，让人口发展与家庭幸福、经济可持续及代际公平形成良性循环。

# 加州亿万富翁税与富豪“跑路”困境：快照规则能否堵住财富避税漏洞 **加州富豪迁出潮背后的财富税争议** 2026年的美国加州，并没有被野火烟霾完全占据舆论中心，真正引发关注的是另一种“气息”——财富的流动。硅谷多名科技巨富和富豪家庭陆续搬离加州，围绕“富豪出逃”的讨论持续发酵。在外界看来，加州高昂的税收成本、严格的企业监管以及不断变化的政策环境，正在推动高净值人群向佛罗里达、得州等地区迁移。 面对富豪迁出，加州方面提出了亿万富翁税法案。这项制度最值得关注的设计，是通过“快照日”锁定纳税人的居民身份。换句话说，一个人可以在特定日期之后搬离加州，但财富产生的税务账单未必能够随着搬家被一并取消。由此提出的核心问题是：富豪究竟能不能借迁居彻底实现“跑路”？这套机制究竟是史上最严格、最有效的防避税措施，还是一项充满争议、并可能带来复杂后果的财富实验？第一财经邀请中国民航大学经管学院教授励贺林，对相关规则及其影响进行拆解。 **亿万富翁税究竟是什么** 亿万富翁税，顾名思义，主要针对拥有极高财富的个人征收，重点涉及能够影响州内财政和公共资源分配的高净值群体。与普通所得税侧重工资、薪金和经营收入不同，财富税更直接地关注个人已经积累的资产，因此也被视为对富豪财富存量进行征税的工具。 加州提出这项法案，与富豪持续外迁的背景密切相关。富豪迁出不仅会引发关于个人选择权的讨论，还可能让州政府担忧税基流失、财政收入下降以及财富集中度加剧。因此，加州需要寻找一种既能增加财政收入，又能提高大型财富在本州留存的制度工具。 不过，“向亿万富翁征税”并不只是提高某一税率。真正困难的是确定谁在加州属于纳税人、哪些财富应当被计入税基，以及居民离开后是否还需要承担已经形成的纳税义务。快照日规则正是为了回应这些治理难题。 **5%的税率为何带来超过5%的痛感** 法案提出的税率是5%。单看数字，5%似乎并不是一个极端税率，但节目强调，“5%的税，不止5%的痛”。这意味着，财富税的实际影响不能只根据名义税率衡量，还需要考虑财富规模、资产估值、流动性、持有成本以及适用对象等多重因素。 对于资产规模达到数十亿乃至上百亿美元的人来说，即使税基计算方式、征收范围或实施节奏仍存在讨论，5%对应的绝对金额也可能非常可观。巨额财富还往往集中于股票、股权、不动产、企业权益等流动性较弱的资产，纳税人在出售资产、融资或者缴纳相关税费时，可能面临较高的执行压力。 更重要的是，财富税可能被认为具有“乘数效应”。如果富人为降低税负而出售股份、转让企业或改变资产持有方式，其行为可能进一步影响资本市场、创业融资和企业治理。富豪感受到的，因而不只是5%的直接成本，还可能包括资产结构调整成本、财富流动性下降以及个人决策自由度受到约束。 **想走可以，但并不是立刻就能走** 快照日机制构成了防止富豪快速避税的关键约束。其基本逻辑是：在法定的特定日期，根据个人在加州的居民身份和财富状况确定纳税资格或税基。居民可以在快照日之后迁往其他州，但仅凭搬家这一行为，通常无法自动消除此前已经确定的加州纳税义务。 这一设计直接针对了传统税收规则中的迁移漏洞。过去，部分高收入或高净值人群可能通过改变居住地、调整公司注册地或者转移资产所在地来降低税负。如果各地只关注个人当前居住地，那么财富拥有者就可能获得较强的地理套利空间，在不同州之间进行成本比较后选择最有利地区。 快照日规则意味着，加州不仅关心富豪现在住在哪里，也会追踪其在关键时点的身份和财富状态。它试图把税收关系从“持续居住行为”进一步延伸到“特定时点的财富归属”，从而提高富豪通过临时迁居规避税负的难度。 **跑不了的终究是钱** 节目用“跑不了的，终究是钱”概括了财富与地理迁移之间的关系。人可以离开加州，账户和资产也可以在其他州持有，但财富的经济属性并不会因为一次搬家就消失。只要某笔财富在加州法律认定的纳税时点与纳税人身份、收入来源或资产联系相关，相应的税务责任就可能继续存在。 这也揭示了为什么财富税比单纯的工资税更难以通过迁居来规避。工资通常与劳动地点和实际工作安排密切相关，而财富的来源更加多元：一项股权可能来自加州的创业公司，一处房产位于加州，一项投资收益也可能与当地市场或产业环境有关。个人改变居住地，并不必然切断财富与原辖区之间的全部联系。 因此，快照日不是简单地把人“钉”在加州，而是试图把纳税义务锁定在财富形成的特定节点。富豪当然仍可以出售资产、重新配置组合或者把家庭成员迁往低税地区，但这些行为可能需要承担成本，也未必能够完全达到“零税务后果”的目的。 **要看富豪究竟“跑得多彻底”** 富豪能否真正避开加州税负，取决于其迁移安排的彻底程度。如果只是把个人登记地址搬到佛罗里达或得州，而核心公司、董事会职位、房产、投资关系和主要经济利益仍与加州紧密相连，那么在快照规则下，其避税效果可能十分有限。 相反，如果富豪进行的是系统性的整体迁移，包括改变家庭成员的实际居住安排、转移企业和核心资产、调整管理层与经营地点，并重新配置长期投资组合，那么其与加州的联系就可能被显著削弱。当然，这种彻底迁移本身也可能非常昂贵，且会牵涉资产出售折价、公司治理变化、投资收益损失以及生活网络重建等复杂问题。 由此，快照日规则并不是一道绝对无法突破的防线，而更像是一道提高规避成本的“门槛”。它无法完全消除跨州税务筹划，但可以削弱富豪通过短期、低成本搬家就迅速实现避税的可能性。对于政策制定者而言，真正有效的制度不能只依赖口号，还必须具备清晰的身份认定标准、财富估值方法、跨州协作机制和可执行的法律程序。 **总结与核心启示** 这场讨论的核心并不只是加州能否向亿万富翁多征5%的财富税，而是税收辖区如何在新财源、资本流动和个人选择权之间寻找平衡。加州富豪外迁表明，高净值人群对税负和营商环境高度敏感；快照日规则则表明，仅凭改变居住地址，已经越来越难摆脱财富所在地所对应的纳税责任。 其核心启示有三点：第一，财富税的争议不能只看名义税率，还要看税基范围、估值方式、资产流动性和征管能力；第二，防止富豪避税不能只关注人是否搬走，还要追踪财富、企业和利益关系是否随之转移；第三，任何制度都会产生成本，快照机制虽然提高了短期迁移的避税成本，但实施过程中仍需要解决跨州认定、税务公平和资产估值等难题。 富豪可以“走”，但财富很难被真正“甩掉”。加州亿万富翁税实验最终要回答的，不只是谁能留下，更是税收政策应如何留住税基，同时仍允许资本、劳动者和企业家作出合理的流动选择。

Moses对人工智能产业及其融资模式的再评估。作为曾在FrontPoint从事做空交易、并亲历次贷危机的组合，两人并不否认AI已经成为真实且重要的产业趋势，但他们认为，产业趋势的真实性并不意味着参与其中的每一项投资都能获得回报。本期讨论的重点因此不是“AI是否值得投资”，而是“支撑AI扩张的资金从哪里来、风险最终由谁承担，以及繁荣能否转化为可持续的盈利和现金回报”。 Danny Moses是Steve Eisman当年的做空搭档，也是《On The Tape》播客主持人。长期关注金融市场、私募信贷和AI融资之后，他更倾向于从资本结构、证券化链条和资产负债表的角度审视问题。对他们而言，AI热潮与次贷危机之间存在值得警惕的结构性相似：两者都依靠大规模资金推动，并通过贷款、债务和证券化工具进一步放大市场影响。 **AI产业趋势真实，但投资回报不会自动实现** 节目首先明确了一个重要区分：AI的技术进步和商业价值是真实的，产业也可能持续增长，但前沿科技受到资本追捧，并不代表所有投资者都能分享增长成果。技术成功、企业价值提升与二级市场投资回报之间，还隔着估值、融资成本、资本开支、竞争格局和最终盈利能力等多重变量。 这意味着，即使AI确实改变计算、模型、软件和生产力，资本市场仍可能出现局部甚至整体性的高估。特别是当大量资金仅因为“AI”这一标签而涌入时，资本价格可能远远领先于企业实际创造现金流的速度。节目由此把讨论重点从产业叙事转向回报兑现：投资者最终需要的不是更多宏大愿景，而是企业能否覆盖巨额投入、产生稳定利润，并把利润合理地回馈给股东。 **华尔街资金、贷款与证券化：AI扩张背后的复制链条** Eisman和Moses最关注的，是AI基础设施扩张背后的融资机制。其观察模式可以概括为一条清晰链条：华尔街首先提供资金，AI公司或相关项目借此进行大规模投入；随后，部分资金以贷款形式存在，并被进一步打包成证券化产品出售给投资者。 他们之所以联想到当年的房贷生意，是因为次贷危机前同样存在广泛而复杂的资金链条。大量贷款经过打包、评级和分销后进入全球金融市场，风险不再只停留在原始贷款人手中，而是通过证券化被传递给更广泛的投资者。原始资产的瑕疵，也因此可能在杠杆、评级和流动性机制中被持续放大。 今天的AI融资虽然涉及的数据中心、芯片和基础设施不同于住房贷款，但“资金推动需求—债务扩张—资产证券化—风险向市场扩散”的基本逻辑具有相似性。两人真正警惕的并不是AI公司会不会失败这一单一问题，而是融资链条是否会在追逐回报的过程中，把原本集中于少数项目中的风险扩散到更大范围的投资者和金融体系中。 **巨额资本开支与盈利难题构成核心矛盾** AI产业要实现真正的大规模应用，需要大量资金投入服务器、GPU、数据中心、电力、网络及相关基础设施。节目指出，AI公司当前面临的关键难题，是巨额投入与实际盈利之间存在明显的时间差，甚至尚未证明最终能够形成足够高的回报率。 在传统互联网业务中，企业往往可以先建设较轻资产的软件平台，再通过用户增长和收费模式逐步扩大利润；AI基础设施的成本结构则更重，需要提前采购昂贵硬件、建设机房并锁定长期能源与算力资源。模型能力不断进步，也不必然意味着所有承担成本的企业都能获得相应收入。 因此，AI投资是否健康，最终要回到资本回报率这一基本问题：如果基础设施投入持续上升，而使用这些设施产生的收入、利润和自由现金流增长不足，那么估值就会面临压力。Eisman和Moses的做空视角，正是试图判断哪些企业的增长依赖外部融资，哪些企业能够在投入高峰之后真正形成自我造血能力。 **英伟达客户集中：产业繁荣中的供应链风险** 节目还谈到英伟达所处的特殊位置及其客户集中风险。作为AI算力扩张的核心受益者，英伟达的重要客户集中在少数大型科技企业和云服务商手中，这种结构为整个产业链带来了一重集中度风险。 客户集中并不必然意味着经营恶化，但它会放大连锁反应。一旦少数大型客户放缓资本开支、调整基础设施计划，或因融资环境变化而延后采购，影响就可能迅速沿供应链向上游硬件、网络、电力和数据中心项目传导。英伟达自身可能拥有较强的产品力和技术优势，但客户集中意味着其增长在很大程度上依赖少数企业的投资意愿具有持续性。 从更广泛的市场角度看，这种集中还会加深AI产业繁荣与金融条件之间的联系。企业越倾向于依赖债务和持续融资购买算力，利率上升、信用收紧或资本市场波动就越可能影响AI投资节奏。市场可能把“AI长期需求”与“短期资本开支不会下降”混为一谈，而Eisman和Moses显然更关注这两者之间随时可能断裂的连接。 **私募股权退出变慢与私募信贷走向散户** 讨论随后从科技产业延伸至私募市场。两人指出，私募股权的变现正在变得越来越慢。过去，私募投资通常依靠企业上市、并购或后续股权转让实现退出，但当前环境下，IPO节奏放缓、并购估值趋于谨慎，使资金在私人企业中的停留时间延长。 退出渠道受阻，会同时带来两方面压力。一方面，私募基金需要更长时间才能把投资收益兑现给有限合伙人；另一方面，早期进入的资本无法顺利退出，就可能减少对新增项目的投资意愿。如果此前依靠持续募集新资金、同时以较高价格退出来维持增长的管理人失去退出动力，整个市场的资金循环就会明显放缓。 与此同时，私募信贷开始更多地向散户开放。过去主要面向专业投资者、保险公司和大型机构的产品，正通过财富管理平台、线上渠道和零售化基金触达普通投资者。节目把这一点视为需要警惕的趋势：复杂信贷产品的购买者范围越大，市场参与者对其风险的理解和承受能力差异也越大。 私募资产通常期限较长、流动性较低，一旦发生估值滞后或信用损失，投资者可能无法及时退出。私募信贷向零售端扩张后，原本相对封闭、专业化的风险，就可能进入更多缺乏复杂风险定价经验的普通投资者组合。 **美国债务、赤字与全球储备货币地位** 在宏观层面，Eisman和Moses将美国债务和财政赤字问题置于美元全球储备货币地位的背景下审视。美元的特殊地位为美国提供了筹集美元资金的重要条件，但同时也意味着金融体系中的压力可能通过全球美元融资和储备资产需求向其他市场传导。 Danniel Moses认为，量化宽松还会回来。其逻辑在于，当经济走弱、信贷市场承压或金融市场出现流动性冲击时，政策制定者仍可能再次使用扩张性货币工具稳定市场。量化宽松有利于缓解融资压力，也可能推动资金重新寻找收益，进而再次进入股票、信用债、私募资产以及AI相关投资。 但如果宽松政策同时伴随着财政赤字扩张和债务持续上升，其影响就不只是短期的利率下降。资金价格可能长期维持低位，追逐收益的资金规模可能继续扩大，而资产价格则可能提前反映未来的宽松预期。这样一来，AI等热门领域最容易成为流动性与杠杆共同推动的估值放大器。 **做空思维：先问风险由谁承担** Steve Eisman在次贷危机中的经历，使“Big Short”不仅是一种交易策略，也成为分析金融繁荣的方法：不要只问上涨逻辑是否成立，还要寻找结构中最脆弱的环节，并判断损失最终会由原借款人、贷款机构、证券持有人，还是更下游的投资者承担。 这一方法应用到AI融资时，重点并不是简单预测AI泡沫何时破裂，而是识别资金链条中的期限错配、杠杆、估值依赖和风险转移。如果支撑产业扩张的融资主要依赖持续增长的信贷、可证券化资产和宽松的流动性，那么资产价格与真实盈利能力之间的差距，就可能在市场压力出现时迅速暴露。 **总结与核心启示** 本期的核心结论是：AI趋势是真的，但这轮投资不会人人获胜。真正决定回报的，不是AI概念是否热门，而是企业能否用足够收入覆盖巨额资本开支，融资链条能否在利率与流动性变化中承受压力，以及风险是否已经被打包传递给更广泛、流动性更弱的投资者。 Eisman与Moses通过比较AI融资和次贷危机，提醒市场关注几个相互关联的问题：巨额基础设施投入何时转化为利润；少数大型客户的资本开支是否具有可持续性；私募股权退出放慢后，私募信贷向散户扩散会不会放大风险；以及美国债务、赤字与未来量化宽松将如何共同影响资产估值。 最终的投资启示是，应同时审视产业前景与资本结构。既不能因为AI具有真实革命性，就忽略价格、融资和盈利层面的风险；也不能因为局部存在泡沫，就否认技术进步和产业增长。更有价值的做法，是沿着资金来源、杠杆水平、证券化结构、退出路径和最终受益者逐层追踪，区分“真实的商业需求”与“被金融条件放大的资产需求”，从而在产业长期向上的同时，避免成为承担错误定价和隐性风险的一方。

## 宏观经济分化加剧：出口超预期背后的三重因素，欧洲财政困局与AI融资风险同步升温 **出口超预期：低基数、台风扰动与政策因素共同推高增速** 三季度经济数据成为过去一周宏观讨论的核心，其中9月国内出口增速达到36%，明显超出市场预期。出口端的强劲表现，并不完全意味着外需出现了持续、系统性的改善，更多是多重短期因素叠加后的结果。首先，去年同期基数相对较低，为同比增速提供了支撑。其次，今年9月台风活动频繁，台风天数创近十年新高，恶劣天气导致上月港口作业受到明显扰停，部分货物和物流节奏被推迟。本月港口运行恢复后，积压订单集中释放，从而形成明显的环比修复。 此外，退税政策以及企业“抢出口”的行为，也对当月出口形成支撑。由此可见，36%的出口增速既包含真实贸易韧性，也受到低基数、天气冲击后修复、政策节奏和企业提前出货的共同影响。因此，判断后续出口趋势时，不能简单将单月高增长线性外推，还需观察台风影响消退后，港口运行、订单交付和企业抢出口行为能否形成新的常态。 **消费回暖并不均衡：补贴退坡与长假错位制造结构分化** 三季度消费总体呈现回暖态势，但这一回升背后存在明显的结构性分化。补贴政策退坡意味着，过去依靠财政激励得到显著拉动的商品与服务，其增长动能正在减弱。与此同时，长假时间安排与消费旺季发生错位，也会改变居民在餐饮、旅游、零售等不同场景下的支出节奏。这种变化容易造成总量数据看似改善，但不同消费板块之间表现并不一致。 因此，消费“回暖”不能只看总额和同比增速，还要进一步判断增长究竟来自居民收入与信心的真实改善，还是来自补贴集中释放、节假日错位及前期需求透支。对宏观政策而言，补贴退坡后的真实消费承接能力，比短期政策刺激形成的数字更加重要。 **欧洲财政矛盾升温：法国罢工与法德利差扩大暴露结构性压力** 视线转向海外，法国街头罢工持续发酵，法国与德国之间的利差明显扩大，欧洲债务危机的阴影再度回到市场视野。法国面临的并不只是短期经济波动，而是财政赤字、债务压力、竞争力下降与政治约束相互叠加的结构性矛盾。法国国债收益率相对德国上升，反映出市场对法国财政状况、欧洲政治协调以及欧元区制度环境的担忧正在上升。 利差扩大又会进一步推高法国政府的融资成本，形成“赤字压力上升—融资成本增加—财政空间收窄”的负反馈。若法国政府为稳定债务而推出削减赤字措施，街头抗议和政治阻力可能随之增强；若不愿削减，债务和利差又可能继续恶化。这正是欧洲财政问题最难处理之处。 **民粹主义成为财政改革的主要障碍** 欧洲债务危机反复的根源之一，是经济改革与政治改革之间缺乏有效配合。削减赤字、压缩公共支出、推动养老金或劳动力市场改革，都可能立即触及部分群体的利益，并引发社会抗议。法国街头罢工所反映的，正是政府在财政整顿、增长保障和社会稳定之间难以兼顾的困境。 问题在于，财政风险如果被推迟，只会在未来以更高成本重新出现；但在民粹主义影响较强的政治环境中，任何有效改革都可能被贴上“削减福利”或“让普通群体承担代价”的标签。因此，没有政治改革配合的经济改革，注定会撞上民粹的墙。欧洲要真正化解财政压力，除了技术性的降债方案，还需要政府沟通、跨党派共识以及更适应社会经济变化的政治协调机制。 **美股AI交易进入关键阶段：融资飞轮开始显露反噬风险** 大西洋彼岸的美国资本市场，AI融资正在形成看似繁荣、实则危险的循环。融资能力增强，可以推动企业投入更多算力、招募人才并开发更强的模型；更强模型本应带来新的产品与应用，继而为下一轮融资提供故事和现金流。但在现实中，融资规模扩大也在推高利率和资本成本，而模型迭代速度越来越快，对资金投入的要求不断提高。 一旦AI产品的收入增速无法跟上资本投入、融资规模或估值扩张的速度，飞轮就可能反向运转：融资成本上升，模型投入压力加大，商业化收入却不足，最终从股权融资扩散到债务融资和信用扩张。届时，AI产业链中的估值压力将不再局限于个别科技公司，而可能通过债券市场、信贷渠道和资本市场波动外溢至更广泛的经济金融体系。 **AI投资逻辑正在切换：从硬件叙事转向软件、应用与模型能力** 市场目前对单纯增加硬件供给的逻辑逐渐失去兴趣。大量资本涌入服务器、芯片和数据中心，并不自动等于相关资产具备持续上涨空间。硬件环节能否止跌，关键在于下游是否出现足够强的软件工具、实际应用和商业化模型，将昂贵算力转化为收入、利润与生产率提升。 这也意味着，AI产业将从“资本投入驱动的规模竞赛”逐步进入“收入验证驱动的质量竞赛”。投资者需要关注的不只是模型参数、算力规模和融资额，还包括模型使用成本是否下降、企业是否愿意持续付费、应用能否形成刚需，以及AI收入能否覆盖折旧、研发和融资成本。只有软件和应用端形成闭环，硬件板块才可能真正获得估值支撑。 **三大事件将检验市场主线：美股三季报、美联储议息与美国中期选举** ## 粉红丝带与乳腺癌：让被看见、被谈论的健康议题走进每个人 **粉红丝带背后的公共卫生理念** 三十多年后，乳腺癌及其防治已经拥有较高的社会认知度，“早筛、早诊、早治”也为人们所熟悉。然而，知道疾病名称并不等于每个人都能顺利获得筛查、诊断和治疗。粉红丝带运动的意义，正在于不断把健康信息带入更广泛的人群，并提醒社会：乳腺癌并不只属于某一种人，也不只发生在具备充裕时间、经济条件和医疗资源的人群中。 **不被看见的疾病边缘** 这种跨领域对话的重要性在于，医学信息需要被准确传达，疾病经验又需要被有尊严地表达。专业语言若过于遥远，可能让普通人不愿靠近；个人叙事若缺乏可靠信息，也可能被网络偏方或刻板印象包围。理想状态不是用故事替代医学，而是让二者相互补充：医学提供判断依据，故事扩大传播范围，并让抽象的风险和流程转化为能够被记住、理解与行动的经验。 **从“自己的事”变成“公共的事”** 粉红丝带最初的意义，是让一件原本难以说出口的事可以被公开谈论、可以被看见。三十多年后的挑战，则是如何让这种公共性继续发挥作用。乳腺癌知识不能只在关注月集中出现，也不应只停留在宣传口号和公益符号层面。它需要进入基层女性的日常健康教育，进入年轻妈妈可以负担的体检安排，进入家庭的代际对话，也需要纠正“男性不会得乳腺癌”等认知。 节目以10月国际乳腺癌关注月为背景，也说明公共健康传播需要借助特定时间节点提高关注度。但真正有效的防治观念，应当融入长期、稳定、容易获得的信息服务，使人不必等到症状明显、恐惧加深或偶然看到宣传之后，才开始思考自己的健康风险。 **总结与核心启示** 本期播客以粉红丝带的历史为起点，关照乳腺癌防治中那些容易被忽略的人，并试图从康复者、医生和文化创作者的不同视角，讨论疾病知识、早期筛查、家庭支持与公共表达。粉红丝带超越了单纯代表乳腺癌的视觉标志，倡导一种更开放的态度：有关健康和身体的议题应当能够被谈论，困难与恐惧不必独自承受，疾病经验也不应只被当作个人私事。 核心启示可以归纳为三点。第一，乳腺癌离每个人都不远，男性、年轻女性和基层人群都不应被排除在风险认知之外。第二，早筛的价值不仅是发现异常，更在于主动建立检查习惯，不能把是否出现明显症状当作唯一判断标准。第三，确诊后的帮助是全方位的，既包括规范医疗，也包括家庭理解、社会支持、心理陪伴和更有尊严的公共表达。真正成熟的乳腺癌防治，不只是让更多人“知道”这种病，更要让每个人都能看见风险、获得信息、迈出检查的第一步，并在疾病发生后仍然拥有被理解、被支持的生活空间。

## 超大城市、人口集聚与中国经济新变化：陆铭谈发展选择、产业政策与AI时代 **超大城市在经济调整周期中面临新挑战** 本期《高能量》对话嘉宾是上海交通大学安泰经济与管理学院特聘教授、中国发展研究院执行院长陆铭。访谈从当前经济调整周期出发，讨论北京、上海等超大城市的发展问题，涵盖年轻人是否仍应选择一线城市、房价与人口流动的关系、城市承载力、地方竞争、产业政策、“内卷”与消费，以及人工智能对城市和经济格局的影响。值得注意的是，陆铭并不把大城市问题和人口集中简单归结为“过度拥挤”，而是强调要区分现象背后的经济机制，并从长期发展视角理解人口与资源如何重新配置。 **离开一线城市之后，为什么有人又“逃回北上广”** 陆铭认为，年轻人离开北京、上海等一线城市，并不一定意味着他们不再认可大城市的长期价值。现实中存在“先离开、后返回”的现象，反映出个人在不同阶段对就业、收入、公共服务、生活成本和发展机会的综合权衡。大城市提供的不只是就业岗位，还包括更丰富的信息、技术、职业网络、公共服务和文化生活。因此，判断一个城市是否值得留下，不能只看当下的房价或收入压力，也不能只依据一次就业选择，而要观察个人职业发展的长期路径。 **房价高未必是坏事，关键在于区分原因与结果** 在讨论城市房价时，陆铭提出一个重要分析原则：房价高本身未必直接构成城市问题，必须先辨明它是原因还是结果。如果人口持续流入、产业发展较快、公共服务完善推高了房价，那么房价更可能是城市吸引力和经济活跃度的结果；但如果房价通过抬高生活成本、抑制创业创新和人才进入，反过来阻碍城市发展，它才可能成为需要治理的约束因素。由此看，单纯压低房价可能掩盖真正的结构性问题，城市治理需要同时处理住房供给、土地利用、公共服务和区域发展之间的关系。 **城市对人口的承载力不是固定常数，而会随条件变化** 陆铭强调，城市人口承载力不是先天不变的数字，而是会随基础设施、公共服务、产业结构和治理能力而变化的变量。北京、上海等城市在传统公共服务容量上面临压力，但随着轨道交通、住房体系、医疗教育资源以及数字化治理的发展，未来可能释放新的承载空间。因此，讨论“城市还能装多少人”时，不能沿用过去的静态标准，更不能用现有人口规模直接推算未来发展上限。政策制定者需要重新评估城市功能，在疏解非核心功能的同时，提高核心区域的资源配置效率与公共服务供给能力。 **人口向大城市集中，是市场选择而非经济学家强加的主张** 对于人口持续向北京、上海等大城市集中，陆铭指出，这并不只是经济学家的理论偏好，而是普通人通过实际选择形成的格局。人们在就业机会、收入水平、教育医疗、商业文化以及社会网络之间进行比较后，用生活选择投出了“选票”。人口集中说明大城市能够创造更多价值，而小城市和乡村在某些产业没有形成足够优势。不过，人口集中并不意味着每个人都应该留在大城市，也不意味着中小城市只能被动流失人口，而是提示不同地区需要找到各自可持续的产业定位。 **经济总量差距与人均发展差距要分开观察** 访谈中提到一个容易被忽略的区分：当前城市之间，尤其是不同规模城市之间的经济总量差距仍在扩大，但人均发展差距却可能在缩小。经济总量反映城市影响资源、调动市场和集聚产业的能力；人均指标则更接近普通居民实际获得的生活水平和公共服务体验。总量差距扩大并不必然意味着所有人的生活都在恶化，而人均差距缩小也提示，大城市之外的城市并非没有改善空间。评估区域发展质量，应同时观察总量、流量和人均结果，避免仅凭宏观排名作出片面判断。 **大城市像演唱会门票，市中心则像前排座位** 陆铭用“演唱会门票”和“前排座位”比喻城市机会。能够进入热门城市、获得稀缺资源，就像买到一张热门演唱会的门票；而能够生活在最核心区域，则相当于拿到前排座位。两者并不相同：前排视野固然更好，但门票价格也可能更高，不同位置对应不同成本和收益。现实中，人们为了获得职业、创业、教育和 networking 等机会愿意支付一定成本；问题在于，成本应由市场机制透明反映，同时政府要通过保障房、公共交通和公共服务降低基本生活与优质机会之间的脱节，而不能简单阻止人口流动。 **人口集中与个人选择之间，需要更精细的政策设计** 人口向大城市集中，不等于每个人都应留在大城市；对个人来说，留在大城市的机会成本可能包括房价、拥堵、育儿压力和较长工作距离；对城市来说，过度集中则可能加剧住房、教育和医疗资源紧张。因此，合理的政策不是单向鼓励人口回流，也不是无限制强化超大城市中心区的吸引力，而是推动大中小城市完善功能分工，增强县城和区域中心的服务能力，同时让人口根据自身情况自由选择，并通过均等化公共服务降低迁移与安家的制度性风险。 **陆铭为何执着于讨论“大国”** 陆铭特别关注中国作为大国的规模特征。超大规模经济体内部的区域差异、产业多样性和人口流动，不能简单套用小型经济体的分析框架。“大国”意味着不同地区拥有不同发展阶段、比较优势和治理条件，也意味着全国政策要在效率、均衡与安全之间进行更复杂的协调。大城市问题只是这一整体结构中的局部表现：如果只讨论一线城市，而不同时关注区域产业基础和公共财政关系，就容易把结构性问题误判为单纯的住房或拥堵问题。 **中国式产业政策的价值与“产能过剩”争议** 访谈讨论了受到广泛关注的产业政策。陆铭提到，马斯克认为中国式产业政策中有值得美国学习的部分，例如政府能够围绕长期战略形成稳定支持，推动技术研发和产业链建设；也有人将部分产业政策与重复建设、地方政府竞争和产能过剩联系起来。关键不在于政府是否参与产业，而在于参与方式是否有效：政策目标是否清晰，是否经过市场检验，是否允许企业退出，是否存在地方保护主义，以及是否会造成资源错配。产业政策既有推动规模经济和技术突破的积极作用，也可能因地方政府竞相追逐热门赛道而放大风险。 **地方政府竞争既可能是动力，也可能制造“内卷”** 地方政府之间围绕项目、人才、工厂和投资展开竞争，是过去中国经济增长的重要动力之一。地方官员具有推动基础设施和产业发展的积极性，也能通过政策试验寻找新的增长点。但当考核标准偏向短期投资和产业规模时，地方政府可能复制相同产业、争夺相同资源，导致企业在国内市场相互压价，形成“内卷”，并把成本传导至利润、就业和消费。评估地方政府竞争，不能只问其是否制造了更多产能，还要观察是否真正形成了技术创新、品牌升级和具有国际竞争力的产业。 **“内卷”最终会反映到消费与增长动力上** 当企业和地方政府把主要精力用于争夺同一市场、通过价格战和重复投资维持增长时，效率损失会不断累积。居民在收入预期偏弱的情况下，也可能增加储蓄、减少消费，形成供给端继续扩张、需求端相对不足的结构性矛盾。要打破低水平重复，需要通过提高居民收入、完善社会保障、降低预防性储蓄需求来改善消费预期；同时，产业升级应从数量扩张转向效率、质量和原创能力提升，使经济增长不再主要依赖新增产能和低价格竞争。 **AI时代并未削弱集聚，反而可能强化大城市的优势** 对于人工智能带来的新变化，陆铭指出，AI时代并不是人口和产业集聚趋势的终点。AI可能替代部分标准化岗位、降低部分服务的交付成本，并改变传统城市的区位优势，但它也会提高对高端人才、数据、研发机构、资本和基础设施的需求。这些资源集中于大城市，使超大城市在技术外溢和产业升级方面仍具有吸引力。与此同时，AI也可能增强中小城市和乡村接入大城市市场的能力，使它们不必把所有创新活动都集中于本地。由此，未来的关键不是让技术平均分布，而是确保不同规模的城市都能接入新技术创造的价值。 **经济学研究也需要从模型假设走向真实世界** 陆铭还谈到当前经济学研究存在的问题。过度依赖标准化模型、均衡假设和可量化指标，容易忽视人口流动、地方政府行为、制度差异以及技术变化之间的复杂关系。尤其是研究城市和产业政策时，不能只根据简单相关性得出因果结论，更应区分价格是原因还是结果、总量与人均指标、短期政策激励与长期市场选择。更有解释力的研究，需要把制度背景、空间尺度和人的实际行为纳入分析。 **总结与核心启示：城市问题不能靠单点政策解决** 本期访谈的核心启示是：理解中国经济，不能把城市房价、人口集中、产业政策、内卷、消费和AI视为彼此独立的问题。房价高低往往是人口选择、产业发展和公共服务共同作用的结果；人口集中是市场配置的产物，但城市承载力能够通过基础设施和制度改革得到提升；地方竞争既能激发增长，也可能因考核错位和重复建设造成产能过剩；AI不会简单终结城市集聚，而可能重新定义哪些地区更值得人才与资本选择。真正有效的政策，应减少制度性交易成本和不合理重复竞争，改善公共服务与住房保障，激励技术创新，并让不同规模城市都能从技术进步和区域分工中获得合理收益。

What Is torch.compile? Dynamo, PyTorch & Faster AI Models Explained

## torch.compile 如何优化 PyTorch 模型：Dynamo、AOT Autograd 与 Inductor 完整解析 **视频主题与核心问题** 在深度学习模型开发中，许多 PyTorch 程序默认以“即时执行”的方式运行：代码执行到某一层时，框架立即调用对应算子。这种模式灵活、便于调试，但也会带来较高的 Python 调度开销、重复算子调用以及显存读写成本。随着模型结构越来越复杂，这些额外开销可能抵消硬件本身的计算能力。 视频由 Avery Blanchard 讲解，围绕 `torch.compile` 如何改变 PyTorch 模型的执行方式展开。其核心观点是：开发者只需通过很少的代码改动，就可以让 PyTorch 自动分析模型、捕获计算图，并生成经过优化的执行计划，从而减少运行开销并提升模型速度。整套机制主要依赖三个阶段：Dynamo、AOT Autograd 和 Inductor。 **从 PyTorch 默认执行模式转向编译优化** 在普通 PyTorch 模式下，模型通常以 eager 模式执行。Eager 模式的优势是行为直观、调试方便，每一行代码都直接对应实际运行过程；但当一个模型包含大量线性层、归一化层、激活函数以及其他逐元素操作时，框架需要在运行时频繁完成算子选择、参数准备、内存管理和设备调度。 `torch.compile` 会在保留 PyTorch 使用方式的同时，对模型执行过程进行编译和优化。它首先尝试从 Python 代码中识别出可以整体转换的 PyTorch 运算，将这些运算组织成计算图，随后对图进行前后向处理，最后生成更高效的低层执行代码。对于许多以标准 PyTorch 算子构成的模型，这种优化可以减少不必要的中间结果和内核启动次数，尤其适合推理以及重复运行的训练任务。 视频强调，性能提升并不是简单地“把模型换成另一种算法”，而主要是改变模型的执行方式。模型计算仍然遵循原有数学逻辑，但底层算子可以被重新安排、融合或以更低开销执行。 **第一阶段：使用 Dynamo 捕获模型计算图** `torch.compile` 的第一阶段由 Dynamo 负责。Dynamo 的任务是从 Python 和 PyTorch 代码中捕获模型操作，把原本逐条执行的代码转换成可分析的中间表示或计算图。 在捕获过程中，Dynamo 会跟踪张量运算、模块调用以及控制流，并尝试确定哪些操作能够安全地放入同一个编译图中。这样做可以避免在每个小算子处立即返回 Python 执行环境，从而降低解释器开销，并让后续优化器看到更大的计算上下文。 Dynamo 的难点在于，Python 本身是动态语言，模型代码可能包含条件判断、循环、动态属性访问、第三方扩展或自定义算子。当 Dynamo 无法确认某段代码的执行方式时，就需要结束当前图的捕获并回到普通 Python 执行模式，这一位置被称为“图中断”，即 graph break。 **图中断如何影响优化效果** 图中断并非一定意味着程序无法运行，而是意味着相关代码无法被纳入同一张优化图。出现图中断后，Dynamo 会将模型划分成多个可编译片段，各片段之间仍需由 Python 运行时协调。 图中断过多会削弱整体优化收益，因为编译器无法跨过这些边界进行统一的算子融合、内存规划或调度。因此，减少 graph break 通常是提高 `torch.compile` 效果的重要方向。 常见原因包括模型中存在难以静态分析的 Python 控制流、直接修改张量数据、调用编译器无法追踪的自定义逻辑，或者使用某些高级 Python 特性。实际项目中可以通过查看编译日志和图中断信息定位问题，再根据需要重构相关代码。 **第二阶段：利用 AOT Autograd 处理自动微分** 捕获计算图后，第二阶段是 AOT Autograd，即 Ahead-of-Time Autograd。它的主要作用是提前处理 PyTorch 自动微分系统，使前向传播和反向传播能够在编译阶段被统一分析。 这一阶段会追踪由算子组合而成的自动微分图，将前向计算和反向计算中的操作分别整理出来，并明确梯度如何经过模型传播。这样做可以减少运行训练任务时动态调度 autograd 引擎的开销，也能为后续优化提供更完整的信息。 AOT Autograd 还能帮助编译器识别和消除与自动微分有关的不必要工作，并优化反向传播中的计算。对于训练模型而言，梯度计算往往与前向计算一样重要，因此只优化前向传播并不足以体现完整性能收益。通过提前处理自动微分，`torch.compile` 可以同时改善前向和反向执行路径。 **第三阶段：由 Inductor 生成高性能执行内核** 第三个核心阶段是 Inductor。Inductor 接收前两个阶段生成的图，并将其转换为针对具体硬件优化的低层执行代码。对于 GPU 环境，它通常能够利用 Triton 等技术生成高性能内核；对于 CPU，则会结合相应的 CPU 优化策略进行代码生成和调度。 Inductor 不只是将图中的每个算子一对一翻译成内核，它还会分析算子之间的数据依赖，判断哪些操作可以合并执行。例如，归一化、激活函数、逐元素运算或部分线性计算，在条件允许时可以被融合为一个内核。 这种 kernel fusion 的核心价值在于减少中间张量的创建、写入和再次读取。GPU 或加速器执行多个独立内核时，不仅有启动开销，还会反复访问显存。将多个操作合并后，中间结果可以留在芯片内部缓存中，从而显著降低内存带宽压力。对于受显存带宽限制的模型，这类优化往往比单纯增加计算单元更有效。 **惰性编译与首次运行成本** 视频进一步说明，`torch.compile` 并不是在程序启动时立即编译模型中的所有代码，而是采用惰性编译机制。编译器通常在某个计算图第一次被实际执行时，才对其进行捕获、分析和代码生成。 这种方式可以避免为永远不会执行到的分支提前付出编译成本，也让模型先按实际运行路径进行编译。不过，它的直接结果是首次调用往往比后续调用更慢，因为首次运行需要完成图捕获、编译、内核生成以及可能的缓存初始化。 因此，在评估性能时不能只测量第一次执行。更合理的方法是先进行预热，再测量稳定运行阶段。如果模型每次启动后只执行一次，编译成本可能得不偿失；如果模型会长期运行、重复推理或执行大量训练迭代，编译带来的收益通常更容易体现。不同进程、不同输入形状或不同模型结构也可能触发新的编译工作。 **动态形状、缓存与重复编译** 惰性编译还引入了缓存和重复编译问题。编译器在生成代码前，会根据输入形状、张量设备、数据类型以及部分 Python 控制条件建立判断信息。只有当新输入仍满足此前记录的条件时，编译器才能复用已经生成的内核。 如果输入尺寸持续变化，编译器可能需要针对多个形状生成不同版本，称为动态形状处理或 recompilation。虽然 `torch.compile` 可以尝试将部分形状变化归一化，以减少重复编译，但过度动态的模型仍可能带来额外成本。 重复编译还可能由模型中过多分支、不同设备、不同数据类型或不适合捕获的控制流触发。视频通过 Dynamo 的行为说明，编译器并非完全脱离 Python 规则，而是会在保证语义正确的前提下建立可复用的快速路径。 **算子融合如何真正提升 AI 模型性能** `torch.compile` 带来的性能收益主要来自多个层面的协同。首先，Dynamo 减少了逐算子返回 Python 的开销；其次，AOT Autograd 提前整理前向与反向计算图；最后，Inductor 根据硬件生成融合内核并优化执行顺序。 其中，算子融合是最直观的优化手段。未融合时，一个简单模型可能需要依次启动多个 GPU 内核，并在显存中反复保存中间结果。融合后，多个操作能够在一次内核调用中完成，中间数据不必完整写回显存。这样既减少内核启动次数，也降低显存访问量，对 Transformer、扩散模型、推荐模型以及其他包含大量逐元素操作的深度网络尤其有价值。 但融合并非对所有情况都同样有效。如果某个算子本身计算量很大，或者操作之间存在复杂的数据依赖，编译器就需要在融合收益与并行效率之间进行权衡。此外，融合后的内核如果尺寸过大，也可能影响资源利用率。因此，Inductor 会结合图结构和目标硬件进行选择，而不是机械地把所有算子合并。 **实际使用方式与性能评估原则** 在典型代码中，开发者只需要对模型或可调用函数使用 `torch.compile`，即可启用整套编译流程。其接口设计强调低迁移成本：模型主体通常不需要重写，原有的数据加载、损失函数、训练循环和评估逻辑可以继续沿用。 不过，获得最佳效果仍需要一些实践配合。应尽量保持模型主体由编译器支持的标准 PyTorch 算子构成，减少难以追踪的 Python 逻辑；关注日志中的 graph break；避免无必要地改变输入形状；并在正式测试前进行充分预热。对于训练任务，还应同时比较前向和反向传播耗时，而不能只测试推理速度。 **总结与核心启示** 视频的核心结论是，`torch.compile` 并不是一个单独的加速器，而是由 Dynamo、AOT Autograd 和 Inductor 组成的 PyTorch 编译优化体系。Dynamo 负责捕获可编译的计算图，AOT Autograd 负责提前处理自动微分，Inductor 则负责生成面向硬件的高性能内核。三者共同减少 Python 调度、算子启动和中间张量读写，并通过 kernel fusion 提高执行效率。 其最重要的启示是：AI 模型性能不仅取决于网络结构和硬件算力，也取决于框架如何执行模型。Python 控制流复杂、图中断频繁、动态形状过多或编译预热不足，都可能削弱优化收益。正确理解惰性编译、重复编译与图中断机制，再结合稳定场景进行基准测试，才能判断 `torch.compile` 是否真正适合特定模型。

**街区派对：嘻哈最真实的发生现场** 面对早期嘻哈的历史时，Kurtis Blow没有把起点包装成一个遥远、抽象的传奇时刻，而是将其放回哈莱姆的街区环境。Block
