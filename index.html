&nbsp; DeepSeek的答案，不是只仰望星空，也不是只脚踏实地，而是用现实问题去支撑一个足够远的目标。 &nbsp; &nbsp; 撰文&nbsp;|&nbsp;李嘉星 刘辰艺 编辑&nbsp;|&nbsp;张薇 头图来源&nbsp;|&nbsp;DeepSeek 封面来源&nbsp;|&nbsp;DeepSeek &nbsp; DeepSeek又一次被推到聚光灯下。&nbsp; 这家公司一度几乎是AI圈最神秘的存在：工程师文化、低调，创始人很少公开露面，团队也不像典型互联网公司那样频繁讲故事、做传播。但过去一年，它几乎每隔一段时间就会成为中文科技圈的中心。模型发布时，它因为低成本和开源刷屏；融资消息传出时，它因为估值和投资方引发讨论；这一次，梁文锋一场近4小时的投资人交流会录音流出，又让外界重新审视这家公司。 这一次，外界看到的是一个更完整、也更矛盾的DeepSeek。&nbsp; 一面是一个足够远的目标。梁文锋谈AGI，谈愿景，谈“对世界的善意”，谈不追求利润最大化，谈不开源就无法组织人。他说DeepSeek不想做下一个超级App，不想成为下一个字节或腾讯；公司靠愿景而不是KPI运转，研究员有大量自由探索时间，也不太加班。 另一面是脚踏实地。梁文锋也谈十个月回本的API定价，谈融资如何缓解团队稳定风险，谈钱要尽快变成卡，谈国产算力的产能瓶颈，谈一半核心研究员在标数据，谈公司变大后必须补组织结构。他甚至说，最坏情况卖API，也能支撑一家上市公司。 一家AI公司如何既仰望星空，又脚踏实地？这正是DeepSeek想给出的答卷。 根据网络上流出的“梁文锋投资者交流会录音文字稿”，“未来人类实验室”做了以下的梳理。&nbsp; &nbsp; 看得很远，但拆成台阶 &nbsp; 长期目标是AGI，但不是空喊远方，而是拆成连续台阶&nbsp; 梁文锋把长期目标定义为AGI，但他没有把AGI讲成一个悬浮概念，而是拆成一条连续路线：语言模型、CoT、Agent、持续学习、自我迭代、具身智能。目标足够远，但每一步都能落到当前技术问题上。&nbsp; “这是我们的推测，这是我们觉得这个时间表应该是：先解决学习去学习，然后再到那个智能的奇点，能自我迭代的奇点，然后才是具身智能。到具身智能之后，它就走进现实世界，可以给你做家务，可以给你养老。” “我们觉得这是一个比较理想的路线图，但每个人的观点不一样，没有对错之分。只是我们觉得，这个路线图是最轻松的。这个路线图是因为每一步你要做新的都很少。” “AI的发展，我们可以理解成它是一个阶梯。去年走的阶梯是CoT，就是思维链。因为我们发现，通过思维链的方式，可以让智能达到一个更高的水平。通过它自己思考，可以让这个上限，可以让这个AI能做更多的事情。” 它追Agent，但不把Agent当终点 外界现在最热的是Agent产品和商业落地，但梁文锋更关心Agent之后的瓶颈：持续学习。它参与当下技术浪潮，但不被当下热点定义终局。 “Agent这个地方，能看到的是下一个瓶颈，就是持续学习。下一个要解决的问题，就是解决怎么持续学习，这个是看得到的，是相对来讲比较明确的。” “AI并不能够替代你的员工。但如果说AI具有持续学习的能力，它跟你的员工一样，到公司学习两个月，那就可以替代天下的人了。” “现在投资人看到的最多的是Agent；但对于我们这些研究的人来讲，现在看到更多的是学习。” 看得远，但会主动排除不在主线上的技术方向。 视频生成、3D、世界模型、多模态、具身智能，都被放在不同优先级里。DeepSeek不是否定它们，而是判断它们是否处在当前智能主线上。既看见未来的丰富形态，也克制住不被每个热点牵走。 “在对外面打交道的时候，我们的态度是：我们只做AGI的主线。这就是我刚刚说的这个GPT、CoT、Agent等等，就只做主线。AI领域很广泛，有很多东西我们觉得它不在这个主线上面，比如说3D、视频生成，我觉得可能跟智能的主线没有太大的关系，我们不会去做。” “但在商业上，它是个好生意，在商业上是个好生意。但是这跟智能没有什么关系。我们不会因为它是一个好商业而去做它，我们只会因为它是智能路线图上的东西，才会去做。” “多模态布局，我们一直在做。对产品来讲，它很重要；对C端用户产品来讲，它很重要。但是对智能的上限，它是一个组件，它不是主线本身。” 它允许高不确定性的研究“摸奖”，但也承认技术突破背后有大量苦活。&nbsp; 持续学习这类问题，不适合完全项目制、KPI制，也不一定需要大量卡。梁文锋把它称为“摸奖”：门槛低，很多人可以去想，突破不确定。但另一边，他又非常现实地讲数据标注、后训练、幻觉、成本效率。这不是只靠灵感的研究文化，而是自由探索和脏活累活并存。给研究留出不确定空间，同时接受技术突破背后的笨功夫。 “他不是一个项目，而是需要有很多人都在那里想这个问题。所以并不需要给它分配什么资源。只是说，我们跟其他公司不一样的地方，就是我们会花时间去讨论这个问题，会去想这个问题，然后把它当做一个重要的事情。” “所以我们叫这个叫‘摸奖’。门槛很低，谁都可以去摸，但是谁能摸出什么来，这个可能我也不知道是看天赋还是看什么。” “所以现在基本上是两条腿走路。并不是说我们完全不能标，而是因为标数据有一些成本低，有一些成本高。我们先标成本低的。所以你也可以认为，现在我们公司有一半的人在标数据。有一半的核心研究员，最重要的人，有一半在标数据。” “幻觉问题也是有一个方法可以解决的，但是这是一个长命题。幻觉问题可以认为是一个可以通过更好的Post-training解决的，是一个能解、能够改善的问题。只是大家没有花很大的力气去做。或者说，对我来讲，幻觉是一个问题，但我们归结可能是产品问题。我们会去解决它，但是不是重点的问题。” 它相信Scaling，也承认算力才是现实瓶颈 DeepSeek不否认Scaling，也不回避中美差距。梁文锋把差距说得很直接：不是人才，而是资源。所以低成本、国产算力、底层编译器，不是产业口号，而是技术路线的一部分。相信大模型规律，但在资源受限下用工程效率换迭代空间。 “Scaling，我们是信Scaling，肯定是规模越大，效果越好，能够解锁更多的功能。阻止我们Scaling的其实就是算力，并不是我们不想Scaling，是我们没有那么多的算力去做这个Scaling。” “我们没有触摸到这个上限在哪里。我们训练这么大的模型，并不是因为我觉得这么大的模型就够了，而是我刚好有这么多资源。我是按照我的资源来算，我能够接受、能够训练的模型是多大，是这样算出来的，并不是这个模型就够了。” &nbsp; &nbsp; 不是无组织，而是动态组织 &nbsp; 不是不要组织，而是动态长组织&nbsp; 在寻找技术路线时，梁文锋的思路出其不意，他说做这个路线图可以不用加班，于是这个做起来最轻松的路线成为他们的技术路线。这种对轻松和灵活的追求，同样体现在他对团队的组织和管理中，梁文锋说，他们没有组织架构，团队不加班，没有Kpi，至少有一半的时间，团队成员在做自己的事。 “他们（员工）还有一半的时间，是不被安排的，他们想做什么就做什么。这是一个研究的范围，让他们可以自己去探索，按照他们觉得什么重要，他们去探索什么，没有前置的要求。” 创始人权威来自共识，而不是独断 在梁文锋看来，将大家组织起来的是愿景。大家靠愿景驱动，“他们怀着对这个世界非常大的善意，想要做一点事情”，因此他们来了。最开始的几十个人完全没有想过赚钱，“如果他们这么想，那么就不会来。”梁文锋说。他自己的权威也由共识塑造，一件事情能够推动，那是因为它是共识。 “我跟你们讲个故事，就是我们那个DDCP，是我们那个模型。一开始我们担心需求太多，所以一开始把价格定得比较高，团队里大家不是很高兴。后来我把价格又降下来了，降到四分之一，大家就很开心。 我觉得这个才是我们真实的想法。就是我前面说的愿景，我们还是让这个东⻄对人是有用的，而不是我们赚最多的钱，而是我们在能够赚到合理利润的情况下，大家都用得起。我觉得这次我们公司其他人的想法，就是我们那时候降价的时候，公司群里面很多人是欢呼的，大家都觉得很开心。” “比如说我要做一个事情，我肯定是先看我们大家的共识是什么，大家想不想做。然后有可能我会有一些引导或者倾向,但是这引导的作用是有限的,引导的作用是非常有限的，还是建立在一个共识的基础上。这个决策机制其实是一种寻求共识的机制，这并不是说我能够推动一个什么事情，它一定是共识，我才能够推得下去，然后我才会去推。” 它保持松弛，但不是懒散，有自己的组织机制 团队不是只说不做。梁文锋说，愿景不是挂在墙上的标语，而是怎么做。他清楚地知道自己在做什么，有一套清晰的组织逻辑，组织形式、激励机制、团队目标被他想得很明确。员工有一半时间做自己的事，另一半时间要用来完成公司的任务。不加班的确是福利，但是，梁文锋希望这能够为研究创造松弛的环境。团队要做的事情少，是因为他们的目标聚焦，他们要做AGI。未来，随着人员扩充，梁文锋坦诚说，有些部门也需要建立起严格的层级结构，事实上，改变正在发生。&nbsp; “然后第二个问题是，思考未来的组织架构，对人员的规划规模。首先，我们之前的组织架构是非常分散的，因为没有组织架构。但是我们人在进一步扩大之后，这些肯定是需要做出一些改变的。现在只能说，这里会需要做很多改变，但现在很难一下子全部表达出来。最后应该还是要分不同的部门，应该有些部门是我们需要建立起比较严谨的层级结构的。另外一些部门， 可能还是会维持一个比较松散、比较扁平的结构。” &nbsp; “我们一般也不太加班。不加班有两个原因。第一个是，做研究是需要一个比较松弛的环境。 你如果逼得很紧，就没法做研究。因为既然就是要你自己有这个兴趣，你自己平时要去想这些问题，所以得是在一个比较松弛的环境里，才有可能能够探索。这是一个出于研究文化的需要。第二个是，我们非常聚焦。聚焦，就意味着我们要做的事情很少。那我就没那么多事情要做,我就不需要加班。” &nbsp; 团队稳定是理想落地的底座 团队的稳定性是核心利益。在梁文锋看来，很多东西都重要，钱，卡，资源，但这都不是风险最大的地方，风险最大的地方是人散了。为了不让团队坍塌，梁文锋在无组织中寻找着动态组织的可能性，层级、技术、创新机制，都可以成为他维持团队平衡的抓手。近期，DeepSeek完成了部分融资，梁文锋说，大家拿到期权，“人散了”的风险得到了比较大的解除。 “只要我能够保持团队的稳定性，我一定能做成，一定能做成AGI，就这么简单。只要大家都不走，我们能够继续做，我就一定能。基本上没有什么⻛险。只是说早点晚一点，将遇到挫折;如果遇到挫折，大家都不走，那么我又可以继续。” “从团队稳定性来讲，只要最重要的一些员工、最老的员工能够稳定，那么其他人是不太会走的。其他人哪怕期权少一点、收入少一点，他也不会走。因为他不是全奔着钱来的，大家都希望在一个能够做成AGI的环境里面去做这个事情。 所以对人才来讲，还是有吸引力的。” “从历史上来看，我们的人才流动是比较少的，跟同行比，我们人才流动永远是比较少的。但是，这依然是我们最大的挑战，是唯一的挑战，可以这么讲。” &nbsp; 开源是理想，也是商业机制 &nbsp; 开源不是放弃壁垒，而是把壁垒从模型转移到成本和工程效率 梁文锋谈开源时，不是单纯讲理想主义，也不是单纯讲营销。他的判断是：AI这件事足够大，不可能由一家公司独占；开源有利于生态接受，也不会天然伤害商业模式，因为真正的壁垒不只是模型本身，而是部署成本、工程效率和组织能力。 “这个愿景为什么我们这么坚持开源？因为这个愿景本身就要求开源。你没有这个愿景，你没法把人组织起来。” “然后在开源这个事情上面，我们一开始就想得非常清楚。首先，第一个就是愿景；第二个，我们认为要把AI这个事情在商业上做成，开源是有好处的。” “但是AI这个事情足够大，最终它可能得占掉人类社会GDP的百分之十，比如说。那么它其实是一个非常大的数字。一个人独占这个事情，你不可能独占这个事情，你一定得跟别人分享，否则你肯定活不下来。” “如果说我们想独占这个利益，那么一定是要被历史抛弃的。我觉得最主要这是一个客观的规律，这是一个历史观。” “哪怕是模型开源，你把所有东西都告诉别人，这个门槛也非常高。别人要用起来，这个门槛也非常高。他要用起来，就很难；其次，他要用起来，还要成本做得很低，也很难很难，没有那么容易。” “并不是我开源了，他就能够轻易地做到跟我一样的部署成本。这里边还是有很多工作要做的。虽然说这些工作原理都明白，但是不是每一家公司都愿意，或者都有这个意愿和能力来组织人力去达到这个目标的。” “开源，我觉得对我们的商业模式是没有任何影响的。前提是我们只赚六倍的利润，十个月收回成本，大概对应的是六倍的利润。我们只赚六倍利润的情况下，开源是不会有什么影响的。” “然后我也不担心别人部署我们的模型，然后跟我们来竞争，一点都不担心。我们还希望他们能够部署起来。” 不树敌，但不是没有商业防线 DeepSeek不愿意和大厂、小厂成为对手，甚至愿意帮助竞争对手。这种姿态一方面来自愿景，另一方面也减少了外部阻力，让公司可以继续聚焦主线。同时，梁文锋认为，大模型竞争最终不是玄学，而是成本、时间、体验。成本控制好的人多赚一点，成本控制差的人少赚一点。 “所以我们现在做的很多事情，都是为了保持团队的稳定性。除了这一点以外，其他我觉得我们都是可以不要的，都是可以克制的。我们一直非常克制，不愿意跟任何一家互联网大厂或者小厂成为对手。” “在这个前提下，我们是很愿意协助、帮助任何人，甚至我们的竞争对手，包括阿里、智谱、月之暗面，去做得更好。因为我们并不损失什么东西，我们本来也是开源的。” “我并没有因为我们的善意而影响到我的商业利益，完全没有影响，反而可能还有加分。” “差距只有两个东西：一个是时间，一个是成本。所以不至于哪一家有暴利，我觉得不至于有暴利。成本控制得好的人就多赚一点，成本控制得差的人就少赚一点，仅仅此而已。” 不吃全产业链，只守最核心的位置 梁文锋反复表达过一种边界感：DeepSeek不希望把所有东西都做了，不希望向上游芯片垂直整合，也不希望吃掉所有应用层机会。它相信AI时代足够大，会产生很多家公司，DeepSeek只需要成为其中一家，而且吃自己最擅长、最核心的那一块。 “还有问题是，我们会不会向上游进行垂直整合？我希望不要。所以有个问题是，我们是不是会往上游应用进行垂直整合？我们希望不用这个，我希望是其他人来做这个事情。我不希望我把所有东西都吃了，我只要吃一块就好，我只要吃我最擅长那一块，或者我觉得我们自己认为最核心那一块。” &nbsp; 你的下一位面试官，可能不是人

&nbsp; 谁能保证超级数字员工不是下一个AI落地的窗口 &nbsp; 撰文&nbsp;|&nbsp;李嘉星 编辑&nbsp;|&nbsp;张薇 封面来源&nbsp;|&nbsp;元企AI &nbsp; 七月初，秋招开始预热。你投出去的下一份简历，可能不是先被HR看到，而是先被一个AI员工读完。 机器筛简历并不新鲜。真正有意思的是，如果这个AI不只是帮HR筛一下简历，而是像一个新入职的同事一样，被交代一个目标后，自己去找人、沟通、打分、汇报结果呢？ 最近，元企AI推出了第一款产品“超级HR”。它不是一个只解决单点环节的工具，而是试图像一个员工一样接下任务：拆解岗位需求，去招聘平台找人，看你的项目经历，给你打一个匹配分，再把“是否值得继续沟通”的理由交给人类HR。 今年3月底，清华博士陈猛和他的大学室友、北大博士杨一博，正式启动了元企AI的创业。 这不是陈猛第一次创业。 在做元企AI之前，他已经连续做过多个项目，经历过教育SaaS、钠电池、车载光伏等方向。 也正因为长期和企业打交道，陈猛对企业里的成本问题很敏感。 “最近几年和企业家聊天，大家最常聊的就是降本增效。与此同时，很多岗位也存在人的不确定性，比如请假、离职，有些很重要的岗位突然离职，会影响企业业务推进。”这是陈猛与各个企业家交流后发现的问题。那么，企业有没有可能拥有一个更稳定的岗位形态，让企业更稳定，而且成本更低？ 陈猛给出了他的答案。做一套像人的数字员工平台。 先从招聘需求开始。 陈猛告诉“未来人类实验室”，在调研中他们发现，猎头或人力资源服务公司前段找人和沟通可能占掉大量时间。对HR和猎头来说，招聘前段的大量工作并不性感。找简历、翻简历、初筛、沟通、推进面试、整理候选人，这些事耗时、重复，却不一定产生最高价值。 如果这部分工作能交给AI，人的时间就可以被释放到更需要判断和关系处理的地方：理解业务需求、和客户对齐岗位画像、判断候选人是否适合组织，以及促成最终成交。 很关键的一点是，它得像个人。用户不是让它“帮我筛一下简历”，而是直接给它一个任务：我要招一个电子工程师。然后它自己拆任务、去平台找人、筛简历、看项目经验、打分排序、汇报结果，再让人确认下一步。换句话说，它不是嵌在平台里的工具，而是围绕“招到合适的人”这件事往前推进。 但一个新员工刚入职，也不可能第一天就完全懂公司。元企AI对超级HR的理解也是如此。它不是一上来就变成一个满分员工，而是需要在和企业的持续交互中，慢慢理解这家公司到底想要什么样的人。比如同样招产品经理，有的公司更看重大厂经验，有的公司更看重创业公司里从0到1把事情跑通的经历；有的岗位学历是硬门槛，有的岗位项目经验更重要。 AI员工市场 &nbsp; 它还远不是一个完美员工。 “目前行业对数字员工存在两个极端概念，一个是过度悲观，一个是过度乐观。”陈猛告诉“未来人类实验室”。他认为短期内，Agent可能主要解决局部的、重复的、可标准化的环节。之后才可能逐步进入更完整的业务流程。不能因为技术有缺陷就否定方向，也不能因为技术进步就说马上能实现。 陈猛也承认，客户最关心的就是两件事：幻觉和数据泄露。企业没有的福利，AI不能凭空说有；企业是单休，AI不能说成双休。企业交给数字员工的账号和招聘数据，也不能被泄露或滥用。 超级HR只是一个开始。元企AI接下来还想把这套能力复制到财务、法务、销售等企业基础岗位。它已经完成种子轮数百万元融资，正在推进天使轮融资。 它的长期设想，是让企业用自然语言生成不同岗位的数字员工。而一个AI进入组织之后，能不能被管理、被限制、被评价，也能在出错时被追踪，正是它能否在企业的业务流中落地的关键要素。 以下是“未来人类实验室”与元企AI创始人陈猛的对话，经整理发布—— &nbsp; 工具解决环节，员工解决任务&nbsp; 未来：你们为什么一定要把它叫数字员工，而不是AI招聘工具？ 元企AI：工具解决的是环节，员工解决的是任务。 普通工具可能帮你做一个环节，比如筛一下简历、写一段话、生成一份报告。但数字员工是任务导向的。你不是让它“帮我筛一下简历”，而是告诉它“我要招一个电子工程师”。它需要围绕这个目标，自己去拆解任务、找人、筛选、沟通、打分、总结，并把结果交付给人。 它更像一个线上员工。用户不需要每一步都盯着它，它需要自己推进任务，并在关键节点向人汇报。 &nbsp; 未来：一个AI要做到什么程度，才算从工具变成了员工？ 元企AI：我们希望它能够像人一样完成闭环。 现在市面上很多做超级数字员工的公司，其实做的是工作流，只能完成一些环节。比如RPA、淘宝客服这类，有很多地方需要人介入，不能自己闭环完成一个工作。 比如一个任务有A、B、C、D、E五个环节，它可能只能解决A、C、D，中间还有环节需要人介入。这样效率提升就没有那么明显。 我们希望它像人一样独立完成一个闭环工作。比如我让一个人类HR招一个财务或行政，他的目标肯定是招到这个人为止。中间如果他对需求有误解，再和我确认、及时修正，但最后交付物应该是一个完整候选人，而不是每一步都来问我。 如果每一步都要打断我，其实没有给我省很多时间，甚至还挺耽误事。 &nbsp; 未来：它在哪些地方必须像人，哪些地方又不能太像人？ 元企AI：像人的地方，是要能闭环工作，像一个聪明上进的好员工。 不像人的地方，一个是人需要休息，但AI可以7×24小时实时在线响应。另一个是成本。大规模商用必须把成本降下来。 比如一个资深招聘HR，年薪可能五六十万、六七十万。我们希望一年5万到10万元以内，就能把这个成本包住。它可能能顶80%的资深HR，但成本只有那个HR的20%。这样才是真正能帮到企业，而不是一个面子工程。 &nbsp; 未来：如果把超级HR放进一个真实招聘流程里，它具体做哪些事？ 元企AI：它主要做招聘前段比较重复、低效、费时间的工作。 比如从一个招聘漏斗看，可能一开始有1万个人，其中对公司有意向的大概200个；这200个里面，公司感兴趣的可能30个；这30个经过几轮沟通，双方都OK的可能5到6个。 我们解决的是从一两千人到三四百人，甚至到30人的这段工作。比如找简历、筛简历、判断匹配度、做初步沟通、整理结果。最后候选人来不来，还要看HR怎么和他沟通，怎么推销公司，怎么判断价值观是否匹配。 所以我们解决的是匹配工作，HR还是要做更高端的沟通、判断和关系处理。 &nbsp; 未来：那它现在不能做什么？哪些环节必须由人确认？ 元企AI：一头一尾目前还需要人。 头是招聘需求。HR本身不生产需求，很多需求来自老板或业务团队。所以真实、明确的招聘需求，还是需要业务团队或老板输入。 尾是终面。AI可以帮你匹配简历上的信息，但到最后合不合眼缘，或者一些软实力，比如销售的沟通情商、组织适配度，还是需要人做最终判断。 目前AI可以通过简历和初步沟通帮你兜住底线，但上限判断仍然需要人。比如你希望销售是严谨型、数据型，还是春风化雨型，这种偏好需要人做最终决策。 &nbsp; 唯一你会觉得它像AI的地方，可能是它回得太快 &nbsp; 未来：现在外面很多AI产品都能聊天。你们怎么判断一个数字员工是不是真的落地？ 元企AI：我觉得不能只看它会不会聊天，而要看它能不能进入真实业务流。 对招聘来说，真实业务流不是回答几个招聘问题，而是从岗位需求开始，去找人、筛人、沟通、打分、汇报结果。它要能把这些事情串起来。 我们现在更偏产品，不是自己做底层模型。模型层调用市面上成熟的大模型，重点是在应用层、上下文、长期记忆和成本控制上做工作。 如果一个资深HR自己用大模型手搓一个AI招聘产品，产品力可能也能接近我们。但直接用大模型非常耗token，而且它不会长期记住你的偏好，每次都要重新磨合。 我们要做的是让它记住企业的偏好，降低调用成本，让它真正变成一个可以长期使用的产品。 &nbsp; 未来：你们为什么第一步先服务猎头、招聘团队，而不是直接服务所有中小企业？ 元企AI：因为猎头、招聘团队有批量重复需求，而且付费意愿更强。 一个十几二十人的中小企业，正常一年可能只招六七个人。让它花一万多或三万块买一个专业版，并不一定划算。老板自己空的时候看一看，也能处理。 但猎头不一样。猎头招得越多，赚钱越多。他们有大量招聘需求，也有很强的效率诉求。大厂的专门招聘团队、快速扩张的创业公司招聘团队，也有类似需求。 我们的最终目标是服务中小企业，但中小企业不会在A公司买AI招聘、B公司买AI法务、C公司买AI销售。我们希望未来把AI人力、财务、销售、品宣做成一个综合岗产品。到那个时候，中小企业过去可能要找四五个员工，未来找我们一家，就可以覆盖很多基础岗位需求。 &nbsp; 未来：一个普通求职者，可能会最先感受到什么变化？ 元企AI：最直接的是响应速度。 比如你问加不加班、出差频率、五险一金，过去可能要等HR几个小时，甚至等到周一。AI如果提前知道这些信息，就可以7×24小时及时回答。 人类HR处理10份简历时，可能还能高效、温柔地回复你；处理100份时，可能就会疲惫、出错。但AI处理10份还是100份，标准都不会变。 这对求职者来说，体感会更好。一方面能感受到公司更及时的回应，另一方面也能更快判断自己和岗位是否匹配。&nbsp; 未来：求职者会知道自己正在和AI沟通吗？ 元企AI：从我们现在的演示看，它回答得还蛮像真人。比如加不加班、出差频率这些问题，唯一让你觉得它像AI的地方，可能是它回得太快。 但我们作为商用产品，会对规则限制得很死。比如公司没有的福利，它不能乱说；月薪8000的岗位，它不能随便承诺能开到2万。它可以不知道，但不能乱说。 &nbsp; 未来：如果一个人学历一般，但项目经历很好，AI会不会把他误伤？ 元企AI：这取决于用人团队给AI的需求是否明确。 比如老板到底更看重大厂背景，还是更看重创业公司里一个人hold住完整链路的经历？学历是必须项，还是加分项？项目经历是必须有某类技术经验，还是加分项？这些都要先讲清楚。 AI会把这些需求拆成多维度评分。比如英语能力对出海项目可能占30%到40%，但对中后台岗位可能只占5%到10%。如果第一批简历不OK，人也可以反馈给AI，AI会调整打分项。 传统筛简历可能更像关键词匹配，但AI可以看项目经历里的语义。只要候选人把项目写在简历上，AI就能识别并判断匹配度。 但它也有边界。如果候选人简历上没有写出来，AI可能会把他挂掉；而人类HR通过电话追问，把隐藏经历问出来，这件事目前AI还不一定能做到。 &nbsp; 未来：那正在做HR的人应该担心什么？ 元企AI：我觉得不是简单说替代HR，而是把HR从低效重复工作里解放出来。 AI更适合做匹配、初筛、整理这些前段工作。人类HR还是要做更复杂的沟通、判断和关系处理，比如理解业务需求、判断候选人和组织是否适配、把公司推销给候选人。 未来可能被淘汰的，不是HR这个岗位，而是不会用AI的人，或者用AI比较晚的人。用得早的人，会先享受到效率提升。 &nbsp; 越像员工，越需要被管理、审计和限制 未来：数字员工越像人，是不是也越需要被管理？ 元企AI：是。尤其是商用产品，安全性非常重要，甚至是生命线。 免费产品出错，大家可能觉得好笑。但如果用户一年花3万块钱买一个AI产品，它出错，轻则退款，重则产生声誉风险。 所以我们从公司成立第一天，就把安全性写进准则里。比如AI在招聘软件上回答问题，不知道就不能回答。它可以不知道，但不能乱说。&nbsp; 未来：客户最担心它出什么错？ 元企AI：一类是幻觉。比如企业没有的福利，AI不能凭空说有；岗位月薪8000元，它不能承诺2万元；公司是单休，不能说成双休。 另一类是数据安全。招聘里会涉及账号、简历、候选人信息、搜索记录，这些信息不能泄露，也不能被滥用。 &nbsp; 未来：你们在安全上有哪些具体措施？ 元企AI：首先沙盒我们会做。我们服务不同猎头，他们之间的简历信息不重叠。包括训练大模型，我们用的是脱敏后的用户行为，而不是简历本身。 云端会做相应部署。未来面对一些大客户，我们也会支持本地部署模型，这样资料根本不会上云，可以保存在公司内部。所以我们现在用很多国产开源模型，也是因为未来希望服务需要本地化部署的公司。 另外，算法层面也会做一些安全提升。我们的技术负责人之前做过一些算法研究，比如数据离散化处理、数据加密等。基础安全能力，商用产品肯定会做；一些已经公开发表的核心算法，后续也会运用进来。 &nbsp; 未来：Gartner提醒过，很多Agent项目可能因为成本、价值和风控问题被取消。你们怎么避免变成“agent washing”？ 元企AI：我们也认同这个判断。确实有很多AI应用看起来很fancy，但不是真实需求，也不是可持续付费的东西，而且没有很深壁垒。 比如AI PPT，去年很火，刚出来时用户数很多。但今年很多做AI PPT创业的公司已经没有那么强的存在感。因为它很容易被抄，产品生命周期也比较短。 我们公司成立之初就想好，要做产品矩阵，也要持续进化。比如我们现在比市面产品领先3到6个月，等别人摸清我们的产品后，我们已经进化到下一层，和其他公司保持代际差别。 很多所谓AI招聘产品，其实是过去SaaS公司或RPA产品重新包装出来的。比如五六年前淘宝客服可以回答几天发货、女装尺码，五年后还是只能回答这些问题，因为它本质上是配置知识库，不是自我学习和进化。 我们要做数字员工基座，让它有持续进化能力。对我们来说，关键不是包装成Agent，而是能不能进入业务流、能不能持续交付、成本能不能降下来。 &nbsp; 未来：你们怎么看数字员工的长期趋势？ 元企AI：我觉得将来Agent会是人手一个。 但实际情况是，谁先把产品打磨得更好，谁更懂用户，谁的成本最低，谁才能真正铺开。 很多大厂有资金、数据和资源优势，但它们也有历史包袱。我们和大厂是差异化竞争。大厂更多瞄准大中型客户，我们更希望做AI平权，服务中小用户。 基础蓝领工作和基础白领工作，未来一定会被AI和机器人影响。AI应用会影响基础白领工作，机器人会影响基础蓝领工作。这是一个大的方向。但具体谁能跑出来，还是要看产品能不能真实落地。 &nbsp; 对话曾鸣教授：AI时代，企业竞争的关键是构建智能复利，让AI真正进入业务流程

7月17日，2026世界人工智能大会在上海开幕。作为36氪连续第三年深入WAIC现场的重要内容窗口，「氪话未来」直播间也在大会首日同步开启现场对话。曾鸣教授在WAIC现场接受36氪「氪话未来」特邀专访，围绕AI时代企业增长、组织变革、智能复利、AI原生业务以及企业落地路径等话题，分享了他对于人工智能如何重塑商业模式与价值创造方式的观察与判断。 本届WAIC以“智能伙伴，共创未来”为主题。随着人工智能产业进入应用深化阶段，行业关注点正在从模型能力竞争逐步转向应用价值创造。相比过去几年围绕参数规模、模型性能和技术突破的讨论，2026年的AI产业正在更加关注一个核心问题：AI如何真正进入企业业务流程，如何降低应用门槛，如何通过实际业务结果创造价值。 人工智能竞争格局分析 在讨论当前人工智能领域的竞争格局时，徐新对OpenAI和Anthropic两家公司的策略进行了深入对比。她明确指出，在Ilya Sutskever离开OpenAI之后，该公司在技术创新方面“就差点劲了”。这一观察揭示了核心人才对AI公司竞争力的重要性。 相比之下，Anthropic采用了“只赌一个方向”的专注策略，并且“赌对了”。这种聚焦战略使Anthropic能够在资源有限的情况下，在特定领域建立深厚的竞争优势。徐新认为，这种专注而非分散精力的策略，对于初创公司在与资金充裕的大公司竞争时尤为重要。 高继扬从自动驾驶行业分享了一个关键教训：软件供应商拿不到数据，飞轮效应就跑不起来。在自动驾驶领域，数据是训练算法和持续改进的核心资源。如果软件供应商无法直接获取车辆运行数据，就无法建立有效的学习循环来提升系统性能。这一教训同样适用于整个人工智能行业，数据闭环的设计对于AI公司的长期竞争力至关重要。 ## 价值创造的长期逻辑 在价值创造的问题上，高继扬提出了一个具有洞察力的观点：大脑越用越值钱，硬件越造越便宜。这意味着在人工智能时代，算法的价值会随着使用而不断提升，因为更多的使用会产生更多数据，进而训练出更好的模型；而硬件的价值则会随着规模效应和技术进步而不断降低。 基于这一逻辑，星海图选择同时布局软件和硬件两个领域，而非只专注于其中一个。这种“双轮驱动”的策略既能够保证在算法层面建立核心竞争力，又能够在硬件层面形成差异化优势。硬件作为算法的载体和物理世界的接口，其重要性在于能够将抽象的智能能力转化为实际的生产力和服务能力。 徐新对此表示认同，并进一步阐释了投资中的一个重要原则：在暴涨期要“get big fast”，即快速获取市场份额。她强调，在市场增长的黄金时期抢占到的市场份额是“永恒的”。但这有一个重要前提：所提供的产品必须是“operating system”或“infrastructure”，即操作系统或基础设施级别的产品。 这一观点揭示了科技投资中的核心逻辑：只有成为行业基础设施，才能建立持久的竞争壁垒。如果产品可替代性强，即使短期内获得了市场份额，也可能在后续竞争中失去。只有那些真正定义了行业标准、成为生态系统中不可或缺环节的企业，才能在长期竞争中立于不败之地。 ## 星海图的核心战略与行业壁垒 在对话的最后部分，高继扬分享了星海图三年来保持不变的三句话战略：第一是“一脑多形”，即一个智能大脑可以适配多种形态的硬件；第二是“核心在脑不在形”，强调智能能力本身才是价值创造的核心；第三是“壁垒是物理世界”，认识到在软件算法日益普及的今天，真正的竞争壁垒在于将智能能力落地到物理世界的能力。 “一脑多形”的理念体现了对人工智能本质的深刻理解。智能的价值不在于依附于某一个特定的物理形态，而在于其通用性和适应性。通过开发一个能够适配多种硬件平台的智能大脑，星海图可以在不同的应用场景中快速部署解决方案，从而提高技术的利用效率和商业价值。 “核心在脑不在形”的判断则强调了在人工智能时代，算法和智能能力才是核心竞争力。硬件只是载体，是手段而非目的。这一理念与当前许多科技公司的策略形成对比，后者往往过于关注硬件的形态和外观，而忽视了智能能力本身的持续投入和提升。 “壁垒是物理世界”的认识则揭示了具身智能领域的独特挑战。与纯软件领域不同，具身智能需要解决物理世界中的诸多复杂问题，包括机械设计、传感器融合、运动控制、实时决策等。这些问题不仅需要深厚的跨学科知识，还需要在真实环境中进行大量的测试和迭代。正是这些物理世界中的挑战，构成了后来者的进入壁垒。 ## 总结与核心启示 本次播客对话为听众提供了丰富的投资和创业洞见。徐新作为经验丰富的投资家，展现了对行业趋势的敏锐洞察力和快速决策的能力。她强调在研究新行业时要全面系统，同时也要果断行动，在发现优质项目时迅速出手。 高继扬则从创业者的角度分享了对具身智能领域的深刻理解。他指出改变行业的往往是跨界者，软件和硬件的融合是这一时代的创业新模式。同时，他也提醒听众对具身智能的发展保持理性预期，因为这一领域不会有一蹴而就的“GPT时刻”，而是需要持续渐进的技术积累和场景落地。 从投资角度来看，本次对话的核心启示包括：首先，数据闭环对于AI公司至关重要，软件供应商必须想办法获取数据才能建立飞轮效应；其次，只有成为操作系统或基础设施级别的产品，才能建立持久的竞争壁垒；再次，在市场暴涨期要快速抢占份额，因为这一时期获得的市场地位具有持久性。 从创业角度来看，跨界融合、软硬一体、专注核心能力是制胜关键。大脑（智能算法）越用越值钱的特性决定了持续投入研发的必要性，而壁垒存在于物理世界的认知则提醒创业者不要回避真实世界的复杂性。星海图的“一脑多形、核心在脑、壁垒在物理世界”三原则，为具身智能领域的创业者提供了清晰的发展指引。

# **汽车行业利润大洗牌：整车厂的集体困境与突围之路** ## **整车厂集体“失血”：利润率断崖式下跌** 2026年7月，一位汽车行业高管在内部交流中用了一个形象的比喻来形容当前整车制造环节的处境：整车厂被钉在十字架上，左边要交“智能税”，右边要交“电池税”。这一说法深刻揭示了当前整车企业所面临的双重压力。几乎同一时间，中国汽车工业协会副秘书长陈士华给出了更为具体的数据支撑：2026年上半年，国内整车制造环节的平均利润率已经跌至仅1.5%，这一数字较前几年出现了断崖式下跌。 利润率的持续走低并非偶然现象，而是多重因素叠加的结果。首先，持续已久的价格战成为吞噬整车厂利润的“绞肉机”。从2023年开始，国内汽车市场就陷入了激烈的价格竞争，各大车企为了争夺市场份额不断压低售价，这种竞争虽然在短期内刺激了销量增长，但长期来看严重侵蚀了企业的利润空间。其次，上游原材料成本持续高位运行，锂、钴、镍等动力电池关键原材料价格虽然在2024年有所回落，但整体仍维持在较高水平。此外，更为关键的是，利润正在被产业链两端的新兴环节大量分流——智能驾驶解决方案提供商和动力电池制造商正在蚕食原本属于整车厂的利润蛋糕。 从已经公布业绩预告的上市车企数据来看，亏损面较上年同期明显扩大，多家曾经风头正劲的新能源车企都陷入了不同程度的经营困境。这一轮利润下滑的覆盖面之广、程度之深，在汽车行业的发展历史上都属罕见。整车厂作为汽车工业的核心环节，正在经历前所未有的生存危机。 ## **上游供应商盆满钵满：产业链利润分布失衡** 与整车厂的艰难处境形成鲜明对比的是，上游供应商的日子却过得相当滋润。无论是动力电池企业还是智能驾驶技术提供商，都在2026年上半年交出了亮眼的业绩答卷。宁德时代、比亚迪电池等头部电池厂商的利润率持续保持在较高水平，而华为车BU、百度Apollo等智能驾驶解决方案供应商也实现了营收和利润的双增长。 这种产业链上下游利润分布的严重失衡，折射出汽车产业价值链正在发生的深刻重构。传统汽车时代，整车厂作为产业链的“链主”，拥有最强的话语权和定价权，供应商的利润空间很大程度上由整车厂决定。然而，随着电动化、智能化浪潮的来袭，这种格局被彻底颠覆。电池作为新能源汽车最核心的零部件，其成本占整车成本的30%至40%，电池厂商因此获得了前所未有的议价能力。与此同时，智能驾驶系统作为未来汽车差异化竞争的核心，其重要性日益凸显，提供智能驾驶解决方案的企业正在成为新的“链主”，对整车厂的利润形成新一轮蚕食。 产业变局的背后，是技术变革带来的权力转移。在传统汽车时代，整车厂掌握着发动机、变速箱等核心技术的知识产权，这些技术壁垒为整车厂提供了宽阔的护城河。但在新能源汽车时代，电池技术和智能驾驶技术成为新的核心竞争要素，而这些技术的掌控者往往是独立的供应商而非整车厂。技术话语权的旁落，直接导致了利润分配权的转移。 ## **赛力斯盈转亏：行业困境的典型缩影** 在众多车企的困境中，赛力斯的表现尤为引人关注。2026年第一季度，赛力斯尚且保持盈利状态，但短短几个月后，公司突然发布了盈转亏的业绩公告，第二季度亏损超过20亿元，这一戏剧性的转变让市场哗然。赛力斯的遭遇并非个例，而是整个行业困境的典型缩影。 赛力斯的亏损背后，资产减值成为市场关注的重点之一。随着新能源汽车技术的快速迭代，旧的车型和技术平台面临严重的贬值压力。大量的研发投入、产能建设、设备折旧等沉没成本，在市场环境恶化的情况下被迫计提资产减值，直接冲抵了公司的利润。此外，与华为的合作虽然为赛力斯带来了品牌提升和销量增长，但相应的合作成本和利润分成也成为了公司的一大负担。赛力斯需要在品牌溢价和利润空间之间寻找平衡点，而这正是当前所有与科技公司合作的传统车企面临的共同难题。 从赛力斯的案例可以看出，整车厂当前的困境具有系统性和结构性，不是简单的经营问题，而是整个产业模式面临重塑的体现。无论是传统车企还是造车新势力，都在经历这场前所未有的利润寒冬。 ## # 宏观漫谈：中国经济形势深度解析与未来展望 ## 上半年经济数据总览与整体判断 本期《宏观漫谈》由李翔与李丰共同主持，围绕2024年上半年中国宏观经济形势进行深入探讨。节目首先回顾了上半年经济数据的整体表现，指出当前中国经济正处于结构调整与转型升级的关键时期。从各项指标来看，中国经济呈现出复杂多变的态势，既有积极信号，也面临诸多挑战。两位主持人强调，观察中国经济不能仅看短期波动，更需要在历史长周期中寻找参照系，才能更准确地把握经济运行的内在逻辑。 ## 房地产市场：接近企稳的信号与政府收储策略 节目详细讨论了房地产市场现状，指出一个值得关注的积极信号：今年全国商品房待售面积已连续四个月下降。这一变化表明房地产市场去库存压力正在逐步缓解，供求关系趋于平衡。更值得注意的是，部分城市政府开始收储城区的“老破小”住宅，这一政策动向具有深远意义。政府通过直接介入市场的方式，一方面可以帮助消化部分库存，另一方面也为房地产市场注入了流动性，有助于稳定市场预期。 从政策层面分析，政府收储策略体现了精准调控的思路。“老破小”通常位于城市核心区域，配套设施相对完善，流动性较好，但价格相对较低，是性价比较高的收储对象。政府收储这类房产后，可以用于保障性住房、人才公寓等多种用途，实现一举多得的效果。主持人认为，如果这一趋势能够持续，房地产市场的底部特征将更加明显，行业企稳回升的确定性将进一步增强。 ## 消费数据：基数效应与真实需求的双重解读 关于消费数据，节目进行了细致分析。去年国家补贴政策主要集中在四五月份兑现，导致去年同期消费数据基数较高，形成了一个显著的高基数效应。这种基数效应使得今年同期同比数据面临较大压力，容易造成对消费实际情况的误判。进入六月后，基数效应逐步减弱，消费数据呈现回暖迹象，增速有所回升。 然而，主持人提醒不能过于乐观地解读六月数据改善。由于七月、八月的基数效应进一步减弱，这两个月的数据才能更真实地反映消费需求的实际状况。如果七八月消费增速能够保持稳定增长，才能确认消费市场确实处于复苏通道。因此，当前对消费形势的判断仍需保持审慎态度，需要持续观察后续数据变化。 ## 社会融资结构：长期转型与直接融资崛起 节目对中国社会融资结构的长期变化趋势进行了深入剖析。两位主持人指出，当前中国社会融资结构正在经历深刻变革，这一变化将对未来经济发展模式产生深远影响。传统的以投资驱动、银行信贷为主导的融资模式正在逐步改变，社融总量的增长方式将发生根本性转变。 具体而言，贷款对社融增量的贡献正在逐渐下降，这一趋势具有标志性意义。与此同时，直接融资的占比正在稳步提升，包括政府债券发行、非金融企业在境内市场的股票融资等渠道的重要性日益凸显。这种结构性变化反映了金融体系向更加市场化、多元化方向发展的内在要求。 直接融资比例提高对经济发展具有积极意义。首先，它可以更有效地将社会储蓄转化为投资，提高资金配置效率。其次，直接融资有助于分散金融风险，避免风险过度集中于银行体系。再次，股权融资不产生偿债压力，更有利于创新型企业和高风险项目的融资需求。主持人认为，这一趋势将持续深化，并成为未来金融发展的主要方向。 ## 低息周期的战略意义与多重效应 节目重点分析了当前低利率周期的战略价值，指出维持低息环境有助于解决三个核心问题。第一是置换地方隐性债务。在高利率环境下，地方融资平台承担的债务利息负担沉重，还本付息压力巨大。低息环境可以大幅降低债务成本，通过债务置换将高成本债务转化为低成本债务，有效缓解地方债务风险。第二是刺激宏观经济。降低利率可以降低企业融资成本，刺激投资需求；降低居民房贷负担，释放消费潜力，从而形成扩大内需的良性循环。第三是激活居民存款。存款利率降低将促使居民重新配置资产，寻找更高收益的投资渠道，这有利于资金从银行体系流向实体经济，提高资金使用效率。 ## 居民存款波动：短期行为与长期趋势 关于居民存款数据，节目进行了详细解读。四、五月份居民存款出现了连续减少的情况，这一现象引发了市场关注。主持人分析认为，存款减少可能与几方面因素有关：部分居民将存款转化为理财产品或基金等投资产品；购房需求回升带动部分资金流出银行体系；消费信心改善导致即期消费支出增加。 然而，六月份数据显示居民存款又转为增加，这一反复表明当前居民资产配置行为存在较大波动性。主持人指出，不能从单月数据变化中得出过于确定的结论，居民存款走势需要更长时间的观察才能看清趋势。当前居民在存款、投资与消费之间的权衡更加频繁，资产配置行为趋于多元化，这与居民收入水平提高、金融素养提升密切相关。 ## 外贸形势：强劲表现与可持续性分析 节目最后讨论了上半年中国外贸的强劲表现。从数据来看，中国外贸进出口保持了较好增长势头，在全球贸易增长乏力的背景下显得尤为突出。主持人分析认为，这一成绩的取得得益于多方面因素：产业链供应链的完整优势持续发挥作用；出口产品结构不断优化，高附加值产品占比提升；与“一带一路”沿线国家贸易增长迅速，新兴市场开拓取得成效。 关于外贸强劲势头是否可持续，主持人持审慎乐观态度。短期内，全球经济复苏步伐、贸易保护主义动向、汇率波动等因素仍存在较大不确定性，可能对中国外贸造成扰动。但从中长期看，中国制造业的竞争优势、完善的产业配套体系、不断增强的创新能力，都为中国外贸持续发展提供了坚实基础。关键在于要持续推进贸易结构优化升级，培育新的外贸增长点。 ## 总结与核心启示 综合本期节目内容，可以得出以下核心启示：中国经济正处于从高速增长向高质量发展转型的关键阶段，这一过程必然伴随着结构优化与动能转换。从房地产市场的积极变化、消费数据的边际改善，到金融结构的深层变革，都反映出经济运行中的积极因素正在积累。低利率政策环境为经济转型提供了相对宽松的宏观条件，但其效果需要时间来传导和显现。 对中国经济的观察需要保持历史耐心和战略定力。短期波动不应动摇对长期趋势的判断，结构性问题的解决需要持续努力而非一蹴而就。未来中国经济的发展质量，将取决于能否在稳增长与调结构之间找到最佳平衡点，能否在深化改革与防范风险之间实现有机统一。这些问题的答案，需要在实践中不断探索和检验。

# AI时代的机遇与挑战：从市场泡沫到企业转型 ## 当前AI市场与互联网泡沫的历史对比 播客开篇深入探讨了当今人工智能市场与上世纪九十年代末互联网泡沫之间的相似性与差异性。讨论指出，虽然表面上看，当前的AI投资热潮确实呈现出某些令人担忧的泡沫特征——大量资本涌入、初创企业估值飙升、各行各业纷纷宣称要拥抱AI技术——但深入分析后会发现两者存在本质区别。互联网泡沫时期，许多企业的商业模式并不清晰，更多是概念炒作；而当前的AI浪潮虽然也存在过度炒作的成分，但人工智能技术本身已经展现出实实在在的商业价值和生产力提升潜力。泡沫讨论部分并没有简单地得出非黑即白的结论，而是强调投资者和企业家需要具备识别真正价值创造与纯粹概念炒作的能力，避免盲目跟风或一刀切地否定整个行业。 ## 企业AI应用的现实困境与挑战 这是播客中最为核心的讨论部分，嘉宾详细阐述了为什么企业级AI应用远比预期更加困难。首先是数据质量问题，企业内部往往充斥着大量非结构化、格式不统一、缺乏标注的历史数据，而机器学习模型对数据的质量和数量都有严格要求，数据准备阶段往往占据整个项目的大部分时间和资源。其次是集成复杂性，企业现有的IT系统经过多年发展，形成复杂的遗留系统架构，将AI能力无缝嵌入这些系统需要大量的定制开发工作。第三是组织变革的阻力，AI的引入往往意味着业务流程的重新设计甚至岗位的调整，员工对技术变革的恐惧和抵触是项目推进中不可忽视的软性障碍。第四是投资回报难以量化，与购买一套ERP系统可以明确计算成本收益不同，AI项目的收益往往是渐进的、间接的，难以用传统的财务指标衡量。这些因素共同导致了大量企业AI项目延期、超预算甚至失败，使得业界对AI的期待逐渐回归理性。 ## 工作空间的AI转型路径 针对如何实现向AI优先工作空间的过渡，播客提出了一套渐进式的转型框架。转型不应追求一步到位的大爆炸式变革，而应从小处着手、持续迭代。具体的实施策略包括：识别组织内部最痛点最高、容错率相对较高的业务流程作为试点；建立专门的AI卓越中心负责技术选型、人才培养和最佳实践沉淀；构建清晰的治理框架解决AI应用中的伦理、隐私和合规问题；重视员工培训和变革管理，帮助员工理解AI是增强而非取代人类能力的工具。嘉宾特别强调，成功的AI转型不仅是技术项目，更是一场组织文化的深刻变革，需要高层领导的坚定承诺和持续投入。 ## 健康医疗领域的AI革新 健康与AI的交叉话题引发了热烈讨论。自我导向医疗的概念被提上议程，即借助AI工具，个人能够更主动地管理自己的健康状况。 wearables和其他生物特征数据收集设备的普及，使得持续监测心率、睡眠质量、运动数据成为可能，这些数据与AI分析能力结合，能够为个人提供个性化的健康建议和早期疾病预警。然而，讨论也深入分析了其中的风险和挑战：生物数据的隐私保护至关重要，一旦泄露可能造成严重的个人隐私侵犯；AI健康建议的准确性需要严格验证，错误的健康指导可能带来危险后果；人类医生在复杂病例判断和医患情感交流中的作用仍然不可替代。嘉宾主张AI应定位为医疗专业人员的辅助工具，增强而非取代医生的专业判断。 ## AI在政治与真相寻求中的角色 这一部分探讨了一个颇具争议的话题：AI能否成为对抗虚假信息、促进社会真相寻求的力量。讨论承认，AI确实具有识别和标记虚假内容的潜力，先进的自然语言处理技术能够分析文本的可靠性、检测逻辑谬误、交叉验证事实陈述。同时，AI也可以帮助公众更便捷地获取和理解复杂的政策信息，降低政治参与的门槛。然而，嘉宾也清醒地指出这一愿景面临的深层挑战：AI本身也可能被用于生成更具说服力的虚假信息，形成一场军备竞赛；不同AI系统可能内置不同的价值观和政治倾向，难以保持绝对的中立性；真相本身在某些议题上就存在合理分歧，AI难以充当终极仲裁者角色。关于财富税等政治经济议题的讨论，嘉宾强调任何技术手段都无法替代民主协商和政治判断，AI的作用应限于信息处理和分析支持层面。 ## 核心启示与未来展望 综合整期播客的讨论，可以提炼出以下核心启示：第一，对AI市场的评估应保持理性，既不要被泡沫恐惧所裹挟全盘否定，也不要盲目乐观忽视风险。第二，企业AI应用需要做好长期作战准备，将数据基础设施、人才培养和组织文化建设作为基础性工作。第三，AI转型是渐进过程，成功的关键在于选择合适的切入点、保持组织上下对愿景的共识、以及建立有效的容错和迭代机制。第四，AI在健康医疗、政治参与等敏感领域的应用需要格外谨慎，建立完善的伦理框架和监管机制是必要前提。第五，尽管AI展现出强大的潜力，但它既非万能灵药，也非洪水猛兽，其最终价值取决于人类如何设计、应用和治理这项技术。未来已来，唯有以务实、理性和负责任的态度拥抱AI，才能真正实现技术赋能而非技术依赖。

短期企稳的关键要素 关于全球科技股短期能否企稳，播客明确指出三个关键观察点： **韩国融资余额的变化**是首要考量因素。作为全球重要的融资市场，韩国融资余额的变动直接影响市场流动性供给。当融资余额持续下降时，说明市场去杠杆过程尚未结束，反弹动力不足。 **客户保证金水平**反映投资者信心和参与意愿。保证金下降通常意味着投资者要么被迫平仓，要么主动降低风险敞口，这都会抑制市场的反弹动力。 **政策流动性支持**是市场稳定的外部保障。当市场出现流动性紧张时，政策制定者是否及时提供必要的流动性支持，将直接影响市场能否实现软着陆。 这三个要素相互关联，共同决定了科技股能否在短期实现企稳。投资者应当密切关注这些指标的动态变化，作为判断市场走势的重要依据。 ## AI行情进入中盘阶段的特征 播客明确提出，当前AI行情已经“棋至中盘”，这意味着产业发展进入了一个关键转折点。市场关注点发生了根本性转变：从早期的技术突破和债务融资，进一步转向模型商业模式的可行性、行业渗透率的实际增长、Token价格走势和企业的变现能力。 这一转变反映出投资者对AI产业的认知正在成熟。早期市场更关注技术本身的先进性和公司投入的规模，但随着时间推移，市场开始更加理性地评估这些投入能否转化为可持续的商业回报。 在这个阶段，各方竞争的重点也从“谁投得多、谁的算力更强”转向“谁的商业模式更清晰、谁的变现能力更强”。这种转变要求AI企业必须证明其技术优势能够转化为实际的收入增长和利润贡献，而不是停留在概念炒作层面。 ## AI对中国经济的支撑作用 从宏观经济角度分析，AI仍是中国出口和高技术制造业的重要支撑力量。然而，播客也指出了一个值得关注的趋势：目前出口增长主要依赖价格因素，这意味着数量的增长相对有限。 进入四季度后，高基数效应可能会削弱AI对出口贡献的力度。投资者需要对此有充分预期，不能盲目乐观地认为AI相关出口会持续保持高速增长。 与此同时，国内经济内生动力并未出现明显恶化迹象。基于当前的经济数据分析，二季度可能是全年的低点，后续经济运行有望逐步企稳回升。这种判断为政策制定提供了重要的参考依据。 ## ## AI 泡沫下的存储股：周期与成长的博弈，长期价值何在？ 近期，韩日美三国股市剧烈震荡，全球科技股承压，中国股市亦随之摇摆。投资者心中最大的疑问是：“AI 泡沫要破了吗？”要回答这个问题，必须首先厘清一个核心矛盾：本轮行情中涨幅最凶猛的存储股（如韩国SK海力士等），其本质到底是 **周期股** 还是 **成长股**？这一界定将直接决定其未来的股价走势与长期投资价值。本期播客深度剖析了存储芯片产业的周期性与成长性，并对“海力士们”的估值逻辑提出了深刻反思。 ### 何为周期股？一个经典的财务定义 理解存储股的属性，首先要明确“周期股”的概念。从财务报表角度看，周期股具有一个显著特征：**利润波动极大**。当行业处于上行周期时，产品供不应求，价格上涨，企业利润会呈现爆发式增长，甚至达到骇人的高度；但一旦进入下行周期，产能过剩，价格暴跌，利润会迅速萎缩，甚至转为巨额亏损。 这种特性与成长股形成鲜明对比。成长股通常能实现持续的、可预期的利润增长，其股价更多由未来的增长潜力驱动。而周期股则像一个“过山车”，其股价与宏观经济、行业供需的周期性波动高度相关，投资者往往需要精准预判周期的拐点，才能获利。存储芯片的核心产品——DRAM（动态随机存取内存）和NAND Flash（闪存），其价格和利润的历史表现，高度符合周期股的这一经典特征。 ### 存储股是周期股吗？历史数据中的九大周期 答案是**毫无疑问的“是”**。以DRAM内存为例，自其诞生以来，已经历了至少**九个完整的周期循环**。每个周期都遵循着相似的轨迹：需求爆发 -> 产能不足 -> 价格上涨 -> 厂商疯狂扩产 -> 产能过剩 -> 价格暴跌 -> 利润崩溃 -> 厂商削减投资 -> 市场出清 -> 新一轮需求复苏。 播客中详细梳理了DRAM的九大周期，从早期的PC（个人电脑）时代，到后来的服务器、智能手机时代，再到如今的AI（人工智能）时代。每一个周期中，当新的“杀手级应用”出现，对内存需求剧增，如2000年前后的互联网浪潮、2010年代初的智能手机爆发，都会推动一轮强劲的增长。然而，随着厂商对前景过度乐观，大量投资的新建工厂（Fabs）集中投产，供给过剩必然导致价格崩塌。例如，2018-2019年的周期性衰退，就曾让三星、海力士、美光等存储巨头的利润大幅下滑，股价腰斩。 因此，从历史规律看，存储股是不折不扣的周期股。它的股价表现，与其说是由未来的增长故事决定，不如说是由当下的存储芯片“现货价格”走势所主导。每当价格上涨，股价跟随上扬；每当价格下跌，股价亦随之坠落。这种高度同步性，是周期股的典型特征。 ### 对存储芯片的估值逻辑变了？成长性与周期性的悖论 然而，本次由AI算力革命引发的存储需求爆发，似乎让市场看到了“成长性”的曙光。传统的周期性逻辑，正面临一个前所未有的挑战：**AI带来的需求增量，能否彻底改变存储芯片的“周期之王”属性，将其转化为长期稳定增长的成长股？** 核心论点在于，AI大模型的训练和推理，对高带宽内存（HBM，High Bandwidth Memory）产生了指数级的需求。HBM并非传统的内存，它是一种将多个DRAM芯片垂直堆叠，并通过先进封装技术互联的高速、高容量内存，是处理海量数据的关键。拥有领先HBM技术的SK海力士，几乎是英伟达AI芯片的独家内存供应商，其订单可见度、利润率、技术壁垒都远超以往任何一次内存周期。 支持“成长论”的观点认为：首先，**技术壁垒极大提升**。HBM的制造工艺极其复杂，良率提升困难，新进入者难以在短期内复制，这打破了以往“同质化竞争、靠规模取胜”的周期模式。其次，**需求结构发生质变**。AI算力需求的增长远非线性，而是爆炸式的，这将为存储巨头提供远超以往的“确定性增长”，而非过去的“脉冲式需求”。最后，**供需格局被重新定义**。由于AI客户（如英伟达、谷歌、微软）集体锁定产能，并愿意签订长期合同，这使得存储厂商的利润预期比过去更加稳定。 ### 总结与核心启示 **总结：** **GPU的蜕变：从游戏显卡到AI算力的基石** 在本次节目中，英伟达的转型故事被作为一个重要的案例来分析。GPU，即图形处理器，最初的设计目的是处理图形渲染任务，主要应用于电脑游戏和图形设计领域。然而，随着深度学习技术的兴起，人们发现GPU的并行计算架构非常适合处理大规模矩阵运算，这恰恰是神经网络训练的核心需求。 张从志详细讲述了英伟达如何敏锐地捕捉到这一技术转向，并果断调整公司战略的过程。英伟达很早就开始布局通用计算领域，推出了CUDA计算平台，为开发者提供了在GPU上进行通用计算的便利工具。当人工智能浪潮来临之际，英伟达已经积累了深厚的技术储备和生态系统优势，成功从一家游戏显卡厂商蜕变为AI时代的算力巨头。 这一转变的深远意义在于，它展示了技术发展的非线性特征。一个看似专注于游戏产业的硬件公司，凭借其技术架构的内在优势，在短短几年内就成为支撑整个人工智能产业发展的基础设施供应商。这种转型不仅需要技术眼光，更需要对产业发展趋势的准确判断和持续的技术投入。 ## **芯片制造：从一粒沙子到科技明珠的漫长旅程** 节目中用了相当篇幅详细介绍了芯片从设计到成品的完整制造流程。张从志将这个过程概括为“漫长旅程”，因为一枚芯片的诞生确实需要经历多个极其复杂的阶段，每一个环节都凝聚着人类工业文明的最高智慧。 首先是芯片设计阶段。现代芯片设计采用电子设计自动化软件（EDA），工程师们在计算机上完成数十亿晶体管的布局布线工作。设计完成后，版图数据被送到晶圆代工厂开始制造。晶圆厂是芯片制造的核心环节，需要在极度洁净的环境中进行操作。张从志用“奶牛屁都能影响良率”这一形象的说法来形容洁净车间的要求之严格——空气中的微小颗粒、甚至是气体成分的变化，都可能导致芯片报废。 晶圆制造主要采用光刻技术，而光刻机无疑是其中最关键也最“卡脖子”的设备。目前全球高端光刻机市场几乎被荷兰阿斯麦公司垄断，尤其是用于先进制程的极紫外光刻机（EUV）。节目中提到，除了光刻机之外，芯片制造过程中还有许多其他关键环节同样存在技术壁垒，比如高纯度硅片的制备、特殊气体的供应、高端光刻胶的研发等，每一个环节都需要长期的技术积累和大量的资本投入。 制造完成的晶圆还需要经过封装测试环节才能成为可用的芯片。封装厂通常位于晶圆厂附近，负责将晶圆切割成单独的芯片 die，进行封装保护，并进行功能测试。张从志介绍，封装环节虽然技术含量相对较低，但同样是芯片产业链中不可或缺的一环，近年来随着chiplet等新技术的兴起，封装技术的重要性也在不断提升。 ## **摩尔定律的终结与产业新挑战** 摩尔定律是半导体产业过去数十年发展遵循的核心规律，由英特尔创始人戈登·摩尔在1965年提出，其内容是集成电路上可容纳的晶体管数量大约每两年翻一番，同时价格下降一半。这一定律在过去半个多世纪里被反复验证，成为半导体行业技术路线规划的基本准则。 然而，节目中指出，摩尔定律正在走向终结。随着晶体管尺寸越来越接近物理极限，芯片制造的成本急剧上升，每一代技术进步所需的研发投入呈指数级增长。3纳米、2纳米制程的研发已经触及硅基材料的物理极限，继续缩小晶体管尺寸面临的挑战越来越大。 摩尔定律的终结并不意味着芯片产业的停滞，而是意味着产业发展进入了一个新的阶段。张从志认为，未来的技术突破可能来自多个方向：新的材料（如碳纳米管、二维材料）、新的架构（如存算一体、chiplet）、新的计算范式（如量子计算、神经形态计算）等。芯片产业的创新空间依然广阔，只是创新的路径发生了变化。 ## **中国芯片产业的追赶之路** 节目中还重点讨论了以中芯国际为代表的中国芯片企业的追赶历程。张从志客观分析了国产芯片产业面临的机遇与挑战。一方面，中国是全球最大的芯片消费市场，拥有完整的电子产业链和庞大的工程师人才队伍，政府也在政策上给予了大力支持。另一方面，中国芯片产业在先进制程、关键设备、核心材料等方面与国际先进水平仍存在差距，需要在技术封锁的压力下实现自主创新突破。 这是一场需要耐心、资本和代际传承的漫长征程。张从志强调，芯片产业不同于互联网等快速迭代的行业，它需要长期的技术积累和持续的资金投入。喧嚣之下的短期炒作无法真正推动产业进步，只有长期主义精神和一代代技术人才的默默付出，才能让中国芯片产业真正建立起核心竞争力。 ## **核心启示** 本期节目为我们全面展示了芯片产业的真实面貌。芯片不仅是一种技术产品，更是现代文明的基石和国与国之间科技竞争的核心战场。从一粒沙子到数十亿晶体管的精密集合，芯片的诞生凝聚了人类工业文明的最高智慧。当前全球芯片产业正处于深刻变革期，摩尔定律走向终结、新兴技术不断涌现、国际竞争日趋激烈。在这一背景下，无论是国家还是企业，都需要保持战略定力，坚持长期主义，以持续的投入和代际传承来应对这场没有终点的科技竞赛。对于普通公众而言，理解芯片产业的复杂性有助于我们更理性地看待各种“卡脖子”问题和技术突破的来之不易。

**基础指标**：每秒请求数（QPS）、首次响应时间（TTFT）、每 token 费用、总费用。 - **业务指标**：任务成功率、输出质量评分（如基于人类评估或自动评估模型）。 - **测量工具**：DevEx 提供实时监控面板，能够按业务线、API 端点、模型子版本拆分费用与性能。Poly 则提供 Agent Harness，可对同一任务在 Sol、Terra、Luna 上分别运行并对比结果。 - **实验设计**：采用 A/B 测试或金丝雀发布的方式，确保对照组与实验组在同一时间段、相同流量分布下进行比较，避免流量波动导致的偏差。 **成本-性能优化实践** - **批处理与缓存**：对相同或相似的请求进行批量调用或使用缓存（如基于向量相似度的检索缓存），降低整体 token 消耗。 - **Prompt 压缩**：通过去掉冗余信息、使用简化的指令模板，将平均输入 token 数降低 15%–30%。 - **模型蒸馏 & 级联**：利用 Sol 生成高质量答案后，将结果作为 Terra 的示例进行微调；在对质量要求不高的环节直接使用 Luna。 - **资源调度**：在业务高峰期自动提升 Terra 的副本数，低谷期则缩减至 Luna 实例，以实现弹性伸缩。 - **费用预警**：设置每日/每周费用上限，一旦接近阈值即触发告警并自动降级至低费用模型。 **适配评估（Evals）与 Agent Harness 的关键点** - **标准化评估集**：使用公开评测集（如 MMLU、GSM8K）和业务特定数据集，定期对 Sol、Terra、Luna 进行对比。 - **阈值校准**：根据业务容忍度，为每个子模型设定质量阈值（如 BLEU、ROUGE 或自定义任务成功率）。 - **模块化 Harness**：Poly 的 Agent Harness 采用插件化设计，能够在不同模型之间无缝切换，并记录每次调用的上下文、输入、输出及费用。 - **持续监控**：在 CI/CD 流程中集成评估任务，确保模型升级或配置变更后仍满足质量与成本要求。 **生产迁移的关键步骤** 1. **基线测量**：在现有模型（如 GPT‑4）上完整记录 QPS、TTFT、费用与业务指标。 2. **目标模型选型**：依据任务分布图谱确定 Sol、Terra、Luna 的比例（如 20% Sol、50% Terra、30% Luna）。 3. **灰度发布**：先在 5% 流量上启用新模型，监控关键指标是否出现显著偏差。 4. **逐步扩容**：若灰度结果符合预期，逐步提升流量至 30%、50% 直至全量。 5. **回滚机制**：设定回滚阈值（如 TTFT 超过 1.5 倍基准或费用提升 10%），自动回退至旧模型。 6. **文档与培训**：编写模型迁移手册，确保业务团队了解模型特性、费用归属以及监控面板的使用方法。 **总结与核心启示** - **模型并非越大越好**：依据任务复杂度选择合适的子模型（Sola / Terra / Luna），能够在保证输出质量的前提下显著降低费用。 - **成本-性能是双向优化**：通过实时监控、动态路由、批处理与 Prompt 压缩等手段，实现成本与响应速度的协同提升。 - **评估与监控不可缺失**：标准化的 Evals 与细粒度的 Agent Harness 是保证迁移安全、持续改进的基石。 - **弹性伸缩与告警是关键**：在高峰期自动提升资源、在异常时快速降级或回滚，可避免因突发流量导致的高额费用或服务质量下降。 通过系统化的模型选型、精细化的成本-性能度量以及结构化的迁移流程，团队能够在每 token 的使用上实现“价值最大化”，在提升业务竞争力的同时保持技术成本的可持续性。

总结与核心启示 这次对话为我们呈现了一位连续创业者在不同人生阶段的思想演变。Kalanick 从 Uber 的激进扩张到 Atoms 的沉稳深耕，体现了创业智慧的成长和蜕变。他的经历告诉我们：创业不是一场短跑而是一场马拉松，需要在激进与稳健之间找到平衡。 **核心启示一：创始人应该珍惜对公司的主导权**，因为公司的创新精神和执行效率往往与创始人的参与程度密切相关。职业化管理虽然可以带来专业化优势，但也可能稀释公司的创业文化和敏捷响应能力。 **核心启示二：下一个技术革命的主战场在实体行业**。软件创新已经进入成熟期，而工业 AI、机器人技术、自动化系统等领域仍然存在着巨大的技术和商业空间。那些能够将软件智能与硬件能力深度融合的创新者将引领下一波技术浪潮。 **核心启示三：stealth 模式在特定场景下仍然有价值**。对于需要长周期研发、涉及核心技术突破、竞争环境激烈的创业项目，适当的保密可以帮助企业保持竞争优势，避免过早暴露技术路线和商业策略。 **核心启示四：创业者的使命应该超越商业本身**。当技术创新能够解决人类面临的真实挑战——无论是食品安全、能源效率还是生产安全——这样的创业项目不仅具有商业价值，更具有深远的社会意义。Kalanick 从网约车转向工业 AI 的选择，某种程度上反映了他对这种更高层次创业使命的追求。
