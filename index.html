路线，几乎没有人认为曹越选择的自回归（Autoregressive）路线是一种正解。 而在2025年初，发布基于自回归架构训练的模型 Magi-1 后，曹越很快意识到“只有画面是不够的”，于是团队开始探索音画同出。后来，Sand.ai 成为了除了Google VEO 3之外最早拿出音画同出模型的团队，Magi-1也在 Google DeepMind 的 Physics IQ benchmark 我们从第一天就认为，自回归是对视频数据最本质的建模方式。市场上大家都在做纯 Diffusion 模型的时候，我们认为视频在时序上一定是因果关系，很多物理规律，本质是一个随着时间变化的函数 —— Predict Next Frame（预测下一帧）、Predict Next Second（预测下一秒），这是对视频这种数据最本质的训练范式。我们是最早探索自回归视频生成的团队，去年发布的 Magi-1 在 Google-DeepMind 提出的物理真实性测试榜单 Physics-IQ 中取得第一，并长期保持领先，超越了 Nvidia 最新推出的旗舰级世界模型 Cosmos3-Super ，更远超 Sora-2 等其他纯 Diffusion 模型。 音画同出不只是功能升级，它是对世界状态更完整的压缩。我们发布 Magi-1 之后发现，只有画面是不够的。声音和画面天然对齐，同时生成会让两者互相帮助——音画同出之后，哪怕只看画面，真实感也显著提升。本质上，同时拥有画面和声音，更接近对这个世界状态的表达，维度更高。所以我们在去年 5 月就开始探索音画同出，是除了 Google Veo-3 之外最早拿出音画同出模型的团队。 视频模型存在的不可能三角是：成本、速度、效果。去年我们就认为，只能靠研究突破， MoE 就是答案。2025年我们决定转向 MoE，当时市场上没有几乎没有什么视频模型厂商公司全力在做这件事。这是因为，发布音画同出模型 Gaga-1 之后，我们发现 Dense 模型继续 Scale Up 成本会直线上升——如果用 Dense 架构做到同样效果，推理成本至少贵 3 到 5 倍，训练成本也是。我们在那个时间点没有看到任何一家公司在做视频 MoE 我们认为，视频数据是走向世界模型最重要的数据类型。首先，视频数据是对世界观测数据里，规模最大的数据类型。它同时编码了时间、空间、视觉、听觉——是4D物理世界经由摄像头投影后的结构化切片，在所有可获取的世界观测数据中，信息密度最高、维度最丰富、体量最大。视频远不止画面，视频中保留的信息远比直觉上更多，触觉、温度、材料属性、甚至意图和情感，大量在人类感知中属于其他模态的信息，也被编码在视觉和听觉的时序变化中。 有人说要“预测下一状态”，但没有人能帮助模型定义“状态”究竟是什么。很多人认为直接预测（Observation）可能会有很多冗余，效率不够高，从而希望人为定义状态（State）来提高其训练效率。这个教训LLM已经演示过一遍了——多少人试图显式建模词的表征、句子的表征、段落的结构，阶段性也确实被证明“高效”，但最终在规模化的路线上，全被 predict next token 杀死了。我们不应该在多模态建模上重蹈覆辙。历史已经反复证明，每次试图用人类先验去拆解世界，本质上都是在低估它的复杂度，建议全文背诵The Bitter Lesson（苦涩的教训）。我们认为，真正该预测的不是任何human-defined的隐藏状态，而是世界本身给你的原始观测——建模raw data（在视频里即pixels、frames、video）未必是阶段性最高效的方案，但大概率是最Scalable、上限最高的方案。如果要给世界模型定义几个要素，第一，它的核心是预测——但要警惕用人类先验去定义“该预测什么”；第二，它需要足够完整、多维度的数据来压缩真实世界的信息；也就是要能从当前的观测直接推演下一刻的观测，而不是从一个人为定义的隐藏状态推演下一个状态。从这个角度看，今天大家讲的很多“世界模型”，其实还只是很早期的东西。真正的世界模型，不是生成一段看起来合理的视频，而是要理解一个 3D 空间加时间轴上的世界，并且能够持续预测下一刻的真实观测。 视频生成模型的演进，也是在一步步逼近世界模型的过程。你可以把视频模型的演进想象成一个孩子认识世界的过程。最开始他只能看照片，世界是静止的——这就是图像生成。然后画面动起来了，他能看动画了——这就是早期的视频生成。再然后画面有了声音，风声、脚步声、碰撞声都出来了——这就是音画同出。接着他发现换个角度看同一个房间，桌子椅子还在原来的位置——这是3D空间一致性。慢慢地，他知道杯子推到桌边会掉下去——这是因果关系。最后他能伸手推门，门真的会开——这就是实时交互。重点是：没有人给这个孩子塞一本物理课本，告诉他“重力是9.8、声速是340”。他就是从看到的、听到的越来越完整的观测里，自己搞明白了世界怎么运转的。视频模型的演进，走的是一模一样的路——不是人为给模型定义“状态变量”，而是让它从越来越完整的观测中，自己长出对世界的理解。 作为一家创业公司，阶段性还是要想明白你的“加油站”在哪。对于创业公司而言，训练出 SOTA 的视频生成模型后，可以做内容生产，可以卖 Token，可以做 Agent。内容生产天然是一个巨大的方向，它的闭环周期比类似具身这样的领域要快得多，你可以一步一步走到终局（AGI）。 要做模型，也要做产品 做模型的公司做垂直整合之后，成本和体验都会更好。为什么要模型和产品都做？Claude Code 就是这样——Cursor 占了 Claude 很大比例的 API 调用，所以 Anthropic 看到以后，就自己做了。所以如果要抓住大的机会，你必须有训练 SOTA 模型的能力，纯产品公司在这个阶段会很难。 但在视频模型方向上，你很难只做一个卖 API 的公司，你还是得自己做产品，模型和产品必须双轮驱动。在 AI 视频这个大方向上，模型和产品是距离很近的，非常明确地能吃到算力红利和数据红利，它拥有 Scaling Law。我们认为看一个产品方向的时候，终局可能相对容易想清楚，但切入点和路径不容易想清楚。所以，你需要有多产品矩阵的能力。我们是以模型为核心的多产品矩阵打法——VidMuse&nbsp;是其中一个探索，之前的Gaga模型发布后探索数字人也是如此，未来我们还会有新的产品。 模型和产品的目标可能有夹角，在创业公司里可能更好解决。模型和产品有冲突怎么办？关键是你怎么处理这个夹角。对比大厂，创业公司的优势是：你可以让模型负责人和产品负责人都是公司最核心的人，他们和公司目标对齐，拥有 Founder Mode，让他们内心深处认为公司成功是最终目标，而不只是“我要把我这块业务做成”。如果产品负责人觉得模型好坏跟产品无关，那当然没法平衡。但如果他有创业精神，他会想“模型侧有没有我能帮忙的”。 我们现阶段的产品策略是，找泛 AI 视频赛道当下时间点有大杠杆的事情。AI 视频这个方向能做的产品就那么几大类：模型产品、泛Agent 产品、内容消费类产品。我们选了 Agent 方向，VidMuse 今年年初上线，两个月我们就做到 1000 万美金 ARR，说明这个方向的商业化是成立的。用户每天生成各种内容，我们可以端到端收到用户的偏好——他认为什么好、什么不好。这些反馈有机会帮助模型的的后训练。我们的产品也不局限于只调用自己的模型，过程中收集的数据反馈，能让自己的模型效果更好。 视频领域过去两年一直是模型牵引产品。模型每解锁一个能力，产品侧就少搭一层脚手架。以前没有多镜头，产品侧就得想办法解决怎么做多镜头；没有音画同出，就得配音配剪辑。现在这些都有了，帮模型兜底的事越来越少。但上面那层产品工作一直都在，只是内容发生了变化——模型能实时生成了，C 端就有新玩法。 我们的开源模型在持续贡献价值。大公司最大的问题就是人多，大家在同一个代码库写代码，混乱程度增加。我们会通过组织设计让算法和 Infra 更有效地解耦合作，用更少人产生更大价值。我们开源的 MagiAttention 算子库现在被国内几乎所有多模态模型团队使用，英伟达官方也推荐用它训多模态模型。 我很少思考什么是共识、什么是非共识。我只思考什么是本质的、什么是对的。共识的本质是你在思考大多数人怎么想，而不是从事情本身出发做第一性原理的思考。一旦你过于关心他人的认知，大概率就不是在从第一性原理思考问题了。 视频模型是牌桌逻辑，最后留下三五家 Seedance 2.0的爆发，向市场证明了多镜头叙事是重要的。音画同出是Veo3先实现，多镜头叙事是Sora2先实现，但Sora在多主体参考、多镜头叙事的细节效果上做得不够。而Seedance 2.0 的爆发，是因为把这些维度补齐了，比如多镜头叙事上打磨得更扎实，细节也更精细，加上模型Scale Up和数据处理做得好，在这个阶段就吃到了一波红利。 视频模型的垄断程度，不会比语言模型更高。现在视频模型的竞争烈度还没有语言模型这么高。现阶段视频和语言模型差不多，领先窗口大概在两三个月。一个模型在某个时间切片上如果可以 SOTA，那个阶段呈现垄断状态是正常的。不过我觉得行业很快都会追上这个水平，那么每一家份额就会被稀释，最终不会有一家吃掉 95%，大概率是牌桌上留下三五家，一起分这个巨大的市场。重点是只要你一直在牌桌上，就有机会吃到可观的一部分。 OpenAI 关停 Sora，是一次合理的战略收缩。Sora 2 本身还是挺惊艳的，我觉得关停这个业务有它合理的逻辑。一是OpenAI 要上市，得阶段性优化短期目标，快速交出漂亮的结果；二是 OpenAI 在 Coding 上已经落后了，而 Claude 领先的Coding模型能把算力直接转化成现金流。所以，在 Sora App 投入了巨大的算力却没换来一个足够可观的产品的情况下，把这部分算力平移到 Codex模型中，更可能撑起上市的业绩，所以这是在有短期上市预期加之主营业务落后下的战略收缩，他们做这个决策是合理的。 为什么中国能够快速在视频模型上做到世界 Tier 1？我觉得这跟起步早晚有关。我们语言模型起步是偏晚的，国外从 GPT-1 、GPT-2 那时候就开始积累，这里面会有很多训练的 know-how，但国内是 # 自我加速人工智能：重塑科技发展新范式 **开启AI发展的新纪元** 在人工智能领域日新月异的今天，一个根本性的问题正在引发业界顶尖研究者的深度思考：当AI系统不再仅仅是人类手中的工具，而是能够为自身的进化做出实质性贡献时，整个科技发展的轨迹将会发生怎样的转变？这一问题的提出者，正是曾在谷歌和Anthropic两大科技巨头主导研究工作的Behnam Neyshabur和Harsh Mehta。他们共同创立了Mirendil公司，将全部精力投入到探索“自我加速人工智能”这一前沿领域，旨在从根本上重新定义人工智能与科技发展之间的互动关系。 **从工具到伙伴：AI角色的根本转变** 长期以来，人工智能在大多数应用场景中都被定位为提升人类生产力的工具。无论是自动化日常任务、优化业务流程，还是辅助决策分析，AI的价值主要体现在替代或增强人类在特定领域的操作能力。然而，Mirendil的创始人们认为，这种定位虽然具有重要的实用价值，但却远远未能触及AI真正的变革潜力。他们指出，如果我们仅仅将AI视为服务于人类既有目标的工具，那么我们可能正在错失一个更为深远的历史机遇——让AI系统深度参与科学发现和技术创新的核心过程，成为推动人类知识边界不断拓展的真正伙伴，而不仅仅是被动的执行者。 两位创始人在谷歌和Anthropic的工作经历为他们提供了独特的视角。在这些顶尖研究机构中，他们亲眼见证了AI技术在自然语言处理、计算机视觉、强化学习等领域取得的惊人突破，同时也深刻理解当前AI研究范式中存在的局限性。传统的研究模式依赖于人类科学家提出假设、设计实验、分析结果，而AI则主要在实验执行和数据分析环节发挥作用。这种模式虽然高效，但仍然将AI限制在了“辅助工具”的角色。Neyshabur和Mehta认为，AI系统具备的强大的模式识别能力、跨领域知识整合能力以及持续学习能力，使其有潜力在假设生成、理论构建等更高层次的科研活动中发挥关键作用，从而实现真正的研究范式革新。 **自我加速机制：AI进化的新路径** 所谓“自我加速人工智能”，其核心概念是构建能够显著加速自身发展进程的AI系统。这里的“加速”不仅体现在计算资源的优化利用或算法效率的提升，更重要的是指AI系统在知识获取、能力提升、创新产出等方面呈现出的非线性增长态势。传统的AI系统发展遵循相对线性的路径：研究人员提出新架构、新算法，AI系统在特定任务上的性能逐步提升，整个过程主要依赖于人类研究者的智慧投入。而自我加速AI的目标，则是建立一个正向反馈循环：AI能力的提升使其能够更好地参与下一阶段的研发工作，从而实现能力的进一步增强，如此循环往复，形成加速发展的态势。 这种设想的实现需要突破多项技术瓶颈。首先，AI系统需要具备更强大的元学习能力，即“学会学习”的能力，使其能够快速适应新任务、新领域，而无需每次都从零开始。其次，AI需要发展出更完善的因果推理能力，不仅能够识别数据中的相关性，更能够理解变量之间的因果关系，从而在构建理论模型时发挥更积极的作用。此外，让AI真正参与到科学研究中，还需要解决知识表示、推理可解释性、结果可靠性验证等一系列挑战。Mirendil的团队正在从基础研究层面着手，系统性地攻克这些技术难关。 **加速科技进步：超越生产力的价值重估** 在Mirendil创始人的愿景中，AI最“重要的应用”可能并非传统意义上的生产力提升工具，而是加速科学和技术进步本身。这一论断背后蕴含着深刻的洞见。当今人类面临的诸多挑战——气候变化、能源危机、疾病治疗、材料创新等——都需要科学技术的突破性进展来解决。然而，传统科研模式的效率受到人类认知能力、寿命、精力的根本限制。一个能够与人类科学家深度协作、甚至独立开展部分研究工作的AI系统，将有可能极大地加速这一进程。 想象一下这样的场景：AI系统不仅能够分析实验数据，还能够基于海量文献和实验结果提出新的研究假设；不仅能够设计实验方案，还能够预测实验结果并在虚拟环境中进行初步验证；不仅能够撰写论文报告，还能够与人类科学家进行实时讨论、激发新的思路。这样的AI不再是简单的工具，而成为真正的“科学伙伴”，与人类智慧形成互补，共同推动知识边界的拓展。 **挑战与展望：谨慎前行的创新之路** 当然，通向自我加速AI的道路绝非坦途。技术层面的挑战只是其中一部分，更深层的议题涉及AI安全性、可靠性、可解释性以及与人类价值观的对齐问题。如果AI系统将在科学研究中发挥越来越重要的作用，那么确保其输出的正确性、避免“幻觉”问题、以及建立有效的监督机制都变得至关重要。Mirendil团队对此有着清醒的认识，他们强调在追求技术突破的同时，必须将安全性置于核心位置，确保AI的发展始终服务于人类的长远利益。 播客中深入探讨的这一愿景，虽然在短期内可能仍处于探索阶段，但它为我们勾勒了一幅激动人心的未来图景。当人工智能真正具备加速自身乃至整个科技领域发展的能力时，人类社会的进步节奏可能会发生质的飞跃。Neyshabur和Mehta以及他们的Mirendil团队，正站在这一变革的前沿，致力于将这一愿景逐步变为现实。 **总结与核心启示** 本次对话为我们呈现了人工智能发展的一次重要范式思考。从“AI作为生产力工具”到“AI作为自我进化的参与者”，这一理念的转变代表着对AI潜力更深层次的挖掘。Mirendil创始人的核心启示在于：AI的价值不应被局限在辅助人类完成现有任务，而应被激发去参与知识创造和技术创新本身。自我加速AI的实现，将可能带来科技发展的非线性加速，为人类应对各种根本性挑战提供前所未有的助力。然而，这一进程需要在技术创新与安全伦理之间找到精妙的平衡，确保AI的进化始终与人类的长远利益保持一致。对于整个AI行业而言，这不仅是一次技术方向的探索，更是对AI在未来社会中角色定位的深刻重新思考。

# **“融房超贷”：披着购房外衣的高危金融陷阱深度剖析** **现象重出江湖：零首付买房还能倒拿现金的诱惑** 近期，一种名为“融房超贷”的新型金融操作在各大二手交易平台悄然蔓延，以极具诱惑力的宣传话术吸引着急需资金或渴望购房的群体。“零首付买房，买套房还能倒拿30万到50万现金”——这样看似天上掉馅饼的承诺，让不少人心动不已。不需要掏出首付金，不仅能手握房产，还能套现一笔可观的流动资金，这种“一举两得”的宣传话术精准击中了部分人群对快速致富和资金周转的迫切需求。然而，天下没有免费的午餐，这样看似稳赚不赔的操作背后，实际上隐藏着层层陷阱和严苛的法律风险。 **平台沦为导流工具：二手交易平台的灰色变身** 原本用于交易闲置物品的闲鱼等二手平台，如今被部分中介发展成为一类金融灰产的导流温床。这些中介伪装成普通卖家，在平台上高调推广“融房超贷”业务，打着“空手套房、反向套现”的噱头疯狂揽客。他们深谙互联网平台的流量法则，利用二手交易平台看似正规的外衣，掩盖其非法金融操作的本质。这种操作模式的出现，不仅扰乱了正常的金融市场秩序，更让大量不明真相的普通民众暴露在巨大的法律和经济风险之中。平台监管的缺失和中介的刻意伪装，使得这一灰色产业链得以快速扩张。 **高评高贷模式：房产评估的恶意操控** “融房超贷”运作的第一种模式是高评高贷，其核心手法是通过操控房产评估价值来套取更高额度的贷款。在正常购房流程中，银行会根据房产的评估价值来确定贷款额度，通常贷款额度为评估价的70%左右。然而，在高评高贷模式中，操作者会勾结房产中介或评估人员，故意抬高房产的评估价格，使得房产的市场价值被严重高估。通过这种方式，购房者可以从银行获得远高于实际购房价格的贷款额度。例如，一套实际价值100万元的房产，经过高评后可能被估值为200万元，购房者就能从银行套取出140万元的贷款，远超实际购房所需。这种操作不仅涉及贷款欺诈，还可能构成骗取贷款罪，一旦银行发现评估异常或贷款违约，参与者将面临严重的法律后果。 **背债人模式：利用他人身份承担风险** 第二种模式是背债人模式，这是更为激进的操作方式。在这一模式中，操作者会寻找那些信用记录良好但经济状况较差的人员作为“背债人”，由这些背债人出面购房并申请贷款。这些背债人通常是经济条件较差、信用记录空白或信用评分较高但缺乏资产的人群。操作者承诺背债人不需要支付任何首付款，也不需要承担还款责任，房产过户后还能获得一笔“好处费”。然而，一旦房产过户完成，贷款放款后，操作者往往会消失或拒绝承认当初的承诺，留给背债人的是一笔巨额房贷债务和房产被银行收回的风险。背债人不仅会面临严重的信用损害，还可能被银行起诉追讨欠款，甚至被追究骗取贷款的法律责任。 **纯融资模式：房产沦为纯粹的融资工具** 第三种模式是纯融资模式，这是一种更为激进的玩法。在这种模式中，参与者甚至不打算真正购房，而是将房产作为一种纯粹的融资工具。具体操作流程是：先寻找一套低价房产，通过高评高贷的方式获取银行贷款，贷款资金到账后，立即将房产转手出售或进行二次抵押套取更多资金。这种操作的本质是将房产作为获取银行贷款的跳板，完全背离了房产的居住属性和正常的金融功能。纯融资模式不仅涉及贷款欺诈、骗取贷款等刑事罪名，还可能触犯非法经营罪和洗钱罪等多项重罪，参与者面临的刑事风险极高。 **法律风险警示：参与者均有可能涉刑** 值得特别强调的是，“融房超贷”链条上的所有参与者都可能面临刑事法律风险，绝非“稳赚不赔”的生意。对于购房者而言，可能涉嫌贷款诈骗罪或骗取贷款罪；对于房产中介和评估人员而言，可能构成贷款诈骗罪的共犯或帮助信息网络犯罪活动罪；对于提供背债身份的人员而言，同样可能面临骗取贷款罪的追诉。近年来，监管部门对各类违规贷款行为的打击力度持续加大，银行的风控系统也在不断完善，大额贷款异常申报很容易触发预警。一旦东窗事发，参与者面临的将不仅是经济上的巨额损失，更可能是牢狱之灾。 **总结与核心启示** “融房超贷”本质上是一种披着购房外衣的高危金融陷阱，它利用人性中对快速获利的渴望，通过精心设计的套路将参与者一步步引入深渊。无论是高评高贷、背债人模式还是纯融资模式，都严重破坏了金融市场的正常秩序，损害了银行的资金安全，也给参与者带来了巨大的法律和经济风险。对于有购房需求或融资需求的朋友，应当通过正规金融机构和合法渠道解决资金问题，切勿轻信“空手套房”“反向套现”等违背金融规律的宣传话术。守住法律底线，远离灰色地带，才是保护自身财产安全最根本的保障。任何看似诱人的“捷径”，背后往往隐藏着不为人知的陷阱和代价。
