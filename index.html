Manus 回来了，可Agent 的战场已经挤满对手

&nbsp; 文｜李炤锋 编辑 ｜ 张雨忻 2025 年3月6日，Manus 上线那天，办公室里一群工程师看着一张 Manus生成的NBA 球员象限图，觉得十分亮眼——图上排着球员头像，基于得分和投篮次数分布。创始人肖弘后来回忆，让他们意外的不是象限图有多难画，而是过去得由人一步步完成的活，现在只需交代要求，Agent 就能一路做到交付。 一年后，Manus 团队把这段回忆写进公开信，肖弘在这封信的开头，用一句话概括最初的念头：“AI 不仅应该思考，还应该行动。” Manus生成的分析图 &nbsp; 昨天，恢复独立运营的 Manus 发布了 2.0 版本，同时推出面向个人事务的独立应用 Cue。官方介绍显示，2.0 升级了自研 Agent 框架 Cascade；自动化任务可以由新邮件、日历事件等触发。原有桌面应用升级为 Manus Studio，加入可修改初剪时间线的视频编辑器和游戏开发环境。更聚焦个人生活的 Cue，则宣称可以替用户发消息、接听来电，处理日常生活里的琐事。 把时间拨回 2025 年刚上线时，Manus 还要邀请码才能使用。闲鱼上有人声称出售 Manus 邀请码，标价 4 万余元。Manus 团队随后回应，官方从未开设付费获取邀请码的渠道。 在当时的首发视频里，Manus 首席科学家季逸超演示了这款 Agent 如何筛选简历、分析股票、查找纽约房产，也引来中美科技媒体争相报道。Manus 让更多人第一次看见：原来 Agent 可以接下一件事，自己分步骤去做，再交出结果。 接下来的一年，Manus 的命运几经变化。2025 年底，它宣布加入 Meta。今年 9 月 1 日，Manus 又宣布恢复独立，仍由创始团队领导。官宣回归不到一个月，Manus 团队就拿出了 2.0 版本。只是这一次，Agent 赛道上已经挤满了竞争对手。 一年前，自动生成一张图、一份报告或一个网站，对许多刚接触 AI 的用户来说都很新鲜。一年后的今天，“AI 自己办事”已经不再稀奇。编程 Agent 有 OpenAI 的 Codex 和 Anthropic 的 Claude Code；微软 Copilot Cowork、腾讯 WorkBuddy 等产品也在接手普通人的办公任务。 个人事务也开始有人接手。Meta 的 Muse 已在美国逐步开放，可以从 WhatsApp 接任务。据 Sensor Tower 估算，截至 9 月 24 日，Muse 独立 App 累计下载超过 340 万次。而在国内，阿里的千问 App 已展示通过淘宝闪购下单、在对话里付款；字节的豆包手机助手也在尝试从手机端切入普通人的生活场景。 这一回，Manus 2.0 和 Cue 面对的是一场挤满对手的竞争，想要重现 2025 年的惊艳，并非易事。 01 升级工作台之余，还想“Cue”一下个人事务 Manus 2.0 除了升级现有 Agent 框架，还带来了一个新名字：Manus Studio。早在今年 3 月，Manus 就推出桌面应用，允许用户授权它操作本地文件和工具；Studio 是这款桌面应用的升级版。 Cue 则是另一款独立应用，和 Manus 共用底层设施，瞄准个人生活任务。Manus 官方称，Cue 支持网页、桌面和移动端，目前凭邀请码抢先体验；截至昨晚产品公告发布时，iOS 版还在等待 App Store 审核。 这轮发布主要面向海外用户。同时，Manus 也在另行筹备国内市场的产品。 效率是 Manus 这一轮优化的重点。 Cascade，正是 Manus 自研 Agent 框架的最新迭代。Manus 称，在一项测试配置中，它比旧系统少用了 23.2% 的 Token，任务耗时缩短 28.2%，运行成本降低 32%。 在长时间运行的任务上，Manus 2.0 新增了事件触发功能：新邮件、日历事件，或 Slack、Notion 中的信息更新，都能启动预设工作流。云电脑则继续承担长时间运行的任务，也可托管多人游戏服务器。这似乎契合肖弘和团队今年 3 月在年度信里写下的愿景：让 Manus 全天候工作，同时找到用户愿意长期交给它、运行成本也撑得住的任务。 在应用层，从桌面版升级而来的 Manus Studio 把文档、表格、PDF、幻灯片放在同一个工作空间，还覆盖网站、代码、游戏和视频。这次新增的视频编辑器和游戏开发环境，让用户拿到初稿后还能继续动手修改。 除了工作场景，聚焦个人事务的 Cue 也走进了日常生活赛道。按 Manus 的介绍，Cue 中每个 Agent 可以有自己的邮箱、电话号码、钱包和电脑；它可以发消息、接听来电并留下摘要，也能在用户设定的预算内付款。 不过，Cue 的产品理念并非 Manus 团队临时起意。Manus 此前就试过让 Agent 进入聊天场景：今年 2 月，它把 Agent 接进 Telegram，让用户在现成的聊天软件里交代任务。到 9 月推出 Cue，Manus 又让 Agent 带着自己的身份去办事。官方描绘的一个场景是：用户到餐厅扫个码，让 Agent 替自己点餐或排队取号。 Cue 当前展示的交互方式仍更偏向海外用户的习惯。初次使用 Cue 时，App 弹出几条标着“来自 X 的使用案例”的提示，包括给餐厅发邮件问地址、查看 Gmail 中的账单。不难发现，这些用法与在国内处理生活琐事的方式相差很远。 Manus2.0的官方案例 尽管 Manus 团队表示会推出针对国内市场的产品，但在国内，这些生活需求早已和一众超级 App 绑在一起。找餐厅、点餐、打车、付款，许多人会直接打开微信小程序、支付宝、抖音、美团或滴滴。商家、订单和支付，也都留在这些平台里。 说得再直白一点，在国内，个人生活留给独立 Agent 的空间，仍是一个问号。 02 Agent 战争，从 Coding、办公到日常生活，都挤满了竞争对手 “大厂能理解你创新的时候就是很危险的时候。”去年 Manus 上线前，肖弘在采访中这样说。当时他谈的是 Monica 浏览器插件被大厂跟进，以及随之而来的创业焦虑：一款 AI 应用刚做出新东西，大厂就可能把相似的能力放进自己的产品。 Manus 初代发布时，在大众眼中仍是一款前卫的产品。如今 Manus 2.0 归来，Agent 已不是新鲜概念。 在编程和深度工作场景里，Coding Agent 开始接手越来越多的长链任务。今年 6 月，OpenAI 披露，Codex 周活跃用户超过 500 万，其中按公司口径，约两成是知识工作者，有人用它做报告、表格等非代码任务。 微软此前展示过一个销售案例：负责人让 Copilot Cowork 查哪些潜在客户迟迟没有进展，Cowork 找出了跟进中断的地方。微软称，原本需要人工排查一周的记录，它一个上午就完成了。 Cowork 经公司许可后，可以调用 Outlook、Teams 等工具里的资料。微软今年 7 月披露，Microsoft 365 Copilot 已有超过 3000 万个付费席位，这意味着，微软已有一批可以推广新功能的付费客户。 Manus 经历沉浮的这一年，办公 Agent 已经批量进入市场。3 月，腾讯推出 WorkBuddy；8 月，阿里整合 QoderWork、悟空和 MuleRun 的能力，推出千问办公；字节则一边把 TRAE SOLO 升级为 TRAE Work，一边在飞书中推出“豆包工作”，让 Agent 进入办公流程。 易观今年 6 月的统计显示，纳入监测的 17 款国内桌面办公 Agent 合计获得超过 6000 万次访问，其中腾讯 WorkBuddy 为 2097 万次、字节 TRAE IDE 国内版为 1279 万次、阿里 QoderWork 为 788 万次。 在个人 Agent 这边，Muse 同样有 Meta 现成的资源可用。Meta 举的例子里，Muse 可以把用户收藏的 Instagram 食谱整理成购物清单，记住客人的忌口；涉及购买时，还能先征得用户同意，再用 Stripe Link 的一次性卡付款。要替人处理这些日常事务，就得接上用户原来使用的服务，而这对独立 Agent 公司并不容易。 国内也有 AI 应用开始接手具体的生活任务。今年 1 月，在千问 App 发布会上，阿里巴巴集团副总裁吴嘉用它订了 40 杯饮料：千问通过淘宝闪购下单，吴嘉确认后在对话里用支付宝付款，饮料随后送到。9 月，曹操出行宣布与豆包合作的 AI 打车首批在北京、杭州、苏州上线。用户在豆包里查路线、找餐厅时，可以接着选择出行方案，由曹操出行提供用车服务。 Cue 也提出过在餐厅扫码、让 Agent 代为点餐的场景。但如果要在国内市场分到一杯羹，怎样接入各个平台上的商家和服务，是未来国内版产品要解决的问题。 更大的未知来自商业化。Manus 去年 12 月自报 ARR 超过 1 亿美元。可今天，它面对的是一群先送免费额度争用户的对手：WorkBuddy 体验版每月送 500 积分，TRAE 免费新用户可领 4000 积分。 Manus Studio 的升级页面显示，Manus Pro 套餐每月 20 美元。不过， Manus 2.0 升级后，免费用户收到了 1500 credits。各家都在送额度、抢入口，Manus 能否靠 2.0 撬动新一轮商业化，仍是未知数。 在更日常的使用场景里，豆包、千问的基础功能也能免费用；微信的 AI 助手“小微”则已进入灰测。 事实上，距离 2025 年那场令人惊艳的演示，才过去一年多。但对今天的普通用户来说，那个靠一句“AI 会自己做事”就能让人记住一款产品的时刻，似乎已经过去很久。 市面上已有丰富的Agent产品 体验 Manus 2.0 后，它仍是一款高效的 Agent 工具。虽然目前还不知道它背后调用了哪些模型，但实际用起来，Manus Studio 能在多个场景里接住需求，包括一些涉及多模能力的场景：做一份 PPT，或生成一张效果图。打开还在测试阶段的 Cue，也能很快发现一些小巧思：可以定制 Agent 的工作方式，交互里也有更鲜明的性格，这些都是 Manus 2.0 的加分项。 只是，在 2026 年的当下，再看电脑上这一屏Agent/AI 应用图标，Manus似乎不再是那个惊艳的唯一选项。

腾讯 Marvis做 Agent 的不同选择：把用户的电脑“管理起来”

&nbsp; 文｜李炤锋 &nbsp;&nbsp; 编辑 | 张雨忻 近日，腾讯推出新版 Marvis，将这款以“小黑马”为形象的个人 Agent 定位升级为“AI 管家”。智能涌现了解到，截至本月，Marvis 的日活跃用户数比 5 月上线时增长近四倍。 Marvis 源自做应用分发的腾讯应用宝团队。今年 5 月上线时，它被称作“操作系统层级的个人 AI 助手”，重点是按用户指令完成安装软件、查找文件等任务。 这次改版，除了电脑文件管理，腾讯把电脑系统和硬件管理放到更显眼的位置：Marvis 能检查电池健康、找出高耗电应用，也能调整开机启动项。Marvis 业务负责人蔡建涛近日在一场活动上说，5月上线以来，用户的真实用法与团队最初设想的不太一样，“很多用户真的把我们当成一个 AI 管家在使用”。 此前，蔡建涛曾在公开采访中披露，本地文件是使用最多的一类场景，涉及 44% 的用户；另有 28% 用它管理电脑和硬件。一些Marvis早期用户的反馈显示：下载 Marvis 后，不知道该让它做什么。蔡建涛对此回应称：“这次的改版有一半就是为了解决这个问题。”新版主打电脑、文件、软件和浏览器四类任务。 当下，市面上数量繁多的 Agent 所切入的场景已经完成分路。 较早的一路瞄准办公场景。3 月，Anthropic 为 Claude Cowork 开放操作电脑的研究预览：得到许可后，它可以使用桌面应用完成简报、报告。国内，WorkBuddy、千问办公、豆包工作等办公类 Agent 同样是让用户交办工作，拿回文档、网页、PPT 等成果。 另一路瞄准线上生活。Meta 本月推出 Muse，让它在云端虚拟电脑里处理邮件和旅行预订；阿里的千问 App 也宣布自己进入个人 Agent 赛道，接入点餐、购物、机票酒店预订等多个生活场景。全球厂商接连推出个人 Agent 产品——美国创投机构 Menlo Ventures 与市场研究公司 Morning Consult 今年 7 月调查了 5067 名美国成年人：在使用 AI 的受访者中，41% 试过 AI Agent，24% 定期使用。至少在美国的 AI 用户中，Agent 已走出少数人尝鲜的阶段。 办公 Agent 和线上生活 Agent，需要借助PC端平台来完成任务，而Marvis想做的，是管理用户的终端本身，同时成为PC端各种零散任务的“管家”。 并且，Marvis有着比较独特的Agent调用路径：先用端侧模型为获授权的资料建立索引，用户搜索时再利用索引查找，按需调用云端模型——这与 WorkBuddy 等办公 Agent 基本依靠云端模型的思路不太一样。 01 Marvis 的“管家”，做到了哪一步 想要实现“管电脑”，先得深入到系统层。 在新版本演示中，Marvis 调整了一台 Mac 的开机启动项，还找出了影响续航的高耗电应用。不过，碰到需要系统权限的操作，它会停在确认窗口，等用户输入密码。能帮用户做多少，仍取决于操作系统开放哪些功能。 在同类产品上，可以看到类似的操作。微软去年在部分 Windows 电脑的设置中加入自家 Agent，后来也试着向第三方 Agent 开放文件和设置功能，但前提是用户须主动开启相关功能，并同意它访问敏感信息。 新版文件管家功能增加了资料库更新提醒。在公开演示中，Marvis团队以一个校园招聘场景举例：HR 建好简历资料库后，又收到 50 份简历，新文件存进电脑，Marvis 会提示将它们加入原有资料库，但这一过程最终需要由用户确认。 蔡建涛说，“Marvis 搜索本地文件时，会在用户授权的范围内，用端侧模型处理文件内容、建立索引，这样能大大加快搜索文件的速度。一些 Agent 没有‘用端侧模型建立文件索引’这一步，如果让它找一个五年前的文件，花一小时也是有可能的。” 本地处理需要算力，也曾是 Marvis 的一道设备门槛。蔡建涛说，5 月版要求六核处理器和 16GB 内存，主要因为知识库耗费算力；新版简化了本地知识库的搭建流程，这使得电脑配置可以降至四核、8GB，让用户“先能用起来”。 Marvis 还计划把文件搜索扩到 NAS （私有云/网络存储设备）这类私人存储设备，目前与英特尔、飞牛合作打造了定制版 NAS ，计划 10 月推出。在此前的演示中，已经可以初步看到Marvis结合NAS的能力：用户搜索“大海”，Marvis 可以定位到视频里海面出现的片段；搜索“声音中带有掌声的视频”，则能快速定位到对应的声音片段。 一位腾讯人士解释了这项视频搜索背后的流程：在用户授权的范围内，Marvis 先解码视频、处理画面和声音，再建立索引。面对十几 TB 的 NAS，它会先处理用户近期关注的资料，再根据搜索需求扩大范围。 针对用户安装软件的需求，蔡建涛说，改版前每天约有四五万人用它做这件事。新版将安装、更新和操作软件等需求集中到“软件管家”这个独立的功能上，让用户更容易找到。 与此同时，Marvis团队还展示了在游戏场景的应用，后续计划成为独立的“游戏管家”。在 Steam 游戏技能演示中，Marvis 会在观战一局后分析战斗；在教学模式下，则会在游戏过程中提示玩家下一步该按哪个键。 在操作入口方面，用户能通过手机远程向电脑下指令。蔡建涛表示，Marvis 上线以来，远程控制累计使用超过 1800 万次。 智能涌现了解到，腾讯还在争取电脑厂商的合作，让 Marvis 进入更多设备。目前，面向整机厂商的 OEM 版本已经推出。 目前，PC端的 AI 助手市场已经来到了较为激烈的竞争阶段。一些厂商在走自研路线，比如联想的 Qira 已开放给符合条件的电脑用户下载；惠普的 AI ## 硬地骇客的自我运行系统：Try‑Catch‑Finally 方法论 **独立开发者面临的责任驱动型内耗** 在传统的公司结构里，KPI 与上级的指令往往为个人的工作提供了明确的外在框架，焦虑与自我怀疑可以在“完成任务”的节拍中被稀释。然而，作为独立开发者（Indie Hacker），没有老板、没有绩效考核，所有的目标与压力都要自行设定与承担。刘可凡在节目中指出，这种“责任驱动型内耗”常常表现为：对项目进度的持续焦虑、对失败的恐惧、对自我价值的不断审视以及在“该做的事”与“想做的事”之间反复拉锯的思维噪音。内耗不只是情绪上的波动，更是一种认知资源的浪费，导致决策迟缓、创造力受阻，甚至出现“无限期拖延”的现象。 **编程思维构建内耗应对框架：Try‑Catch‑Finally** 刘可凡将程序员的调试逻辑 Try‑Catch‑Finally 引入人生管理，形成了独特的三层应对框架。 - **Try（尝试）**：把每一次行动视作一次“尝试”，明确目标、制定计划、投入执行。Try 阶段的核心是设定清晰的任务（任务 = “代码块”），并通过“小步快跑”的方式降低心理阻力。每一次 Try 都不是“必须成功”，而是“实验”。 - **Catch（捕获）**：当出现负面情绪、错误判断或计划偏差时，使用 Catch 进行“异常捕获”。这一步要求开发者（也就是我们自己）对内耗信号进行快速辨识：焦虑、拖延、自我否定。把这些情绪当作程序中的异常对象，先捕获再分析，而不是让它们无限蔓延。借助情绪日志或每日回顾，把“异常”写入日志，方便后续调试。 - **Finally（最终）**：无论 Try 是否成功，Catch 是否捕获到异常，Finally 块都会执行。它象征着“必然执行的仪式感”，即每天固定要做且不受情绪影响的行为——如晨间写作、十分钟冥想、每日任务复盘等。Finally 的作用是提供一种“系统底色”，让整体运行在不确定的外界变化中保持稳健。 **稳住长期节奏：Finally 仪式感与 AI 任务拆解** 刘可凡强调，单纯的意志力难以支撑长期的独立工作，必须依赖“仪式感”和“结构性工具”。 1. **仪式感**：在每天的固定时间点执行固定动作（比如早晨的 5‑10 分钟写“当天最重要的三件事”，以及晚上的 5 分钟复盘），形成大脑的条件反射。这样即使在情绪低落或外部压力激增时，仍能保证核心活动的持续运转。 2. **AI 任务拆解**：利用 AI（如 ChatGPT、任务拆解插件）将大型目标自动拆分为可操作的子任务。每个子任务对应一个 Try，配合明确的验收标准（类似单元测试），让“尝试—捕获—完成”的循环变得可视化、可量化。刘可凡在节目中演示了使用 AI 将“完成 MVP 发布”拆解成 20+ 个 30 分钟的子任务，每个子任务完成后自动生成进度报告，大幅降低了心理负担。 3. **节奏监控**：通过仪表盘或 Notion 模板记录每周的 Try‑Catch‑Finally 执行情况，形成闭环数据。可视化的进度条让内耗的“异常”更容易被捕捉，也帮助在 Finally 中加入“异常恢复”步骤——比如在连续两天未完成仪式时，强制进行 15 分钟的深度休息或进行一次“情绪重启”。 **识别伪命题与应对创业焦虑** 在创业初期，许多独立开发者会不自觉地套上几种“伪命题”，导致内耗加剧。 - **“必须一次性成功”**：将成功视作唯一出口，忽略了迭代与实验的本质。把每一次失败重新定义为 Try 的自然结果，用 Catch 捕获负面情绪后，再用 Finally 的仪式感进行“经验沉淀”。 - **“我必须在所有领域都是专家”**：追求全知全能导致焦虑。通过 AI 任务拆解，把不擅长的领域交给工具或合作伙伴，自己专注于核心能力，让“Try”更聚焦。 - **“外部评价决定自我价值”**：在社交媒体与行业会议上，外界的评价常常被放大。把外部评价放进 Catch 中进行客观评估，却不让它们干扰 Finally 的仪式感。 刘可凡指出，焦虑本身是一种“异常”，它提醒我们对未知的风险进行感知。关键在于不让焦虑演变成决策瘫痪，而是用 Try‑Catch‑Finally 的框架把它转化为“信号”，进而驱动更精准的行动。 **总结与核心启示** 本期节目通过刘可凡的 TEDx 分享，呈现了一套专为独立开发者设计的自我运行系统。其核心在于： 1. **以 Try 为入口的行动实验**：把每一次任务视为一次可控的实验，降低对结果的执念。 2. **以 Catch 为工具的异常捕获**：通过日志、情绪记录和每日回顾，快速捕获并调试内耗信号。 3. **以 Finally 为底色的仪式感**：建立不受情绪左右的固定仪式，为长期稳健运行提供基础。 4. **借助 AI 与可视化工具**：将大目标拆解为细粒度子任务，提升执行力并让进度透明。 5. **识别并破解伪命题**：主动拆解“必须成功”“全知全能”等思维陷阱，防止焦虑升级。 对独立开发者而言，最重要的不是技术的深耕，而是建立一套能够在“自由”与“不确定性”之间保持平衡的内部运行机制。通过 Try‑Catch‑Finally 的方法论，刘可凡成功把程序员的调试思维转化为自我管理的实用工具，为硬地骇客们提供了一条从“内耗”到“内生动力”的清晰路径。

# 美伊谈判与中美元首会晤：地缘政治博弈下的能源与外交格局分析 ## 美伊谈判：诚意与困境并存，短期突破难度大 **谈判背景与缘起** 9月中旬，国际油价一度逼近110美元高位，引发全球市场高度关注。近期油价出现回落，海外股市风险偏好有所修复。这一变化的重要催化因素是美国与伊朗借助纽约联合国大会期间展开第三方传话外交，双方会谈时长约3小时，显示出两国均有通过对话缓解紧张关系的意愿。这种非直接的沟通方式在地缘政治博弈中较为常见，既保持了双方的尊严，又为后续可能的直接对话保留了空间。 **伊朗方面的谈判动因** 从伊朗角度来看，7月至8月期间，伊朗曾错失美方提出的优厚谈判条件，这一失误在国内引发了广泛讨论，内部鹰派势力因此遭到批评。伊朗决策层意识到需要抓住当前的谈判窗口期，通过对话获取实际利益。在当前中东地缘格局中，中国的影响力日益增强，伊朗希望在中國因素的作用下顺水推舟开启谈判，以期在国际制裁与经济压力下寻求突破口。伊朗的最终目标是通过有限的冲突换取实质性的收益，包括解除部分制裁、恢复石油出口等经济利益。 **美国方面的谈判动因与误判** 从美国角度分析，8月初特朗普政府曾出现严重的战略误判。特朗普认为霍尔木兹海峡的航运安全问题已经通过护航和转运等方式得到有效解决，同时高估了制裁对伊朗经济的打击效果，因此一度拒绝与伊朗进行谈判。然而，伊朗并未坐以待毙，随后重启了对游轮的袭击行动，并对美军军事基地构成威胁。加上胡塞武装的加入，中东局势进一步复杂化。这些事态的发展迫使特朗普政府不得不重新评估形势，认识到单纯依靠制裁和军事威慑难以迫使伊朗屈服，于是重新开启与伊朗的对话渠道。 **谈判面临的制约因素** 尽管双方均有谈判意愿，但短期内实现重大突破面临诸多障碍。首先，美国大选临近，特朗普难以背负“让出霍尔木兹海峡控制权”的政治包袱，这一问题涉及美国在中东的战略核心利益，任何可能被视为让步的协议都可能成为大选中的政治软肋。其次，也门胡塞武装问题的持续发酵为谈判增添了复杂变量，伊朗与胡塞武装的联系使得美国在谈判中需要考虑多重因素。此外，双方在核问题、导弹计划等核心议题上存在根本性分歧，短期内难以找到双方都能接受的解决方案。 **能源市场影响与风险提示** 从能源市场角度看，美伊谈判的僵局对国际油价形成支撑。专业分析预计布伦特原油价格短期将在90至100美元区间高位震荡。这一价格水平对全球通胀和经济复苏构成压力，需要投资者密切关注。地缘政治专家特别提醒，需要警惕特朗普为压低油价而释放“虚假乐观”信号的可能性，这种策略在大选期间尤为常见，可能导致市场短期波动加剧。 ## 中美元首会晤：氛围积极但实质渐进，难有突破性成果 **会晤的基调与形式** 中美元首会晤呈现出形式拉满、氛围融洽的特点。两国领导人的互动释放出管控分歧、稳定关系的积极信号，这对于当前复杂的中美关系而言具有重要的稳定器作用。从外交层面看，这种高层次的沟通有助于防止两国关系进一步恶化，为各层级对话创造有利条件。然而，分析人士普遍认为此次会晤难以产生“大交易”，即那种能够根本性改变两国关系走向的重大协议。 **经贸领域的可能进展** 在经贸领域，预计双方可能达成局部减税措施以及扩大进口的务实安排。这些措施虽然规模有限，但能够在一定程度上缓解贸易紧张关系，为两国企业创造更为稳定的商业环境。值得注意的是，这些经贸安排更可能是技术性的、局部的，而非系统性的结构性改革。扩大进口，特别是美国农产品、能源产品的进口，可能成为中方展示诚意的具体举措。 **科技领域的焦点议题** 科技议题方面，双方的讨论重点将放在人工智能风险管控层面。这一领域正在成为中美博弈的新战场，涉及到数据安全、算法治理、军事应用等敏感议题。双方需要在竞争与合作之间寻找平衡点，既要防止技术竞争失控导致冲突升级，又要保留各自的技术优势和发展空间。AI风险管控可能成为两国为数不多的共识领域之一，因为它符合双方的共同利益——防止不可控的AI技术发展对全球安全构成威胁。 **地缘政治层面的微妙交换** 在地缘政治层面，中美元首会晤可能涉及中东问题的微妙交换。中国在中东地区影响力的提升使其成为美国不得不重视的对话对象。美国希望中国利用其对伊朗的影响力，推动伊朗在核问题和地区冲突问题上采取更为克制的态度。作为交换，美国可能在经贸问题上对中方做出一定让步。这种利益交换体现了中美关系的复杂性——两国既是战略竞争对手，又在某些全球性议题上存在合作需求。 **会晤的总体特征与展望** 综合来看，此次中美元首会晤呈现出“氛围积极、实质渐进”的显著特征。形式上的友好互动为两国关系的稳定发挥了积极作用，但实质性问题的解决仍需要更长时间、更艰苦的谈判。这种“有温度、无深度”的会晤模式可能成为未来一段时期中美关系的常态——双方保持沟通渠道畅通，在具体议题上取得有限进展，但避免根本性的对抗或妥协。对于市场参与者而言，需要降低对中美关系出现戏剧性改善的预期，以更为务实的态度评估两国关系的发展前景。 ## 核心启示与总结 本期播客内容为我们理解当前复杂的地缘政治格局提供了专业视角。在美伊谈判问题上，双方虽有谈判意愿，但受制于美国国内政治周期、伊朗国内政治生态以及地区安全格局的多重制约，短期内难以实现突破性进展。能源市场参与者需要在油价高位震荡的背景下保持警惕，审慎评估各种地缘政治信号的真实性。在中美元首会晤问题上，需要摒弃过于乐观或过于悲观的预期，以“斗而不破、合而不融”的理性态度看待两国关系的长期发展。#地缘政治#中美关系#能源市场#国际关系#宏观经济

# 减脂新风尚：当“健康管理”成为大众生活方式 ## 减脂浪潮：从健身圈到大众生活的身份转变 在当今社会，减脂已经不再仅仅是肥胖人群的医疗需求，而是演变成一种席卷全社会的文化现象和生活方式。体脂率、减脂餐、空腹有氧、16+8轻断食、碳循环饮食法等专业术语，曾经只在健身爱好者的私密圈子里流通，如今却频繁出现在普通人的日常对话中。这些词汇不再是晦涩难懂的“健身圈黑话”，而是成为很多人茶余饭后的谈资和社交媒体上的热门话题。 这种转变意味着什么？它代表着人们对身体管理的态度发生了根本性变化。过去，人们健身减肥往往出于对健康的担忧或对身材的不满意，带有明显的功利性目的。而现在，减脂已经与穿搭、露营、Citywalk等生活方式并列，成为一种被主动追求、被积极分享的生活态度。人们在社交媒体上晒出自己的减脂餐、运动记录、体脂变化，不再是为了炫耀或求得他人的认可，而是将这种自律的生活状态视为自我价值的一种体现。这种变化反映出当代人对“健康美”的追求已经超越了单纯的生理需求，上升到了精神层面和生活品质的层面。 ## 减肥话题的持续热度与多元探索 减脂话题在互联网上的热度持续攀升，已经成为健康类内容中的“常青树”。无论是微博、小红书、抖音还是各大健康类社区，“减肥”和“减脂”始终占据着话题榜的重要位置。这种持续的热度并非偶然，而是社会发展到一定阶段的必然产物。 现代人面临着前所未有的生活压力和工作节奏，身体和心理的双重负担让越来越多的人开始关注自身的身心健康。同时，社交媒体的普及让人与人之间的比较变得更加便捷和频繁，“A4腰”、“锁骨放硬币”等身材挑战一次次引发全民参与，使得身材焦虑与健康意识同时被放大。在这样的背景下，减脂自然而然地成为了一个持续被讨论、被探索的永恒话题。 从内容形态来看，关于减脂的讨论已经从简单的“管住嘴、迈开腿”发展到了精细化、科学化的新阶段。人们不再满足于知道“要减肥”，而是开始追问“为什么要减脂”、“怎么科学减脂”、“什么样的方法适合自己”等更深层次的问题。这种从“知其然”到“知其所以然”的转变，标志着大众健康素养的显著提升。 ## 减脂路上的三大认知陷阱 尽管减脂已经成为一种普遍追求，但真正能够科学、成功减脂的人却并不多。在实践中，无数人反复踩坑，陷入了各种认知和行动的误区。综合来看，最常见的三类“减脂踩坑”主要包括以下几个方面： 第一种是极端饮食陷阱。许多人为了追求快速见效，采取极度严苛的饮食控制方法，比如完全不吃碳水、每天只吃一顿、连续多天只吃蔬菜水果等。这些方法虽然在短期内可能看到体重下降的明显效果，但往往伴随着营养不均衡、基础代谢下降、免疫力降低等健康风险。更糟糕的是，一旦恢复正常饮食，体重就会迅速反弹，甚至超过原来的水平，形成所谓的“溜溜球效应”。 第二种是过度运动陷阱。与极端饮食相对应的是另一种极端——过度运动。有些人认为运动量越大、强度越高，减脂效果就越好，于是每天高强度训练，完全不给自己休息和恢复的时间。这种做法不仅容易导致运动损伤，还会因为身体过度疲劳而产生皮质醇水平升高，反而阻碍脂肪燃烧。同时，过度运动带来的身心压力也让人难以坚持，最终导致计划半途而废。 第三种是急功近利心态陷阱。减脂是一个需要长期坚持的过程，不可能一蹴而就。但许多人缺乏这种耐心，期望在短时间内看到显著变化，一旦效果不如预期就立刻放弃，转而尝试其他“神奇方法”。这种心态让人陷入不断尝试、不断失败的恶性循环，不仅减脂失败，还严重打击了自信心和对健康生活的热情。 ## 懒人减脂方案：轻松可执行的入门选择 面对减脂的需求，许多人并非不愿意行动，而是被“运动”二字吓退。他们担心自己没有足够的体力、时间或专业知识来开始运动。针对这部分人群，播客中推荐了被称为“懒人减脂三件套”的运动方案：爬坡、超慢跑和散步。 爬坡是一种极其简单却效果显著的减脂运动方式。它不需要任何特殊的设备或场地，只要找到有坡度的道路或使用跑步机的坡度功能即可。爬坡运动的强度可以根据个人体能灵活调整，体能较差的人可以选择坡度较小、速度较慢的方式开始，随着体能提升再逐步增加强度。相比于在平地上跑步，爬坡对膝盖的冲击更小，同时能够更有效地锻炼臀部和大腿肌肉，对于塑造下半身线条尤为有效。 超慢跑是近年来兴起的一种新型运动方式，顾名思义，就是以极慢的速度进行跑步。这种看似矛盾的表述实际上蕴含着深刻的运动科学原理。超慢跑的速度通常接近或低于正常快走的速度，几乎任何人都能够轻松完成。由于强度较低，超慢跑可以持续较长时间，让身体在有氧区间内充分燃烧脂肪。同时，这种轻松的运动方式让人更容易坚持，不会产生传统跑步带来的疲惫感和抵触情绪。 散步作为最基础、最温和的运动形式，往往被追求“高效减脂”的人忽视。实际上，对于初学者或体能较差的人群来说，散步是最安全、最容易坚持的选择。每天保持一定时长的散步，不仅能够消耗热量、改善心肺功能，还能够帮助缓解压力、改善睡眠质量，这些都对减脂有着间接但重要的促进作用。 这三种运动的共同特点是门槛低、易执行、不需要专业设备，非常适合作为减脂的入门选择。播客中强调，不必一开始就追求高强度训练，从这些轻松可执行的方式开始，逐步培养运动习惯，才是长期减脂成功的关键。 ## FatMax：燃脂运动的新科学概念 在减脂运动领域，有一个科学概念正在引起越来越多人的关注，那就是FatMax（脂肪最大氧化率）。这一概念代表了对人体能量代谢机制的深入理解，为科学减脂提供了新的理论依据。 简单来说，FatMax指的是人体在运动过程中脂肪氧化速率达到最大值时对应的运动强度。在这个强度下，身体利用脂肪作为燃料的效率最高，单位时间内燃烧的脂肪量最多。这一发现对于传统的减脂运动观念提出了挑战。 过去，人们普遍认为低强度、长时间的运动（如散步、慢跑）是燃烧脂肪的最佳方式，因为这种强度下脂肪供能的比例较高。但FatMax理论指出，脂肪供能比例高并不等于脂肪燃烧总量多。在极低强度运动时，虽然脂肪供能占比可能达到70%至80%，但由于总能耗极低，实际燃烧的脂肪量并不多。而在中等强度运动时，虽然脂肪供能比例下降，但由于总能耗大幅增加，脂肪燃烧的绝对值反而更高。 那么，如何找到自己的FatMax强度呢？研究表明，大多数人的FatMax强度大约在最大摄氧量的45%至65%之间，对应到实际的运动感受上，就是能够保持对话但略微喘气的状态。这种强度既不会过于轻松导致燃脂效率低，也不会过于剧烈导致难以坚持。对于大多数人来说，爬坡行走和超慢跑恰好落在这一强度区间内，这解释了为什么这两种看似“懒人”的运动实际上是高效的减脂选择。 ## 认知重塑：减脂理念的根本转变 减脂之所以让许多人感到困难和痛苦，很大程度上是因为错误的认知框架。通过对当代减脂文化的深入分析，播客提出了“重塑减脂认知”的观点，认为只有从源头上改变对减脂的理解，才能真正走上科学、健康的减脂之路。 首先需要重塑的是对“速度”的认知。社会上弥漫着一种追求快速见效的浮躁风气，各种“7天减10斤”、“一个月瘦出马甲线”的宣传铺天盖地，让人误以为减脂应该是一件迅速完成的事情。但事实上，健康、可持续的减脂速度应该是缓慢的。根据专业建议，每周减重0.5至1公斤是较为理想的速度，这相当于每天创造300至500大卡的热量缺口。超过这个速度的减脂往往意味着身体正在流失水分和肌肉，而非纯粹的脂肪，同时也会给身体带来过大的压力。 其次需要重塑的是对“完美计划”的追求。许多人在开始减脂前会花费大量时间制定详尽的计划，追求最完美的饮食方案、最科学的训练计划、最专业的装备配置。这种追求完美的倾向往往导致两个结果：一是计划过于复杂难以执行，二是因为等待“完美时机”而永远无法开始。实际上，开始比完美更重要。与其等待一个不存在的最佳方案，不如先从力所能及的事情做起，在行动中不断调整和完善。 第三个需要重塑的认知是对“痛苦”的理解。传统观念认为，减脂必须忍受饥饿和疲劳，只有“虐自己”才能看到效果。但这种观念正在被越来越多的科学研究所修正。适度的热量缺口和运动强度确实必要，但如果缺口过大或强度过高，身体会进入应激状态，分泌更多的皮质醇和胰岛素，反而不利于脂肪燃烧。更重要的是，当减脂与痛苦画上等号时，很少有人能够长期坚持，而减脂恰恰是一个需要长期坚持的过程。 ## 慢即是快：可持续减脂的智慧 “慢就是快”是本期播客的核心观点，也是对减脂认知的终极重塑。这一看似矛盾的观点蕴含着深刻的辩证智慧。 “慢”意味着什么？它意味着接受减脂是一个漫长的过程，不期待立竿见影的效果；它意味着选择能够长期坚持的方式，而非追求短期高效但难以持续的方法；它意味着给身体足够的时间适应变化，避免因过度激进而造成的伤害和反弹。 为什么说“慢就是快”？因为在减脂这件事上，暂时的快往往意味着未来的慢。采取极端方法在短期内快速减重的人，往往会在恢复饮食后迅速反弹，甚至超过原来的体重。这种“减了又涨、涨了再减”的循环不仅让减脂效果归零，还会对身体代谢系统造成反复损伤，降低基础代谢率，让以后的减脂越来越困难。相比之下，选择缓慢但稳定减脂方式的人，虽然短期内看不到惊人的变化，但能够确保持久的效果和真正的身体改善。 “慢就是快”还意味着优先级的重新排序。当人们不再急于求成时，就会更关注减脂过程中的身体健康和生活质量，而不是单纯地盯着体重秤上的数字。他们会更愿意选择营养均衡的饮食而非极端节食，会更注重培养运动习惯而非追求一次性的大强度训练，会更重视充足的休息和恢复而非盲目地“消耗更多热量”。这些看似“慢”的选择，实际上为长期成功奠定了坚实的基础。 ## 总结与核心启示 本期播客以“减脂”这一当代社会的热门话题为切入点，深入探讨了减脂从医疗需求演变为大众生活方式的社会现象，分析了减脂实践中常见的三大认知陷阱，介绍了适合懒人的减脂运动方案，阐述了FatMax这一运动科学新概念，并最终提出了“重塑认知、慢就是快”的核心理念。 对于想要开始或正在减脂的人来说，本期内容提供了几个重要的启示：第一，减脂应该被看作是一种长期的生活习惯培养，而非短期的任务完成；第二，科学、可持续的减脂方法往往看起来“慢”或“懒”，但这恰恰是它们能够长期坚持的原因；第三，不必追求完美的计划或极端的效果，从力所能及的事情开始，在行动中不断调整，才是走向成功的正确路径；第四，给身体足够的时间和耐心，接受缓慢但稳定的进步，才能最终实现真正的改变。 在这个追求即时满足的时代，减脂提醒我们：真正有价值的事情往往需要时间来沉淀，真正有效的改变往往是渐进的。当我们放下对速度和效果的执念，选择与身体和解、与时间做朋友，减脂就不再是一场痛苦的战 役，而是一段美好的自我成长之旅。

# IMF视角下的中国经济转型：4.6%增长预期背后的深层洞察 ## 引言：一份引发广泛关注的增长预测 国际货币基金组织近期将中国2026年经济增速上调至4.6%，这一超预期数值迅速引发各方关注。这一数字背后蕴含着对中国经济现状与未来的全新判断：曾经支撑中国经济高速增长的出口驱动模式已抵达转型节点，房地产市场的深度修复需要投入相当于国内生产总值5%的资源，而长期潜在增速的天花板可能仅为3.5%。国际货币基金组织亚太部主任克里希纳·斯里尼瓦桑在接受第一财经记者梁相宜专访时直言：“改革推进越快，对中国越有利。”这一观点为理解当前中国经济形势提供了重要的外部视角。 ## 4.6%增速预测的三重逻辑 ### 出口驱动模式的转型压力 IMF上调中国增速预期，并非基于出口部门的持续强劲，而是基于对中国经济结构性调整的审慎评估。长期以来，出口导向型增长模式推动了中国经济的快速增长，但这种模式在全球经济格局深刻变化下面临前所未有的挑战。地缘政治因素导致的贸易摩擦、全球供应链重构以及国际市场竞争加剧，都在削弱出口作为经济增长主要引擎的效力。IMF的预测反映出一个核心判断：中国经济正在从出口驱动向内需驱动转型的关键期，这一转型虽然充满挑战，但也孕育着新的增长动力。 ### 内部需求的培育与释放 4.6%的增速预期还考虑到中国内部需求的潜在空间。随着居民收入水平提升和消费结构升级，国内消费市场的规模和质量都在经历深刻变化。服务消费、新兴消费领域的高速增长为经济转型提供了支撑。然而，消费对经济增长的贡献需要收入分配改革、社会保障体系完善等配套措施的系统推进。IMF的预测隐含着一个假设：中国能够在合理的时间内有效释放内部需求的潜力，弥补出口动能减弱带来的缺口。 ### 政策应对的积极效应 IMF的预测还体现了市场对中国政策应对能力的认可。在经济面临多重压力的背景下，中国政府已经并正在采取一系列稳增长措施，包括财政政策的适度扩张、货币政策的灵活调整以及针对特定领域的定向支持。这些政策措施的及时性和有效性是IMF上调增速预期的重要依据。IMF亚太部主任指出，改革推进的速度将直接决定中国经济能否顺利跨越当前的转型关口。 ## 三大下行风险的深度解析 ### 地缘经济碎片化风险 IMF明确将地缘经济碎片化列为中国经济增长面临的首要风险。在全球化退潮、区域化兴起的背景下，国际经济秩序正在经历深刻调整。贸易壁垒的增加、技术封锁的加剧以及跨境投资审查的严格化，都在增加中国经济运行的不确定性。对于高度依赖国际市场的中国经济而言，碎片化风险不仅影响短期的出口表现，更可能重塑长期的增长轨迹。中国需要在维护既有开放格局的同时，加速构建更加多元化、更具韧性的国际经济合作网络。 ### 房地产市场的深度调整 房地产市场的修复是IMF关注的核心议题之一。节目透露，房地产市场的彻底修复可能需要投入相当于国内生产总值5%的资源。这一数字凸显了房地产问题的复杂性和艰巨性。房地产在中国经济中扮演着特殊角色，其影响远超单纯的行业波动，深度关联着地方财政、居民财富、金融稳定等多个关键领域。IMF的判断表明，房地产市场的底部确认和信心恢复需要时间和资源的持续投入，这一过程将在相当程度上决定中国经济的短期表现。 ### 能源价格冲击的影响 全球能源市场的波动为中国经济带来了额外的成本压力。能源价格的剧烈起伏不仅影响工业部门的生产成本，还通过传导机制影响整体物价水平和居民消费能力。在中国能源结构转型的大背景下，如何在保障能源安全的同时控制成本上升，是经济决策面临的重要课题。能源冲击与上述其他风险叠加，构成对中国经济韧性的严峻考验。 ## 财政政策的方向选择 ### 钱往哪里花的关键抉择 在财政政策层面，IMF特别关注资源分配的方向性问题。当前经济环境下，财政支出的边际效益和乘数效应成为政策制定的核心考量。基础设施投资、民生保障、科技创新、绿色转型等领域都在竞争有限的财政资源。IMF的观点倾向于支持那些能够产生长期经济效益、提升经济潜在增速的支出方向，如人力资本投资、基础设施建设以及促进技术进步的领域。 ### 改革优先级的重新排序 财政政策的运用还需要与结构性改革紧密结合。IMF亚太部主任强调，改革推进的速度比任何具体的增长数字都更重要。这意味着财政资源的使用不仅要考虑短期的刺激效果，更要着眼于制度性障碍的消除和发展潜力的释放。在财政空间有限的约束下，如何将有限的资源用在刀刃上，实现稳增长与促改革的有机统一，是政策制定者面临的核心挑战。 ## 人工智能革命与就业市场变革 ### 40%工作受影响的深远影响 节目中提及的一个核心数据是：人工智能可能影响40%的工作岗位。这一数字背后反映的是技术革命对劳动力市场的深刻重塑。生成式人工智能的快速发展正在改变各行各业的生产方式和服务模式，大量重复性、程序化的工作面临被替代的风险。对于中国这个拥有庞大就业人口的经济体而言，人工智能带来的就业结构调整既是挑战也是机遇。 ### 谁的竞争优势更加明显 IMF的分析指出，在人工智能时代，具备特定优势的人群和地区将更容易适应技术变革带来的变化。这些优势包括：较强的学习能力和适应能力、较高水平的技术素养、灵活的就业观念以及创新创业的意愿。从区域视角看，人工智能产业发展基础较好的地区、高等教育资源集中的城市可能在转型中占据先机。这提示政策制定者需要关注技术变革可能带来的就业分化和社会公平问题。 ## 亚洲经济的整体韧性 ### 三重冲击下的表现评估 在全球经济面临多重冲击的背景下，亚洲经济的整体表现受到广泛关注。IMF的评估显示，亚洲在面对地缘政治紧张、能源价格波动和供应链重构等三重冲击时，展现出一定的韧性。这种韧性来源于亚洲经济的结构性优势，包括较强的制造业基础、庞大的国内市场和快速增长的中产阶级群体。然而，IMF同时指出，亚洲经济也存在明显的脆弱性。 ### 脆弱性的根源分析 IMF分析了亚洲经济格外脆弱的原因。首先，亚洲许多经济体高度依赖出口和国际市场，对外部环境变化敏感。其次，区域内的产业链供应链虽然紧密，但也意味着风险的传导更为迅速。第三，部分亚洲经济体面临人口老龄化、债务累积等中长期挑战。这些脆弱性因素意味着亚洲在享受全球化红利的同时，也需要为可能的冲击做好准备。 ## 总结与核心启示 本期《两说》节目通过IMF亚太部主任的专业视角，为理解中国经济的现状与前景提供了重要的分析框架。4.6%的增速预期既是对中国当前经济韧性的认可，也是对改革紧迫性的警示。核心启示可以归纳为以下几点： 第一，中国经济正处于从高速增长向高质量发展转型的关键阶段，出口驱动模式的边际效益递减，内部需求的培育和释放将成为决定性因素。第二，房地产市场的深度调整是经济企稳回升必须跨越的关口，需要投入大量资源但也必须与长效机制建设相结合。第三，人工智能等技术革命将深刻改变经济结构和就业格局，政策制定者需要前瞻性地应对这一变革带来的社会影响。第四，改革的推进速度是决定中国经济长期前景的关键变量，犹豫和迟缓只会增加转型的成本和风险。第五，在充满不确定性的国际环境中，保持开放、深化合作、增强韧性是应对外部冲击的必然选择。 IMF的判断表明，中国经济拥有足够的规模和潜力，但将这些潜力转化为持续的增长动能，需要坚定的改革意志、精准的政策选择和全社会的共同努力。改革推进越快，对中国越有利——这一观点在当前语境下显得格外中肯。

# AI娱乐产品的未来：泛创作与轻游戏的融合探索 ## 当前AI领域的发展重心与反思 从今年初到现在，整个AI领域最大的重心集中在coding、生产力和工作场景。这一趋势几乎成为了行业共识，各大科技公司和创业团队都在努力将AI能力落地于提升工作效率、优化工作流程、解决专业问题等领域。然而，在这一片火热的技术竞赛中，有一个关键问题被相对忽视了：如何用AI让人真正开心？如何为用户创造一种真正新颖、长期、高频且不容易厌倦的娱乐体验？ 这一问题的提出者正是96年出生的年轻创业者梁琛奇。他认为，当行业都在关注“解题”类工具产品时，更值得思考的是“出题”类娱乐产品的可能性。工具产品解决的是明确的需求和痛点，而娱乐产品需要激发用户的内在动机，让人在使用过程中获得快乐和满足感。这两种产品逻辑有着本质的区别。 ## 梁琛奇的职业轨迹与创业背景 在去年夏天创立“动念引线”之前，梁琛奇只待过一家公司——字节跳动。在这家公司的7年时间里，他亲历了中国短视频和社交产品的多个重要发展阶段。 2018年是抖音快速崛起的年份，梁琛奇亲眼见证并参与了这个日后成为现象级产品的平台从起步到壮大的过程。这段经历让他深刻理解了内容平台的运作机制、用户行为模式以及娱乐产品的核心要素。 到了2021年，梁琛奇开始从零开始lead一个实时社交产品。这段从无到有建设产品的经历，锻炼了他对社交互动场景的洞察能力和产品设计能力。实时社交不同于异步的内容消费，它需要更快的反馈循环、更强的即时性和更高的用户黏性。 2023年，字节跳动成立AI产品部门Flow，梁琛奇带领团队推出了“猫箱”这款AI产品。这段经历让他深入了解了AI技术的能力边界和应用潜力，同时也让他开始思考AI在娱乐领域的更广阔前景。 ## 动念引线：押注泛创作与轻游戏的融合 带着对娱乐和内容的持续热情，梁琛奇创立了“动念引线”。这家公司选择了一条独特的赛道：泛创作和表达，并混合轻游戏的体验。这一选择的背后，是对未来娱乐形态的深度思考。 梁琛奇认为，目前还没有人真正拿出AI娱乐方向的爆款产品，把那种无可争议的新体验推到用户面前。市场上虽然涌现了大量AI应用，但大多数仍然集中在生产力工具、教育辅助或智能助手等场景，真正的AI娱乐产品仍然是一片蓝海。 动念引线希望填补这一空白。他们构想的泛创作体验，不是让用户进行严肃的专业创作，而是降低创作的门槛，让每个人都能轻松地表达自己的想法和创意。同时，融入轻游戏的元素，增加互动性和趣味性，让整个体验更加轻松愉快。 ## 关于人类创作行为的两种假设 这一押注能否成立，实际上取决于我们如何想象和推演未来的自己。梁琛奇提出了两种截然不同的假设。 第一种假设认为，大部分人即使拥有闲暇时间，也不会主动投入创作。在这一观点看来，人类的本性是趋向于被动消费内容的。我们更愿意刷短视频、看剧、浏览社交媒体，而不是自己动手创作。即使创作工具变得更加便捷，大多数人仍然会选择“kill time”的方式度过空闲时光。 第二种假设则更加乐观。梁琛奇相信，随着AI技术的进步和社会的发展，当人们不再需要为生计而工作时，泛创作将会成为一种普及、高频的娱乐活动。就像今天人们会自发地拍照分享、撰写日记、录制视频一样，未来的创作行为会更加日常化和娱乐化。 动念引线显然选择了第二种假设作为自己的赌注。他们认为，AI技术可以大幅降低创作的门槛和成本，让更多人能够参与到创作过程中来。当创作不再是专业技能，而是一种轻松愉快的表达方式时，人类的创作欲望将会得到充分释放。 ## 总结与核心启示 这期播客的核心在于探讨AI时代娱乐产品的未来方向。梁琛奇和动念引线的实践代表了一种全新的思考方式：不是用AI来解决问题，而是用AI来激发快乐。 这一探索的价值不仅在于商业层面，更在于它触及了人类行为和需求的核心问题。娱乐产品的本质是什么？人类的创作冲动能否被技术释放？未来的数字生活会是什么样子？这些问题没有标准答案，但正是这种不确定性，让内容和娱乐创业变得如此有意思。 对于所有关注AI应用发展的从业者和观察者而言，梁琛奇的思考提供了一个重要的视角：除了关注AI如何提升效率，我们同样应该关注AI如何提升幸福感。而最终的答案，或许就藏在每个人对“自己会如何度过闲暇时光”这一问题的回答中。

# 千年古蜀道的沧桑与新生：文学、历史与现代徒步的交织 ## 引言：文学印象中的蜀道 李白的不朽名篇《蜀道难》，或许是当代人对于“蜀道”这一概念最为深刻的文学印象。“噫吁嚱，危乎高哉！蜀道之难，难于上青天！”诗人以极度夸张的手法，将蜀道描绘为逶迤峻险的高山峭壁之上、历代修凿而成的天梯石栈，其高不可攀、险象环生的景象跃然纸上。然而，这些气势磅礴的诗句背后，实际上是由一条条真实存在的古道所构成的复杂道路交通网络，它们如同血脉般勾连着四川盆地与中原腹地，成为连接西南与内地的关键纽带。 《蜀道难》不仅仅是一首描写自然险峻的诗歌，更承载着深厚的历史文化内涵。它反映了唐代以前蜀道作为进出蜀地唯一通道的艰难处境，也映射出历代文人墨客面对天险时的复杂情感——既有敬畏，也有挑战自然的豪迈。从这个意义上说，蜀道已经超越了单纯的交通概念，成为中华文化中关于艰难险阻、坚韧不拔的精神象征。 ## 蜀道的历史地位与交通功能 蜀道作为一个系统性的道路交通网络，其历史可以追溯到先秦时期甚至更早。据本期播客中几位记者的介绍，蜀道并非单指某一条道路，而是由多条不同走向、不同年代的古道共同构成的复合交通体系。这些道路共同承担着蜀地与外界联系的重任，是古代四川盆地与中原地区政治、经济、文化交流的主要通道。 在漫长的历史长河中，蜀道的重要性体现在多个层面。首先是政治层面，蜀地作为西南重镇，其归属直接关系到中央王朝对全国的统治稳定。无论是秦灭蜀国，还是历代王朝对西南边疆的管理，都必须依赖蜀道来实现兵力投送和行政管控。其次是经济层面，蜀地的物产，特别是天府之国丰富的粮食和手工业品，需要通过蜀道运往中原；而中原的先进技术和文化，也沿着同样的路线传入蜀地。此外，蜀道还是文化传播的载体，佛教传入西南、蜀学向外传播，都离不开这条文化走廊。 节目中提到，蜀道究竟有多少条，这是一个看似简单却难以精确回答的问题。从文献记载和考古发现来看，历史上使用过的蜀道至少有十几条之多，它们因时代不同、起点终点不同、途经地域不同而各具特色。其中最为著名的包括子午道、褒斜道、陈仓道、故道等，它们穿越秦岭和大巴山的崇山峻岭，蜿蜒于悬崖峭壁之间，工程之艰巨令人叹为观止。 ## 栈道建造：古代工程技术的奇迹 节目中用了相当篇幅讨论“明修栈道，暗度陈仓”这一历史典故背后的栈道建造技术。所谓栈道，又称阁道，是蜀道上最具特色的建筑形式。它是在悬崖峭壁上凿孔架木或直接在石壁上凿出一条通道，供行人通行。这种建筑方式的出现，完全是迫于地形条件的无奈之举——当崇山峻岭阻挡了直接通行的可能时，古人选择借助山体的自然轮廓，用最少的工程量实现道路的连通。 栈道的建造过程极为艰辛。首先需要选定路线，由有经验的工匠勘察地形，选择岩壁最为坚固、相对平坦的区段。然后在岩壁上开凿石孔，石孔的间距、深浅、方向都有严格的技术规范。接下来是将加工好的木梁或石梁嵌入石孔，形成悬空的路面基础。最后在梁上铺板、设栏，形成完整的通道。据考古发现和文献记载，栈道的承载能力远超今人想象，能够通行马车和军队辎重。 然而，栈道也是蜀道上最为脆弱的环节。由于完全暴露在自然环境中，栈道极易受到风雨侵蚀、山洪冲击甚至地震破坏。历史上，栈道的损毁与修复反复交替，往往一次大的自然灾害就能使某段栈道完全报废。因此，历代政府都需要投入大量人力物力进行维护，这也是蜀道始终需要国家力量持续介入的原因之一。 ## 从辉煌到沉寂：蜀道的衰落 随着历史的发展，蜀道的命运发生了根本性的转折。当王朝的政治中心逐渐离开中原腹地，向北方或南方偏移时，翻越秦岭、大巴山的古道逐渐失去了其原有的核心交通价值。这一变化的过程是渐进的，但影响却是深远的。 更为关键的是内河航运的兴起。长江及其支流构成了另一套通往蜀地的水路交通网络，相比陆路翻山越岭的艰辛，水路运输具有运量大、成本低、风险小的优势。特别是在唐宋以后，随着造船技术和导航技术的发展，水路逐渐成为进出蜀地的主要通道。到了明清时期，蜀道上的人流量和货流量已经大不如前，许多区段甚至趋于废弃。 现代交通方式的出现则彻底改变了蜀道的命运。铁路和高速公路的建设，使得翻越秦岭不再需要数日甚至数周的艰苦跋涉，而是可以在数小时内完成。这种质的飞跃使得古道在功能上完全失去了存在的基础。曾经的官道驿站、商旅要津，如今只剩下断断续续的遗迹，淹没在荒草乱石之中。从功能主义的角度看，古蜀道的生命确实已经划上了句号。 ## 当代复兴：考古发现与徒步文化 然而，事情并未就此终结。近些年来，沉寂多年的古蜀道出现了令人瞩目的复兴迹象，这一复兴主要体现在两个层面：学术研究层面的考古工作，以及大众文化层面的徒步运动。 首先是考古工作的深入开展。《三联生活周刊》的记者们在节目中详细介绍了近年来蜀道考古的重要发现。通过系统的田野调查和文献梳理，考古工作者基本摸清了主要蜀道的走向、保存状况和历史变迁。特别是在一些过去认为已经完全消失的路段，考古学家发现了保存相对完好的栈道遗迹、石刻题记、古驿站遗址等重要文物。这些发现不仅填补了历史记录的空白，也为后续的保护和利用奠定了基础。 与此同时，网红徒步路线的兴起为古蜀道注入了新的活力。随着户外运动在中国的普及，越来越多的人开始追求深度体验式的旅行方式。古蜀道恰好契合了这种需求——它既有深厚的历史文化底蕴，又保持了相对原始的自然风貌；既有挑战性，又不至于过于艰险。在一些互联网平台上，关于蜀道徒步的攻略和分享文章动辄获得数万点赞，曾经的“天险”如今成为都市人逃离喧嚣、寻找自我的热门目的地。 ## ## AI新时代的产业演进：曾鸣教授的战略视角 **嘉宾简介** 曾鸣教授曾任阿里巴巴集团总参谋长，亲历了中国互联网从萌芽到成熟的完整周期，同时参与创办了长江商学院与湖畔大学。作为一位深耕商业战略的研究者，他以系统性的“动力学”视角审视产业变迁，为众多创业者和企业家提供了独到的思考框架。 **AI产业化的三阶段模型** 曾鸣教授指出，AI的产业化将遵循三大递进阶段。 1. **技术基础设施阶段**：AI技术逐步被社会接受，演化为像水电一样的公共基础设施。此阶段的核心是技术的可靠性和规模化供给。 2. **百花齐放的应用阶段**：基于成熟的基础设施，大量创新应用将如雨后春笋般涌现，形成生态系统的多样化繁荣。 3. **原生应用阶段**：当海量应用渗透到各行各业后，人们发现需要更底层的运行方法、平台和标准来统一管理这些应用，此时会出现“原生应用”——即在AI底层能力上重新定义业务流程的全新形态。 **各阶段企业生存的挑战** 曾鸣教授强调了一个关键的“阶段性淘汰”规律：**第一阶段的企业很难活到第二阶段；第二阶段的企业很难活到第三阶段**。这并不是说技术创新不够，而是商业模式的适配度、组织能力的演进以及生态位的把握决定企业在阶段跃迁时的生死。只有在每个阶段都能完成“价值迁移”——从技术提供转向平台运营，再到原生创新的企业，才能在AI时代持续生存。 **互联网时代的对照** 为帮助听众形象化理解当前AI的演进位置，曾教授把AI产业化比作互联网的早期发展。他说：“我们现在刚刚走到浏览器阶段，甚至比Yahoo还要早”。这意味着大多数AI项目仍停留在底层接入与技术验证的层面，尚未进入真正的“信息聚合”与“商业变现”阶段。通过回顾AOL（美国在线）作为互联网接入服务商的兴衰，以及Yahoo在门户与搜索业务中的快速崛起，曾鸣教授暗示：*提供技术“接入”本身的模式难以长久存活，真正的价值在于在接入之上构建信息聚合、搜索与应用的生态*。 **模型公司的定位与类比** 曾教授进一步把“模型公司”——即提供大模型能力的企业——类比为互联网时代的AOL。模型公司是AI时代的“基础接入层”，它们为所有下游应用提供必需的算力与算法资源。但正如AOL最终被更开放的互联网生态所取代，模型公司若只停留在“接入”层面，也将面临被更高级平台或原生应用所边缘化的风险。 **非共识判断与“暴论”** 在本次对话中，曾鸣教授公开了15条“非共识判断”，其中不少被主持人称为“暴论”。这些判断包括但不限于： - AI的第一波技术创新（如大模型）不会直接创造长期竞争优势； - 大多数AI创业公司将在第二阶段被平台型公司吞并或自行倒闭； - 未来的竞争焦点将从“模型本身”转向“模型之上的应用层”和“原生应用的标准化”； - 生态位的争夺将决定企业的生死，而非单纯的技术领先。 这些观点挑战了业界普遍对AI的乐观预期，提示创业者和投资者在布局时必须关注商业模式的可持续性和生态系统的演进路径。 **总结与核心启示** 1. **阶段性视角**：AI产业会经历基础设施→应用生态→原生创新的三次跃迁，企业必须提前布局“价值迁移”，否则将在每一次转折中被淘汰。 2. **类比思考**：把当前的AI发展阶段类比为互联网早期的“接入”时代，有助于预判技术普及与商业化的节奏，避免盲目追高。 3. **平台思维**：模型公司若只做底层接入，难以长期保持竞争力；真正的护城河在于在模型之上构建平台、标准和原生应用。 4. **非共识风险**：曾教授的“暴论”提醒业界，AI的热潮背后隐藏着泡沫与淘汰，企业应以系统性思考代替盲目跟风，注重生态位的塑造与组织能力的升级。 **核心启示**：在AI新范式降临之际，企业家需要从“技术驱动”转向“价值驱动”，在每一次产业阶段转换中保持敏捷的转型能力；投资者则应关注那些能够在基础设施之上构建平台或原生应用、并具备生态整合能力的团队。只有把握住“底层接入—平台聚合—原生创新”的演进规律，才能在AI浪潮中立于不败之地。

## Jev：突破传统的决策型AI模型深度解析 ### 引言：重新定义AI的能力边界 在人工智能领域，大多数人对AI的认知往往停留在“生成内容”这一层面。无论是ChatGPT、Claude还是其他大语言模型，它们的主要功能都是生成文本、回答问题、撰写文章。然而，视频开篇就提出了一个颠覆性的问题：如果AI模型根本不需要生成文本，那它还能做什么？答案就是Jev——一个专门为快速决策而生的System 1 AI模型。这一概念的出现，标志着AI技术发展进入了全新的分支，为人工智能的应用场景开辟了更加多元化的可能性。 ### System 1 AI的核心概念与特点 视频首先介绍了System 1 AI这一概念。在认知科学中，人类有两种思维模式：System 1是快速、自动、凭直觉的思考方式，比如识别面孔或理解简单语句；System 2则是缓慢、深思熟虑、需要刻意努力的思考方式，比如解数学题或做复杂决策。应用到AI领域，System 1 AI指的是那些能够以极快速度进行判断和决策的模型，它们不需要经过复杂的推理过程，而是依赖于预先训练好的模式和概率分布来做出即时响应。 Jev正是这样一个System 1 AI模型的典型代表。与传统大语言模型追求的“思考深度”不同，Jev追求的是“响应速度”和“决策效率”。这种设计理念使得Jev能够在毫秒级别完成复杂判断，这对于需要实时处理大量请求的应用场景来说至关重要。 ### Jev与传统大语言模型的本质区别 视频用相当篇幅对比了Jev与大语言模型（LLM）以及推理模型（Reasoning Models）之间的差异。这三者虽然都属于人工智能的范畴，但在设计目标和运行机制上有着本质的不同。 大语言模型的核心能力是“生成”。它们通过预测下一个词的方式来构建连贯的文本输出，这一过程涉及到对语言模式、语义关系、上下文理解等多维度的综合考量。因此，LLM通常需要大量的计算资源和时间来生成高质量的回复。以GPT-4、Claude等为代表的现代大语言模型，其参数量往往达到数千亿级别，运行时需要消耗大量的GPU算力。 推理模型则更进一步，它们不仅生成文本，还会在生成过程中进行“思考”。例如OpenAI的o1、o3系列模型，它们会先构建内部推理链条，对问题进行逐步分析，然后再给出最终答案。这种“思维链”机制使得推理模型在处理数学证明、逻辑推理等复杂任务时表现出色，但代价是响应时间显著延长。 相比之下，Jev的设计哲学完全不同。它不生成任何文本，而是直接输出概率分布。当用户向Jev提出一个问题时，它会评估各种可能答案的概率，并返回一个经过校准的概率向量。这种直接输出概率的方式省去了文本生成的环节，使得响应速度可以达到毫秒级别。视频强调，Jev的这种设计并非缺陷，而是一种刻意为之的优化——它将“判断”能力发挥到极致，而将“生成”任务交给更适合的模型去完成。 ### Jev擅长处理的决策任务类型 视频详细展示了Jev的典型应用场景和它所擅长的决策任务类型。这些任务有一个共同特点：需要快速、准确定义输入内容的类别或属性，而不是需要详细的文本解释。 **路由任务（Routing）** 是Jev最经典的应用之一。在大型AI系统中，用户的问题可能涉及不同的领域、需要不同的专业知识，甚至可能包含敏感内容。传统的做法是将所有请求都发送给同一个大型模型处理，但这会造成资源浪费和响应延迟。Jev可以作为系统的“守门人”，快速判断用户请求的类别，然后将请求路由到最合适的专门模型或处理流程。例如，一个技术咨询请求可以被快速识别并转交给技术支持模型，而一个创意写作请求则会被导向创意助手。这种智能路由机制能够显著提高整个系统的效率和用户体验。 **分类任务（Classification）** 是Jev的另一大强项。无论是垃圾邮件识别、情感分析、内容审核还是意图识别，Jev都能凭借其快速概率计算能力给出准确判断。与需要生成完整分析报告的LLM不同，Jev直接输出分类标签和相关概率，让下游系统能够快速做出处理决策。视频指出，在实际商业应用中，分类任务往往需要在极短时间内完成，比如判断用户输入是否包含违规内容、识别用户是否具有购买意图等——这些场景正是Jev的用武之地。 **AI Guardrails（AI护栏）** 是视频特别强调的一个应用方向。随着AI系统变得越来越强大，如何确保它们不会产生有害、非法或不当的输出成为重要课题。传统方法是让LLM自己“思考”什么不该说，但这不仅效率低下，还可能被绕过。Jev可以在用户输入进入LLM之前就进行预筛选，快速判断输入是否安全、是否符合政策要求。对于模型生成的内容，Jev同样可以进行后处理检查，确保输出不包含敏感信息。这种“事前预防+事后检查”的双层防护机制，大大提升了AI系统的安全性和可靠性。 ### 概率输出的机制与校准技术 视频用了专门章节讲解Jev如何返回概率以及概率校准的重要性。这一部分深入技术细节，解释了Jev工作的内在逻辑。 传统VPN方案的局限性 在讨论现有隐私保护方案时，Barrett对传统VPN提出了独到的批评见解。他明确指出，传统VPN虽然能够在一定程度上改善用户的在线隐私状况，但实际上只是解决了整个问题的一个局部层面。传统VPN的工作原理是将用户的网络流量通过第三方服务器进行转发，这种架构设计本身依然依赖于中心化的服务提供商。 Barrett详细分析了传统VPN存在的几个核心问题。首先，用户必须完全信任VPN服务提供商，因为所有的网络流量都必须经过其服务器，这意味着新的中心化依赖关系被建立起来。其次，VPN服务提供商可能面临来自政府机构的法律压力，被要求提供用户数据或日志记录，这在某种程度上削弱了用户寻求隐私保护的初衷。第三，VPN服务器本身可能成为攻击目标，一旦被入侵，用户的通信安全将面临严重威胁。 Barrett强调，真正的隐私保护方案应该避免引入新的中心化风险点，而传统VPN恰恰相反，它在解决旧问题的同时创造了一个新的单点故障和信任集中点。这种治标不治本的方法无法从根本上改变用户隐私面临的系统性风险。 ## DoxxNet的创新解决方案 针对传统方案的不足，Barrett Lyon介绍了DoxxNet的创新解决方案。他表示，DoxxNet正在构建一个平行的网状网络（mesh network），这是一种完全不同的网络架构理念。该网络的设计目标是实现真正的点对点通信，让用户能够在不依赖任何中心化服务器的情况下进行各种网络活动。 在技术实现层面，DoxxNet的网状网络采用了分布式架构，每个参与者既是数据的消费者也是数据的提供者，形成了一个自我维护、自我扩展的网络生态系统。用户可以在这个网络上进行即时消息传递、语音通话、大文件传输等操作，所有的通信数据都在用户之间直接路由，无需经过任何中心化的应用服务器。 Barrett指出，这种架构的最大优势在于消除了中间人风险。由于没有任何中心化节点存储或处理用户数据，第三方想要监控或截获通信内容将变得极为困难。同时，这种分布式设计也提高了网络的韧性和抗干扰能力，即使部分节点出现故障，整个网络依然能够正常运行。 ##
